# Triage labels

| Matt role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者判断范围或优先级 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | Spec 已批准且没有 open blocker |
| `ready-for-human` | `ready-for-human` | 需要人类实施或平台操作 |
| `wontfix` | `wontfix` | 不会实施 |

`spec` 是 ClinMesh 项目 label；新增任务用它标识引用 [仓库正式规格](../spec/README.md) 的追踪 Issue，既有 spec Issue 在迁移前沿用原合同。它不替代 triage 状态。Assignee、native dependencies、draft PR 和 open/closed state 分别表示领取、阻塞、评审和完成，不再复制为 labels。
