# 病理切片会诊使用指南

本文面向第一次接触病理切片会诊的管理员、医生和开发者，说明乳腺切片病理会诊从安装切片、准备病例到开单、阅片和已阅的完整用法，以及界面上每种状态的含义。设计边界见 [系统架构](architecture.md) 的 8.7 与 10.7 节，切片来源与许可见 [病理切片素材清单](../pathology-assets/README.md)；放射检查见 [影像检查使用指南](imaging.md)。

## 功能概览

门诊医生可以为既往做过乳腺手术的合成随访病例开立“乳腺切片病理会诊”：患者带来既往手术的 H&E 切片，本院病理科几秒后出具会诊报告，医生在浏览器里查看数字切片，确认已阅后才能完诊。

切片取自公开数据集 TCGA-BRCA，是已去标识的真实切片。患者身份、病史和就诊过程仍然全部是合成的。系统只把切片配给受体（ER、PR、HER2）、淋巴结与肿瘤 T 类别都与病例来源记录一致的病例；找不到相符切片的病例不会得到伪造的报告。

一个病例能否看到切片取决于三件事同时成立：

1. 切片已经安装到本机并且已复核发布。
2. 病例已经运行过病理准备，且结果是“已就绪”。
3. 病例已经开始门诊就诊，医生签发了会诊申请。

## 部署者：安装切片

切片不随仓库分发，按清单从公开数据源下载到本机，与放射素材分开安装：

```sh
pnpm pathology:sync
pnpm pathology:verify
```

首批七张切片下载约 1.2 GB，安装后另占约 1.6 GB。下载、离线修复、目录位置和备份见 [部署教程的病理切片素材一节](deployment.md#病理切片素材)。没有安装切片时系统照常运行，医生看到会诊“本院当前未开展”；只安装放射素材或只安装病理切片都可以。

## 管理员：复核切片与准备病例

以管理员登录，进入“模拟数据”。与病理有关的入口有两个：页面上的“病理覆盖清单”，以及每位患者详情里的“病理准备”。两者只有管理员能看到。

### 病理覆盖清单

覆盖清单按“适配条目”列出本机的切片。一个条目是一种事实组合，例如“ER 阳性 · PR 阳性 · HER2 阴性 · 淋巴结阳性 · T2”；条目由切片的来源临床字段自动得出，不需要手工维护。每张切片显示两个状态：

| 显示 | 含义 | 处理 |
| --- | --- | --- |
| 已安装 / 未安装 | 切片文件是否在本机 | 运行 `pnpm pathology:sync` |
| 已发布 / 未发布：尚未复核 | 报告是否通过自动核对并由人工复核签署 | 在“复核预览”中对照切片核对后签署 |

来源字段不全（例如淋巴结分期未知）的切片列在“缺少匹配字段的素材”下，不参与病例匹配。

### 复核并签署切片

点切片旁的“复核预览”可以直接阅片，下方是报告草稿、自动核对结果和来源临床字段。逐张核对三件事：最低倍率下组织区域内没有可识别的文字；报告所写内容与切片不矛盾；来源字段转录无误。核对无误后由维护者在命令行签署，页面不提供写入：

```sh
pnpm pathology:review --asset <素材标识> --reviewer <复核人> --pathologist no --conclusion approved
```

`--pathologist` 如实填写复核人是否为病理专业人员。签署绑定切片文件、来源字段、报告内容和整理规则的哈希，任何一项变化都需要重新签署。演示、截图和录屏使用这些切片时保留 [清单](../pathology-assets/README.md#来源许可与署名) 要求的署名。

### 病理准备

“准备下一批病例”为患者库中尚未按当前清单与安装状态准备的病例匹配切片；患者详情里的“病理准备”可以对单个病例重新准备。面板显示来源诊断、五项来源固定事实、可送检的既往手术和所配切片：

| 状态 | 含义 |
| --- | --- |
| 已就绪 | 有受体、淋巴结与 T 类别全部相符的已发布且已安装切片；面板同时列出由切片补充的组织学类型 |
| 待处理 | 病例既有事实与全部已发布切片矛盾，首批切片不覆盖这种组合 |
| 未覆盖：来源没有可用依据 | 不是女性乳腺恶性肿瘤病例 |
| 未覆盖：既往病史中没有可送检的手术 | 没有早于本次就诊的肿块切除或乳腺病灶切除 |
| 未覆盖：缺少受体、淋巴结或 T 分期 | 来源或切片缺少某项事实，无法确认相符 |
| 未覆盖：没有通过复核的切片素材 | 本机没有已发布的切片 |
| 未覆盖：相符切片尚未安装 | 有已发布的相符切片，但本机未安装；安装后重新准备 |

安装、移除或恢复切片后，重新运行病理准备。病例开始就诊前，所配切片跟随最新一次准备；开始后已配的切片不再更换，重放同一病例看到的是同一张切片，文件缺失时应修复原切片。

### 得到一个能做会诊的病例

随机生成的患者很少恰好是受体组合相符的乳腺随访病例。在“生成患者”的“定向病例”中选择一个乳腺切片会诊条目，性别和年龄会自动对齐（女性，45–80 岁），“高级设置”中的历史起始日期也会前移到结束日期前 45 年，生成的患者满足该条目并已完成病理准备。确诊和手术可能发生在多年以前，起始日期改得更晚时表单会提示，生成任务也会以“历史起始日期晚于所选适配条目的要求”失败。定向生成的失败原因和处理与 [影像检查](imaging.md#得到一个能看片的病例) 相同；稀有的受体组合（如三阴性）每次尝试最多约 4 分钟，整个任务可能需要十几分钟；仍失败时更换 seed 再试。按受体定向需要支持 Observation 保留条件的 Synthea Provider，旧 Provider 会提示不支持定向生成。

## 医生：开单、阅片、确认已阅

1. 在“待诊”选择患者，点“开始首诊”。
2. 打开“检验检查”页签，切到“病理会诊”。未开立时直接搜索目录并明确选择会诊项目；已有申请时先点“追加申请”，在“送检的既往手术”中选择这次会诊对应的手术，填写“会诊目的”，点“签发申请”。也可以先“保存草稿”。
3. 申请出现在申请列表中。病理科在后台收片、阅片并签发报告，页面会自行刷新。
4. 报告出现后点“打开切片”阅片。
5. 切片成功显示之后，“确认已阅”才可以点击。确认后这份报告不再阻塞完诊。
6. 需要把结论写进病历时点“摘要插入病历”，病理诊断会追加到病历“辅助检查”，写明报告版本与签发时间。

“送检的既往手术”只列出该患者既往病史中医生本来就能看到的乳腺手术。医生看不到切片编号、来源信息或匹配原因。同一会诊项目同时只能有一条进行中的申请。

### 申请状态

| 状态 | 含义 | 可用操作 |
| --- | --- | --- |
| 已开立 | 申请已签发，等待病理科收片 | 取消申请 |
| 已收片、阅片中 | 病理科正在处理 | 等待 |
| 报告已出 | 报告已签发，尚未确认 | 打开切片、摘要插入病历、确认已阅 |
| 医生已阅 | 报告已确认 | 打开切片、摘要插入病历 |
| 未取得结果 | 这个病例没有相符的切片，或系统连续三次执行失败；没有报告 | 重试、取消申请 |
| 已取消 | 申请已取消 | — |

### 报告内容

报告包含标本信息（所选既往手术、切片数量、染色）、镜下所见、病理诊断、既有免疫组化结果和备注。受体结果引自原始病理资料，本次会诊不提供免疫组化切片；来源资料没有组织学分级，报告会注明；切片只含原发灶组织，淋巴结情况以原病例记录为准。

### 阅片器

| 操作 | 方式 |
| --- | --- |
| 平移 | 拖动切片，或在右上角的导航小图中拖动 |
| 缩放 | 鼠标滚轮、单击切片，或“+”“−”按钮；最高 20× |
| 回到全貌 | “复位” |
| 全屏 | “全屏”与“退出全屏”；返回后病例和未提交的输入保留 |

工具栏显示当前倍率。切片按原始颜色值显示，没有做颜色管理。阅片器显示“影像暂不可用”时，说明本机的切片文件缺失或损坏：报告仍可阅读，但不能确认已阅。由部署者运行 `pnpm pathology:repair` 修复，修复后无需重启。

## 管理员：更正报告

当前账号兼有管理员岗位时，每份报告下方有“更正报告（管理员）”。更正不能改写报告文字，只能填写同一切片另一份已复核发布的“报告内容修订号”和更正原因。提交后系统按该修订重新签发报告，原报告和原确认保留在“历史报告”中，新报告需要医生重新确认。可选的修订号在“病理覆盖清单 → 复核预览”中查看。

## Agent 与 CLI

Agent 通过报告参与诊疗，不读取切片像素。在 DSH 中，页面 Tools 可以读取会诊服务与可送检手术、读取申请与报告、替人展开切片、填写草稿，并准备开立、取消、重试、已阅和更正的提案；每个正式动作都由登录的人确认，切片没有在人面前显示过时已阅提案会被拒绝。各 Tool 的可用条件见 [Agent 操作与反馈](agent-capabilities.md)。

任务 Agent 通过 CLI 执行同样的操作，命令与输入格式见 `clinmesh-doctor` Skill：

```sh
clinmesh doctor case pathology-services list --case-id <case-id>
clinmesh encounter pathology-request draft set --input @pathology.json --idempotency-key <key>
clinmesh encounter pathology-request issue --input @pathology-issue.json --idempotency-key <key>
clinmesh pathology-request cancel --input @pathology-cancel.json --idempotency-key <key>
clinmesh pathology-request retry --input @pathology-retry.json --idempotency-key <key>
clinmesh pathology-report acknowledge --input @pathology-acknowledgement.json --idempotency-key <key>
clinmesh pathology-report correct --input @pathology-correction.json --idempotency-key <key>
```

## 常见问题

**会诊项目显示“本院当前未开展”。** 本机没有已发布且已安装的切片，页面不能选择该会诊项目。在“病理覆盖清单”查看切片是未安装还是未发布。这个状态与具体病例无关。

**“送检的既往手术”没有可选项。** 该患者的既往病史中没有早于本次就诊的肿块切除或乳腺病灶切除，这个病例不能开立会诊。

**签发后显示“未取得结果”。** 这个病例没有配到切片。请管理员在患者详情的“病理准备”中查看原因；如果从未准备过，先运行病理准备再点“重试”。

**“确认已阅”是灰色的。** 需要先点“打开切片”并等切片显示出来。

**页面提示没有可用的病理素材清单或适配规则。** Server 找不到 `pathology-assets/` 清单。病理会诊在源码运行方式下使用。
