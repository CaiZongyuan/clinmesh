# 产品方向与交互偏好

修改产品方向、交互取舍或对标外部系统时查阅；已落地的业务与界面合同归 [`docs/architecture.md`](../architecture.md) 与 [`docs/ui/design.md`](../ui/design.md)，[工程记忆入口](memory.md)拥有协作偏好。

## 交互打磨防回退提示

- **安静反馈**：保存成功且界面已应用返回值时只提示“已保存”，后台次级刷新失败静默处理，不向用户暴露“已保存但刷新失败”等内部同步提示；问诊自动整理与 DSH 环绕柔光遵循已落地的安静记录与执行期反馈决策，不回调逐条确认弹窗或常驻失败横幅。
- **高密度医疗直觉优先**：先立住贴合国内医护直觉的紧凑工作台与分屏层级，再自然嵌入 Agent 协作舞台；不添加“留空表示未记录”等解释型废话，不抬高 Surface `z-index` 遮挡 DSH 原生弹层。

## 长期方向与外部参考优先级

- **长期演进目标**：支持 Agent 扮演患者或岗位人员参与全院多方仿真、教学复盘与持续自我改进（RSI）。
- **外部参考优先级**：中国公立医院正向/逆向业务流与交接以 OpenHIS 为首要业务参照，FHIR R5 仓储、历史、Search 与审计以 Medplum 为首要基础设施参照，`references/DSH-AGUI-demo` 等案例仅参考交互布局；不照搬外部物理架构或未闭环的占位菜单。
