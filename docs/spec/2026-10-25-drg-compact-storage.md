# DRG 离线资料无损精简储存

Status: implemented

## 问题与目标

完整 DRG 离线资料包含完全相同的文件、可重建导出和逐行重复来源说明，常驻内容为 665,553,443 bytes。本需求在完整覆盖和当前使用限制不变的条件下，同时完成派生文件按需读取与字段模板化，目标常驻内容约 350 MB；新增索引和模板计入实际结果，下载体积另行实测。关联执行任务为 Issue #297。

## 范围

- 保留五目录 r3 的全部 records、原文页和来源元数据，以及 OpenDRG 全部地区、版本、参数、规则和来源关系。
- 完全相同内容只保存一次，以索引保留每个原逻辑路径；accepted、hierarchy、CSV、module JSON 和展开 DAT 按需重建。
- readiness 使用完整状态模板，rule-members 使用原文页和零起算行引用；不按编码合并成员记录。
- 制包、完整性检查、自动安装和显式导出使用同一读取合同；安装不永久物化旧副本，也不引入跨运行的核验缓存。
- 使用新的 inventory 和分发身份；旧锁与已发布资产保持可回退。

## 用户故事

1. 作为安装者，我希望完整资料自动准备后减少磁盘占用，并继续获得相同的完整性保证。
2. 作为维护者，我希望按原逻辑路径读取或导出任意文件，逐字节核对旧资料及其来源。

## 验收条件

- [x] 所有 2,335 个原逻辑文件可重建为原 SHA-256；保留完整记录、顺序、资格状态、原文和来源。
- [x] 别名不合并地区或版本身份；保留隔离理由、缺参、source-only-unverified、offline-review、integrity-only 和 runtimeEnabled=false。
- [x] 模板及页行引用覆盖全部 62,648 条 readiness 和 139,591 条 rule-members；无效引用、缺少来源和失配数据拒绝通过。
- [x] 制包结果确定可复现，仅包含锁定内容；记录压缩字节、常驻总字节（含索引及模板）、物理文件数和节省比例。
- [x] 空目录首次准备、离线重复准备、损坏修复、下载或发布失败保旧及 check-only 均由公共准备入口验证。
- [x] 路径越界、链接、重复路径、循环或悬空别名、错误版本、索引与文件哈希失配均拒绝就绪。
- [x] 按需读取及导出不向安装目录写入派生副本；旧格式仍可校验和安装，旧发行身份不被覆盖。

## 设计决定

在既有逻辑 manifest/checksums 之外增加锁定的物理储存索引；原逻辑文件哈希继续约束字节，物理索引描述内容别名、受限派生配方及模板文件。读取器只解释内建数据转换，不执行包内 JavaScript。完整核验覆盖所有原逻辑文件与物理储存。转换在独立目录完成并逐文件往返，成功后才输出新锁和归档。

非平凡格式及分发取舍由对应 Agent Note 记录。

## 测试策略

沿用原安装规格的公共准备、制包和清单查询入口，增加同一读取器的显式文件导出入口。合成 fixture 与受控本地 HTTP、临时 SQLite 覆盖失败边界；真实固定资料执行全量字节往返、制包和仓库外空目录首次及重复准备。不开启模型或压测。

实际资料规模、全部旧 SHA-256 往返、真实首次／离线重复准备及固定公开下载地址的完整字节核验结果见[固定快照证据](../drg-reference-storage.md#当前固定快照)。

## 范围外

参考 SQLite 瘦身、药品或耗材收费价格接入、资料子集分发、患者分组及支付运行用途均不属于本次交付。

## 依赖与风险

旧数据的 JSON 数字词法、字段顺序、CSV BOM 和换行也是原 SHA-256 的组成部分；转换必须保留这些字节属性。新 Release 资产需要独立发布权限，未经发布的本地包不得宣称已供新安装取得。安装和完整覆盖合同继续见[原规格](2026-10-22-drg-reference-installation.md)。
