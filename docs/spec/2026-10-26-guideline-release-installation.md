# 既有与冠心病指南的 Release 分发及内部测试安装

Status: implemented

执行追踪：[GitHub Issue #315](https://github.com/CaiZongyuan/clinmesh/issues/315)。

## 问题与目标

既有指南同步能够建立个人机器上的全文数据库，但克隆代码不会取得该数据库及原文；新提供的冠心病 PDF 也尚未接入来源注册表和同步入口。内部测试人员应能通过正常准备入口，从固定 Release 取得同一版资料并建立可检索的指南库，无需复制维护者桌面目录，也不能只有下载数量而没有可用正文。

本需求承接用户确认的内部测试用途，采用既有 [DRG 自动安装规格](2026-10-22-drg-reference-installation.md)对应的固定 Release 分发思路。既有来源、全文定位、检索和建议失效合同见[免费指南规格](2026-10-16-free-guideline-corpus.md)；本需求只增量调整资料获取、安装与内部测试部署的启用策略，不重写诊疗建议业务合同。

## 范围

- 纳入 [既有来源注册表](../../apps/server/reference-data/guideline-sources.json)的 26 项资料：21 份国内官方 PDF 和 5 份 WHO 正文文本。已取得的 1,255 段是既有快照基线，不是新包应硬编码的段落数。
- 纳入用户提供的冠心病资料包内全部 32 份 PDF，具体输入见文末清单；随附 XLSX 用于核对题录，`.DS_Store` 不进入资料包。两批合计 58 项候选来源，实际来源、物理文件和可检索数量分别统计，去重不丢失版本与出处关系。
- 登记原始题名、发布机构、文献性质、年份与版本、适用范围、原始来源、文件 SHA-256、抽取方式、页码或行号、文本核验和来源状态。英文正文登记面向冠心病与 PCI 的中英主题词，避免仅靠英文题名才能命中。
- 使用独立指南 Release 资产分发固定快照，保留原件、已校验提取正文和来源清单；接收端复用既有指南 SQLite 及全文检索能力。包及原件不提交 Git，代码保存版本、下载地址、哈希、格式和规模约束，不依赖维护者个人绝对路径。
- 接入独立 Server、DSH、局域网及生产构建的准备阶段，并提供独立准备和只读检查入口。已有有效安装复用，更新先在临时位置完成核验，再发布到运行库；业务请求期间不下载资料。
- 内部测试部署通过显式策略允许本包中已登记且正文可靠的资料进入检索和建议依据，包括既有用途待核实及非商业类别。来源原始许可说明和核实状态继续如实保存，不改写为开放许可；内部测试用途不再作为本任务的分发或启用前置阻塞。未选择内部测试策略的部署维持既有默认用途过滤；已知撤回、被替代和不可读正文仍不得成为可执行建议依据。
- 固定包、本地同步及后续院内上传复用同一导入规则：同一文献、版本及内容完全一致时只存一份正文并返回一组检索结果，保留各导入来源记录及既有停用限制。节选、修订或不同版本另立记录并关联原来源，不以多个入口重复扩大覆盖量。

## 用户故事

1. 作为内部测试安装者，我希望正常准备环境即可取得既有与新增指南，以便与同事使用相同资料而无需索取个人数据库。
2. 作为资料维护者，我希望固定包可核验、可重复安装、失败保留旧版，以便可靠更新内容。
3. 作为测试医生，我希望冠心病相关问题能取得有原文定位的依据，并能分辨资料缺失、文本未核验、用途未启用与检索无匹配。

## 验收条件

- [x] G1：清单可逐项核对既有 26 项和新增 32 项输入；报告来源数、下载文件数、已提取来源及段落数、可检索来源及段落数、失败和停用原因，重复版本不冒充新增覆盖。
- [x] G2：冠心病输入完成逐页机器提取及来源、正文和定位核验；2016 年中国 PCI 指南和 2015 年冠状动脉痉挛共识由 Agent 对照原始 PDF 校对恢复的正文与关键表格，核验记录可追溯到原件、物理页和修订。未解决的正文问题如实报告并隔离，不要求用户另外提供人工校对记录。
- [x] G3：关键表格、脚注、数值、单位、否定词和适用条件有可追溯的核验记录，区分自动提取检查、Agent 原页校对与自然人审校，明确实际覆盖范围和未确认段落；PDF 保留物理页定位，WHO 文本保留原有行号或字符定位；不以模型摘要替代原文。资料年份明确可见，不将 2015—2023 年合集标为最新指南全集。
- [x] G4：仓库锁定独立指南包的精确版本、地址、哈希和规模；已发布的同一版本资产不覆盖。包内来源身份和原文哈希与清单一致，既有 DRG Release 与临床参考目录不被混入或改写。
- [x] G5：仓库外空数据目录不接触维护者桌面和缓存，即可从固定 Release 安装；Server、DSH、局域网及生产构建的资料准备覆盖同一版本。已有业务库或参考目录不能使指南准备被跳过，安装完成后后端实际读取目标指南库。
- [x] G6：重复准备离线复用完整资料；下载失败、错误版本、哈希不符、截断包、缺文件、超额解包、越界路径和链接条目不能产生假就绪或部分发布。修复失败不丢失已有有效资料、其他来源或业务数据；容器重建及镜像更新保留指南维护限制；只读检查不修改正式库、安装目录或审计。
- [x] G7：显式内部测试策略下，正文可靠且未撤回、未被替代的已登记来源实际可检索；原始用途待核实状态仍可回读。关闭该策略后恢复既有用途限制，模型输入、可用统计、检索 revision、缓存与旧建议失效判断保持一致，不借用非商业开关暗中放行所有未核实资料。
- [x] G8：从既有指南检索及诊疗建议公共入口，以受控模型流验证至少一项旧来源和多项新增冠心病来源的实际引用；覆盖稳定冠心病及血运重建、抗血小板、对比剂安全、术后评估主题，中文查询能取得对应中英文依据。无匹配、正文未就绪或策略未启用时返回真实缺口，已安装不等于检索命中。
- [x] G9：来源版本、状态、正文或部署策略变化后，旧建议不可继续采纳；生成与核验使用同一份真实检索依据，医生草稿保护及正式确认边界继续有效。
- [x] G10：部署说明包含首次获取、内部测试启用、独立检查、更新、失败恢复和备份；全新环境安装证据明确区分下载成功、库已加载、可检索和实际引用，不以维护者现有本地数据库替代新安装验收。
- [x] G11：跨固定包与本地入口导入相同文献版本及完整正文，只物理保存和索引一份，检索及段落统计不重复；来源记录、各自范围与限制保留。交换导入顺序及重复导入不改变最终结果；节选、修订、不同版本及不同原件不误合并，移除或清空一个来源不删除其他来源仍引用的正文。原来源停用向下传播，派生来源停用不反向停用原件；旧库升级、只读检查、失败回滚与损坏修复不丢数据、不放宽限制。

## 设计决定

复用 PR [#291](https://github.com/CaiZongyuan/clinmesh/pull/291)和 [#301](https://github.com/CaiZongyuan/clinmesh/pull/301)的固定资产、内容锁、安全解包、失败保旧与离线复用机制，为指南单独拥有来源清单和安装入口，不将指南解释为 DRG 资料。采用原件与经过机器核验的提取结果制包，在部署侧导入既有指南库；正文提取工具及格式版本随包锁定，接收端验证原件、派生正文与定位的对应关系。边界和取舍见[分发决定](../decisions/implemented/architecture/2026-10-26-guideline-release-installation.md)。

内部测试启用是部署策略，来源许可是事实，两者分别表达。新策略只调整测试部署对已登记来源的采用，不放宽任意 URL、未登记来源、撤回状态、文本质量或病例权限边界。首次建库或切换路径按既有后端加载合同处理；运行库更新继续遵守 revision 和旧建议失效合同。

Agent 承担原件对照校对并记录实际检查范围；自动检查不能冒充 Agent 阅读，Agent 校对也不登记为自然人审校。未确认的提取异常段落保留原文和定位，但不送入检索或模型。代码实施授权不包含发布 Release、合并或真实模型及负载测试；这些动作按工程协作授权规则分别处理。

## 测试策略

使用合成归档、受控 HTTP 服务和临时 SQLite，从制包、资料准备 CLI、只读检查、既有检索及诊疗建议 HTTP 公共入口验证首次安装、离线复用、损坏修复、失败保旧、归档约束、用途切换与旧结果失效。新增指南引用使用受控模型流，断言真实检索来源和页码进入生成及核验输入，不能直接构造可采纳建议冒充检索成功。

真实资料另外从仓库外空目录下载已发布固定包，核验清单、正文、统计、离线重复准备及后端加载；Web 和 React 18/19 Surface 按受影响合同验证引用展示与医生确认。该证据不等于右侧原生 DSH Agent 已拥有独立检索工具。纯资料和文档阶段运行对应检查，跨启动或构建路径实施按仓库规则运行所需检查；不默认运行真实模型、压测或真实患者验证。

## 范围外

新增向量数据库、全网搜索、自动升级到未登记最新版、自动抓取付费资料、住院 PCI 决策支持、右侧 DSH／CLI 独立指南检索工具、自动诊疗和完整临床质量认证。指南入库不自动使文书质控接入临床指南，也不改变院内目录、费用、DRG 分组和医生正式操作合同。

## 依赖与风险

维护者制包需要取得既有 26 项原件及用户提供的 32 份 PDF，分别记录可读正文与未确认段落；接收端不能依赖这些维护者输入路径。首次获取依赖固定 Release 可达，失败应明确报告，已有完整安装可以离线复用。复杂临床条款的文本校对与指南现行性分别表达，局部核对不冒充全篇审校。内部测试范围是已确认需求，保留原始权利说明，不把待核实用途升级为已取得开放许可。
