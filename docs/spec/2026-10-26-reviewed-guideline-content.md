# 冠心病本地资料推荐流程验证

Status: implemented

## 问题与目标

本机免费指南库已恢复，但用户提供的冠心病资料尚未进入推荐。当前阶段先跑通本地资料、检索、检验／诊断／处方建议、独立核验与医生正式确认；商业用途核验不作为这一内部流程验证的前置条件。保留真实许可、发布者和版本，不把本地验证改写为商业授权。

[Issue #315](https://github.com/CaiZongyuan/clinmesh/issues/315)追踪原有 26 项和新增 32 份候选资料的固定 Release 分发、自动安装及完整新环境验收，正式 owner 为该票指定的 `docs/spec/2026-10-26-guideline-release-installation.md`。本规格仅拥有当前先行的本地冠心病推荐流程验收，不替代整项规格，也不将本地库成功当作 Release 安装完成。

## 范围

- 核对桌面全部 32 份冠心病 PDF，保存纳入或暂不纳入的原因；文字层异常或符号不可解释的文件／页不进入模型，不猜测补全医学符号。
- 显式本地导入只写入受控的本地验证来源，按原始 SHA-256 和物理页范围读取用户提供的原件；原始文件与现有 26 份资料保留原样。
- 真实标题、文献性质、发布者／作者、版本、出版链接、原文位置、节选范围与实际使用条件随检索依据保留并可查看。不把节选标成完整原文或最新指南全集。
- 本地验证模式默认关闭，仅由可信部署配置开启，仅作用于显式导入的本地来源，并进入检索 revision。原非商业用途开关不被打开，其他来源不被连带放开。
- 复用既有门诊建议、院内共享目录、生成与独立核验、医生编辑及正式确认流程，只读取岗位可见证据，不新增临床状态机或住院助手。
- 本机完成实际导入、检索和服务读取验证；合成病例、临时业务库与受控 Provider 验证冠心病诊断、检验与处方的完整接线，不调用真实模型。

## 用户故事

1. 作为医生，我希望本地冠心病资料能参与当前病例的建议，并能查看原文与范围。
2. 作为测试人员，我希望通过真实业务入口完成建议、核验、编辑和正式确认，同时保留剂量及病例证据不足时的限制。
3. 作为资料维护者，我希望原文和范围可核对、重导幂等，撤回或移除后旧内容停止提供。

## 验收条件

- [x] A1：本地验证模式开启时可检索本次导入的冠心病原文；关闭后对应依据及旧建议失效，即使该本地来源另有开放许可。原 WHO／未知来源不被连带放开。
- [x] A2：32 份候选有完整纳入／暂不纳入记录；实际页范围、版本、哈希和原文位置一致，无完整原文、缓存或个人桌面依赖提交到 Git。
- [x] A3：公开导入入口拒绝错误哈希、非法／越界范围、不可读原文及不可解释控制字符；保留其他来源及原始文件。
- [x] A4：重导不重复段落；范围收紧、撤回或移除优先停用旧内容，文件缺失或更新失败不恢复已撤销范围。原来源稳定身份撤回时，派生内容及统计同步停用。
- [x] A5：公开 HTTP 和受控 Provider 证明冠心病原文同时进入检验、诊断和处方的生成与核验；未纳入页不进入请求。
- [x] A6：合成冠心病病例可以通过真实入口确认诊断、开具检验及处方。处方字段缺依据时保持空值，医生按正常人工编辑完成，不伪造产品核验或降低正式开具校验。
- [x] A7：当前服务打开实际目标库；资料、范围和用途变化后旧自动建议失效，已正式确认的诊疗事实保留。完成真实 Web 入口验证。
- [x] A8：部署、当前合同及证据与本地验证范围一致，未声称 #315 的 Release 制包、自动安装或新环境验收已经完成。

## 设计决定

受控本地验证来源使用独立、稳定的来源身份，实际出版状态和许可字段保持真实。目的开关作用于本地来源命名空间，默认正常用途不自动消费用户验证资料；撤回仍生效。来源元数据参与段落依据身份，范围或适用条件变化时旧依据 ID 失效，不在临床界面展示内部哈希代替出处。

复用现有指南库和 PDF 提取器；本地文件按内容哈希定位，不扩大官方下载 URL allowlist。不在业务请求中读取任意文件、下载或自动导入。资料来源事实见[冠心病评估](../research/2026-10-26-coronary-guideline-folder-assessment.md)。

用途隔离、范围收紧和依据身份的取舍见[本地验证用途决策](../decisions/implemented/architecture/2026-10-26-local-guideline-validation.md)。

## 测试策略

导入入口与 `GuidelineCorpus.search/sources` 使用合成 PDF 和临时 SQLite 验证原文、范围、哈希、模式隔离、幂等、失败与撤回。公开 HTTP 使用受控模型边界验证三类建议的原文引用及正式确认；浏览器从实际 Web 入口验证依据、待补字段、人工编辑和持久结果。完成相关类型、静态、文档、构建及固定范围双轴审查；不用真实模型或压测替代接线证据。

## 范围外

#315 的固定 Release 资产发布、自动安装和仓库外空目录验收；其他国内来源的批量启用；商业许可定性、训练／微调、整册公开分发、真实模型或负载测试；新增住院建议、修改临床状态机、伪造产品说明书或监管核验；用户其他未提交改动的整合。

## 依赖与风险

既有资料版本较旧，临床现行性和个体适用性仍需保留限定。本地验证只证明输入、核验和业务接线，不构成医学准确性认证。省略下载地址的本地来源要求新读端先部署；回滚旧读端时需恢复指南库一致快照，不回滚业务库。异常原文保留待可靠替代或人工核对，不以非空字符数证明可靠。
