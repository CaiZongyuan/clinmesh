# 免费跨专科指南全文与诊疗建议检索

Status: implemented

本文拥有免费指南采集与全文检索的增量需求；[既有诊疗建议规格](2026-10-13-doctor-guideline-recommendations.md)继续拥有建议生成、独立核验、逐条采纳、草稿保护与医生最终确认合同。来源事实和接入调查见[指南来源研究](../research/2026-10-13-clinical-recommendation-guidelines.md)。免费路线、跨专科目标及运行时接入方案已确认。

## 问题与目标

当前建议使用少量固定引文，病例落在现有主题之外时无法获得相应依据。用户希望尽量扩充不同病种和专科的指南，并明确本阶段只使用免费来源。目标是取得可追溯的完整原文，按当前病例检索相关章节供既有生成与核验使用。

## 范围

- 免费来源优先使用国内官方公开发布的诊疗指南、方案与标准，补充单篇许可适用于当前用途的 WHO 全文；不同资料类型保持原始身份。
- 范围跨病种与专科，不限定避孕；首批使用实际取得的官方原文，不把来源目录、PDF 文件数和已可用指南数混为一谈。
- 来源清单记录发布者、题名、版本、来源页、原文件、内容哈希、可用文本、定位方式、许可与更新状态。获取失败、正文不可读或许可尚待核实的资料保留明确状态。
- 完整原文与派生索引保存在本地数据目录，Git 保存必要的来源清单、获取与校验实现及合成测试，不提交整库原文。
- 接入现有诊疗建议生成与独立核验；检索命中支持既有范围之外的主题，不继续仅由原有固定主题词决定指南和参考诊断候选。

## 用户故事

1. 作为医生，我希望不同病种都能检索到已经取得的相关指南原文，并按需核对出处。
2. 作为维护者，我希望免费更新指南，明确看到已发现、已下载、已提取、已允许使用和已可检索的实际数量。
3. 作为医生，我希望缺少适用指南时看到真实缺口，自己的草稿和正式操作边界继续得到保护。

## 验收条件

- [x] F1：采集只使用登记的免费官方来源；不触发订阅、付费接口或购买，无法取得的来源记录具体原因。
- [x] F2：至少以一个跨病种官方合集和多个不同主题的 WHO 全文验证获取、哈希、版本、许可与重复运行；真实下载数量与可用文本数量分别报告。
- [x] F3：文本提取与分段保留可核对的原文、章节或页码定位、否定和限定语，不以模型改写摘要替代原文；无法可靠读取的资料不进入可用证据。
- [x] F4：同一来源重复获取不生成重复版本；失败或损坏的更新不替换原有可用版本。已知撤回或替代的资料不冒充当前版本。
- [x] F5：当前授权病例能够检索已导入的相关章节；未知、未获准用于当前用途或未完成提取的资料不能成为建议引用。
- [x] F6：同一建议的生成与独立核验使用相同的真实检索依据，引用可追溯至完整来源；继续检查适用性、目录匹配及所有候选，检索命中本身不代表临床建议成立。
- [x] F7：病例、权限、指南内容或版本变化后，旧建议不可采纳；检索与模型输入遵守现有预算，资料不足时保留草稿并显示缺口。
- [x] F8：公开 HTTP、真实 SQLite、真实 Web/DSH 入口验证至少一个新增主题的指南引用路径，以及缺证、失败、人工编辑保护和医生正式确认边界；替身证据与真实模型质量证据分开报告。

## 设计决定

### 已确认

- 本阶段只使用免费的指南来源，不采购商业库或收费 API。
- 覆盖尽可能多的病种与专科；国内官方资料优先，WHO 为免费路线的补充，单篇许可仍须适用于实际用途。
- 既有临床引用、草稿保护、院内目录与医生最终确认要求继续有效。

### 已确认的实施方案

- 一次完成免费来源采集、完整文本读取、可追溯分段、本地检索、既有建议流程接入和验证。
- 复用项目现有 SQLite 和全文检索模式；不增加收费检索服务。网络获取由显式同步入口执行，建议生成读取已经校验的本地资料。
- WHO 优先使用官方提供的完整正文文本层；国内 PDF 需要可靠文本提取能力，具体解析依赖由实施阶段按现有工具与最小必要依赖选择。
- 以来源可用性和病例相关性选择章节；检索结果仍经过原有生成及独立核验，不自动扩充院内项目、药品或正式诊断。

## 测试策略

1. 按 TDD 从已登记的免费源获取与校验、真实文本定位和检索公共接口逐个锁定行为，外部网络使用合成响应与固定本地输入。
2. 覆盖重定向及来源边界、超大或损坏文件、哈希变化、重复导入、不可读文本、许可不可用、撤回版本、中文与英文检索、相邻章节限定语及无匹配结果。
3. 复用现有建议 HTTP/SQLite 与模型桥测试，验证真实检索证据到生成、核验、引用与失效的完整路径，不用直接构造可采纳建议代替检索验收。
4. 运行完整交付范围所需的类型、静态、文档、相关回归和跨包检查；用户可见行为通过实际 Web 与锁定 DSH 入口核对。

## 范围外

- 付费订阅、商业指南 SDK/API、联系供应商、购买或绕过登录和访问限制。
- 将全文公开下载等同于任何用途许可，或将 WHO 非商业许可自动解释为商业模型服务授权。
- 将新增指南等同于全病种医学质量保证、全面药学安全质控或自动正式诊疗。
- 自动新增院内尚未提供的药物、诊断编码、检查项目或医疗服务。
- 本轮仅为演示临时拼接少量摘要，或仅增加链接而不接入正文检索。

## 依赖与风险

- 国内 PDF 使用 PDF.js 提取物理页，WHO 使用官方全文文本层；可读取不等于复杂表格、脚注阅读顺序和临床语义已经完成医学审校。
- 公开资料的版本、文本质量、许可和适用范围不同。已下载不代表已允许模型使用，未核验的状态必须可见，不能伪造可用覆盖数量。
- 可用指南增多不保证院内目录足够，也不保证模型给出正确建议；真实模型仍可能错误引用或给出错误解释，既有独立核验与医生最终确认继续执行。
