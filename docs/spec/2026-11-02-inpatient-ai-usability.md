# 住院 PCI AI 减负：造影报告带入、费用与医保说明、指南依据及去除跟进门槛

Status: approved

## 问题与目标

住院 PCI 的 AI 能力已经实现，但医生在真实流程中仍要先手填选型参数、逐项认可候选并分两次确认，AI 主要复核医生已经做出的决定。持续跟进中的耗材分析在 DRG 规则未启用、分组未完成或缺少支付参考时全部停止，页面只显示原始错误码；部署默认不启用 DRG 规则，因此开启跟进后 AI 实际不工作。术中每登记一笔耗材都会自动发起生成与核验两次模型请求，返回的数量由规则预先算定，模型只补一句理由。计划与实际用量、耗材收费核对仍要求事先开启持续跟进，未开启的病例在术后看不到这些差异。现有指南库能支持支架类别、影像指导和测量要求的说明，但住院耗材建议没有接入指南原文，医生看不到选型背后的指南依据。

目标是让 AI 替医生做准备工作，医生只做一次审阅：造影完成后由仿真侧产生结构化造影报告，系统按规则把测量带入 PCI 选型草稿，AI 起草耗材清单并用自然语言说明本次住院费用与医保病组的关系，医生在一个界面确认一次。DRG 不可用只影响医保说明，不阻断耗材建议；术中改为实时费用板，不自动调用模型；术后用量与收费差异不依赖持续跟进。同一审阅区提供带原文出处的指南依据说明；没有造影报告、测量不全时，仍给出有条件的类别说明和具体缺项。

## 范围

- 仿真侧造影报告：固定 PCI 病例的 Case Truth 增加造影所见（靶血管部位、病变长度、近端与远端参考管腔直径、测量方法）。诊断性冠脉造影（`88.5500`、`88.5600`）完成后，仿真侧经持久后台任务读取 Case Truth，按规则或模板生成本院正式造影报告及结构化测量，关联本次造影 Procedure，不调用模型。Case Truth 缺少造影所见时报告明确为无法生成，不以默认值补齐。
- 选型草稿按规则带入：本次住院已有造影报告且 PCI 计划尚无医生确认的选型时，系统从报告逐字段复制测量的对象、部位、数值、单位、方法与来源（报告身份及版本），靶部位取自报告；每类预计数量及依据按当前合成方案写明来源。报告缺少的字段在草稿中保持缺项并标出。不用模型读取或推断测量值。没有造影报告时保留医生手填路径。
- AI 起草与一次确认：选型草稿就绪后，现有单次预计在规则判定有效的候选范围内起草耗材清单、数量理由与费用。手术页把带出处的选型参数、耗材清单和费用放在同一审阅区，医生修改后确认一次，同一共享 Command 原子完成选型确认（含认可的候选）、术前清单快照与整批预留。
- 费用与医保说明：单次预计与持续跟进的耗材建议同时提供确定性费用块和 AI 自然语言说明。费用块列出本次住院预计总费用的组成（已发生正式收费含造影、待执行医嘱、剩余计划耗材、计划手术费）、当前正式分组、若计划手术实施的推演分组、对应医院支付参考及差额。数值全部由既有 DRG 推演计算；AI 只依据这些数值说明费用位置，不产生金额。
- 特例提醒：沿用既有规则，仅当已发生正式收费净额严格大于当前有效 DRG 医院支付参考的 3 倍时出现；不显示与阈值的距离，不用计划或预留金额判断。
- DRG 不可用不阻断耗材建议：分组规则未启用、分组未完成或病组缺少支付参考时，耗材建议照常生成，医保说明替换为对应的自然语言原因；持续跟进的模型分析不再把这三类 DRG 状态作为前置缺项。
- 造影阶段支付参考：为当前规则下仅完成造影时得到的病组（合成规则为 FM59）补充合成医院支付参数，使只做造影的阶段也能说明支付参考。参数仍是标明合成的独立身份，不代表任何地区真实点值。
- 术中实时费用板：术中逐笔登记耗材后，页面按规则即时显示每类计划量、已用量与剩余量，计划外或超出计划的使用及其对本台耗材费用、住院预计总费用和支付参考差额的影响。术中不自动调用模型；用户主动请求时才生成解释。
- 术后差异不依赖跟进：手术完成后，计划与实际用量差异（超出计划、计划内未使用、计划外产品）和耗材及术式收费净额不一致，随当前正式事实直接显示并生成对应岗位待办，无需先开启持续跟进；模型解释按需请求。
- 原记录入口：术后待办和差异项显示手术、材料、计划量、实际量及收费差异，并提供当前岗位有权进入的原手术、收费或首页入口，替代只显示资源标识字符串。
- 指南依据说明：保存有效 PCI 计划后，同一次单次准备意图同时准备只读的指南参考意见，解释支架类别、IVUS／OCT 指导条件和测量要求，并给出指南名称、版本、物理页与原句。已有报告带入的测量时据此说明；没有造影报告或测量不全时，给出有条件的类别说明和具体缺项。首期只接入经过原文核对、版本固定的“PCI 支架类别与尺寸核对”专题导航，再回读现有指南库原文。
- 缺项与失败使用自然语言：AI 建议、费用说明与核对区域不向用户显示原始错误码；加载、处理中、部分资料不足、模型不可用、核验拒绝、失败与结果未知分别表达。

## 用户故事

1. 作为住院医生，我希望造影完成后开 PCI 计划时选型参数已经按报告填好并注明出处，以便只核对而不重复录入。
2. 作为住院医生，我希望在一个界面里审阅参数、AI 起草的耗材清单和费用并确认一次，以便同时完成选型认可、清单确认和预留。
3. 作为住院医生，我希望看到本次住院总费用由哪些部分组成、当前及计划实施后的病组和医保支付参考差额，以便在给定方案内了解费用位置。
4. 作为住院医生，我希望 DRG 规则未就绪时仍能拿到耗材清单，并知道医保说明缺在哪里，以便不因医保配置耽误手术准备。
5. 作为术者或记录耗材的护士，我希望每登记一笔耗材就看到用量与费用的变化，以便当场发现计划外使用及其费用影响。
6. 作为医生或收费员，我希望术后不必事先开启跟进也能看到属于自己处理的用量或收费差异，并直接进入原记录更正。
7. 作为住院医生，我希望看到选型对应的指南名称、版本、原文和页码，并区分指南范围与有限合成演示范围，以便核对适用条件。
8. 作为住院医生，我希望没有造影报告或测量不全时仍能看到有条件的类别说明和具体缺项，以便知道还要补什么。

## 验收条件

- [ ] C1：固定 PCI 病例完成诊断性造影后，本次住院出现一份关联该造影 Procedure 的正式造影报告，含靶血管部位、病变长度、近端与远端参考管腔直径、方法及合成标识；同一造影重放、刷新、重启不重复生成。生成过程不调用模型，医生、Agent DTO、Page Context 与模型载荷均不包含 Case Truth 本身。
- [ ] C2：Case Truth 缺少造影所见或字段不完整时，报告状态明确为无法生成或部分缺项，不以默认值或病例作者底稿补齐。
- [ ] C3：已有造影报告时保存 PCI 计划，选型草稿的测量、靶部位与来源逐字段等于报告内容并绑定报告身份和版本；报告晚于计划到达时，在尚无医生确认的情况下补出草稿。医生已编辑或已确认的选型不被覆盖。没有造影报告时，选型保持现有手填流程并可完成全程。
- [ ] C4：选型草稿就绪后无需医生先确认选型，单次预计自动起草耗材清单；超出合成依据范围的测量或数量使对应候选显示不可用原因，不进入可确认清单。
- [ ] C5：医生在手术页一次确认后，选型确认、术前清单快照和预留在同一事务内全部成功或全部回滚；同一确认重放不重复预留，版本冲突返回可理解的刷新提示。
- [ ] C6：费用块显示本次住院预计总费用的组成、当前正式分组、计划实施推演分组、医院支付参考及差额，数值与 DRG 推演一致；AI 说明只引用这些数值，生成或核验失败时费用块仍可见。
- [ ] C7：DRG 规则未启用、分组未完成、病组缺少支付参考三种情况下，单次预计和持续跟进的耗材建议均照常生成；医保说明分别显示“医院尚未启用医保分组”“诊断或手术记录不全，暂时无法分组”“已分到某组，但暂无支付参考，金额暂不可估”含义的自然语言原因。
- [ ] C8：仅完成造影的阶段，当前规则得到的病组有合成支付参考并显示金额；参数身份标明合成，不影响既有 FM39 与其他病组参数和历史归档回读。
- [ ] C9：特例提醒只在已发生正式收费净额严格大于支付参考 3 倍时出现，恰好 3 倍不出现；不显示距离阈值的提示，计划、预留与草稿金额不参与判断。
- [ ] C10：术中每登记或更正一笔耗材，费用板即时显示每类计划量、已用量、剩余量，标出计划外或超计划使用，以及本台耗材费用、住院预计总费用与支付参考差额的变化；整个术中不自动产生模型请求，用户主动请求解释后才发起一次解释，生成与独立核验按实际请求计量，同依据复用结果。
- [ ] C11：未开启持续跟进时完成 PCI，超出计划、计划内未使用、计划外产品及收费净额不一致分别显示并生成医生或收费员待办；更正正式事实后自动复查并解决对应待办。开启持续跟进的病例不产生重复待办。
- [ ] C12：差异项和待办显示手术、材料、计划量、实际量及费用差异，提供当前岗位有权进入的原手术、收费或首页入口；收费员只看到财务差异与正式收费。
- [ ] C13：AI 建议、费用说明、核对及跟进区域的业务状态不以原始错误码呈现；加载、处理中、部分缺项、模型不可用、核验拒绝、失败与结果未知分别有可理解文字，结果未知不自动重发。这些状态的视觉呈现按 C15 沿用外壳规格。
- [ ] C14：standalone Web 与 DSH Surface 的上述审阅、费用板、指南依据和对话框在 React 18 与 19 下行为一致；宽度档位、主题与浮层检查沿用[外壳规格](2026-11-02-dsh-shell-feedback-redesign.md#外壳)。
- [ ] C15：本规格新增的 AI 产物按[外壳规格的助手呈现](2026-11-02-dsh-shell-feedback-redesign.md#助手呈现)与[交互反馈](2026-11-02-dsh-shell-feedback-redesign.md#交互反馈)展示，不另定样式：选型草稿、耗材清单、费用说明与指南参考意见计入住院医生患者头部的“助手已准备”行与页签“助手 n”，某一项未生成时写明是哪一项；一次确认使用操作栏的助手确认条与主按钮提交中、原位结果和下一步反馈；按规则带入或 AI 填写的字段带“助手”标记和“依据”入口。

### 指南依据说明

- [ ] G1：保存有效 PCI 计划后，无需开启持续跟进即可由同一次单次准备意图准备指南参考意见；重放、刷新、重新登录和同库重启不重复创建准备或重跑仍有效的成功步骤。页面切换、转科、撤权、取消计划、开始或完成手术与归档沿单次预计的生命周期停止或转为历史只读，晚到结果不写入其他病例或计划。
- [ ] G2：已有报告带入的测量时，意见针对这些测量说明类别与测量要求；缺少病变长度、参考管径、单位、具体候选或数量依据时，仍可基于有效原文给出有条件的类别说明和具体缺项。只有计划等有限资料时只给一般类别与测量说明，不声称患者已确认适用；读取失败与尚无报告分别表达。
- [ ] G3：每条发布的结论能回到本次实际读取的可用原文，显示名称、版本、物理页或章节及必要原句；生成和独立核验使用同一组固定原文与患者事实。专题摘要、目录页、参考文献页或模型自报来源不算依据。
- [ ] G4：支架类别、IVUS／OCT 指导和测长要求保留原文人群、条件、例外与推荐强度，不把“可以考虑”写成必须完成；合成方案的 3.0mm、5–16mm 与每类一件不标为指南要求。
- [ ] G5：没有可用依据时显示来源缺口或范围限制，不补造结论、规格或引用；类别说明不生成假 `materialId`、目录版本、价格、单位或默认数量。
- [ ] G6：页面分别表达“指南参考意见”“待确认耗材清单”和当前预留。意见只读，不能转成清单条目，不产生诊断、手术、预留或费用；一次确认只针对清单与预留，不要求逐条批准意见，新意见不覆盖人工稿。
- [ ] G7：正式资料、计划、目录或所用专题与原文变化时意见标为需更新，医生显式重评后才重新准备；单纯导航和同内容刷新不派发。来源撤回、替代、用途收紧或正文损坏时，依赖它的意见和原文停止展示与复用，但不冻结独立依据仍有效的人工清单。
- [ ] G8：加载、处理中、部分资料不足、无可用指南、模型不可用、核验拒绝、失败、取消、过期和结果未知分别表达；独立核验未通过的内容不发布。生成、核验、格式修复与显式重评复用既有模型执行、Accounting Guard、用量账和未知恢复，按实际请求计量。
- [ ] G9：公开 HTTP 与页面联合验收覆盖资料完整、缺关键测量或单位、超出合成演示范围、无适用来源及来源失效，至少包含血运重建指南支架类别、影像指导条件与 CVIT 测量原文的正例，以及把选择性建议变成强制检查、从目录反推测量、从类别推固定产品或数量的反例；研究脚本的命中数不能替代本验收。

## 设计决定

- 测量值来自仿真侧生成的结构化造影报告，按规则逐字段复制进选型草稿，不用模型读取报告或推断缺项。理由与替代方案见 [Agent Note](../decisions/proposed/architecture/2026-11-02-inpatient-ai-usability.md)。
- 造影报告由仿真侧读取 Case Truth 生成，与检验报告使用同一隔离边界：报告成为本院正式事实后才可被医生和建议模型读取，Case Truth 与病例作者底稿不进入建议模型。
- 医生的唯一确认同时代表认可候选与确认清单；无造影报告的手填路径保留现有两步合同，不强制迁移。
- AI 的费用说明以确定性 DRG 推演为唯一数值来源；AI 不建议减少必要耗材、更换尺寸、增加器械或修改诊断与主操作，不以医保差额影响临床选择。
- 同类耗材只保留当前每类一个已核验候选；“同类换更低价产品”的比较不在本需求内。
- 术中以规则计算的费用板替代逐笔自动模型请求；持续跟进保留开启、停止与后台按需分析的既有合同，本需求不移除它。
- 术后用量与收费核对复用 `drgReview` 的判定与 `materialPlans` 的计划依据，改为随正式事实直接计算；待办处置、复查和交接沿用现有合同，不另建第二套判定。
- 与 [DSH 外壳、交互反馈与助手呈现规格](2026-11-02-dsh-shell-feedback-redesign.md)（[#372](https://github.com/CaiZongyuan/clinmesh/issues/372)）分工：外壳规格拥有顶栏、主卡结构、操作栏、助手行、助手标记、确认条、提交与成功反馈、宽度档位和浮层；本规格只定义住院 PCI 各 AI 产物的内容、业务状态、数据来源与服务端合同，不重复规定布局和样式。外壳规格中住院医生助手行列出的“耗材预计”状态由本规格的单次准备结果提供。

### 指南参考意见与具体清单分开

参考意见表达有条件的临床说明，具体清单表达真实目录产品、规格和数量；二者在同一次单次准备中分别描述就绪、缺项和所依赖的依据，参考意见失效不冻结独立依据仍有效的清单。不把类别意见塞进要求真实产品和正整数数量的 `items`，也不为通过校验解除正式确认的候选、数量、目录与预留检查。理由与替代方案见[指南参考意见 Agent Note](../decisions/proposed/architecture/2026-11-02-inpatient-pci-guideline-advice.md)，研究依据见[指南适用性](../research/2026-11-02-inpatient-guideline-applicability.md)与[LLM-Wiki 评估](../research/2026-11-02-llm-wiki-for-inpatient-guidelines.md#两专题的实际取证对照)。

### 专题导航与原文取证

首期由 PCI 计划定位唯一的[支架类别与尺寸专题](../research/topics/pci-stent.md)，不增加通用意图分类、自动扩展主题或运行时改写 Wiki。专题区分直接条款与操作性归纳，每条依赖固定来源身份、版本、哈希与定位，使用前检查来源及正文可用性；研究 Markdown 纳入产品前需核对引用、人群、例外与适用范围。专题与回读的原文共同受现有最多八段、48 KiB 证据预算约束，专题自身计入预算；无法在预算内保留关键条款及限定语时明确不完整，不截断后假装核验完成。

## 范围外

- 对比剂专题接入、其派生正文修复及水化或剂量建议。
- 真实品牌 IFU 收集、器械兼容引擎、一般化选径或数量算法。
- 全量指南 Wiki、知识图谱、向量服务、独立知识平台、全自动知识编译与自动冲突裁决。
- 改变 PCI 适应证、治疗方向、诊断、术式、主操作、DRG 或医保支付；按费用目标反推治疗和材料。
- 扩充同类耗材候选或在同类产品间按价格比较。
- 对药品、检查、床日等非耗材费用提出节省建议。
- 从自由文本报告、影像像素或手术设备提取测量；造影影像与阅片。
- 造影报告的人工更正入口；选型来源已绑定报告版本，增加更正时沿依据失效规则处理。
- 移除或重构持续跟进任务；术后自动解释在已开启跟进时的既有行为。
- 显示与特例阈值的距离或按预计金额提前预警。
- 真实地区医保点值、患者医保待遇测算及真实模型医学准确率评估。

## 依赖与风险

- 页面部分与 #372 修改同一批住院工作台文件（患者工作区、助手行、操作栏），在 #372 合入后实施；服务端与合同部分不受此限制，可先行。
- 正常演示与回归路径改为先造影再 PCI，现有直接开 PCI 的测试夹具和黄金旅程需要同步；手填路径保留以免既有病例失效。
- 新增或合并的 Command 若进入 Agent-facing CLI，需要在同一改动中更新 Operation Catalog、对应 `clinmesh-*` Skill 与命令示例漂移测试。
- 造影报告进入 FHIR 时只能声明实际实现的资源与检索能力（R5 `5.0.0`）。
- 部署默认不启用 DRG 规则，医保说明在默认环境中会显示“尚未启用医保分组”；这是预期降级，不是故障。
- 合成选型依据仅覆盖单病变、固定管径和每类一件；Case Truth 中的造影所见须落在该范围内，范围外病例只能用于反面测试。
- 支架专题取证的原件以 2021 版本为主，未完成现行版本全集核查；部分原件注明未比对后续终稿。专题是派生内容，可能遗漏限定条件，必须核对具体条款并沿来源失效关系停用。真实模型的医学质量尚无本需求证据。
