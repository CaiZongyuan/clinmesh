# 术后补登记漏记耗材

Status: implemented

## 问题与目标

手术完成后，住院医生可以在「更正耗材」中撤销、修改数量或替换已有耗材记录，但无法独立新增一笔漏记的实际使用。术中「登记本笔使用」在完成手术后隐藏，服务端也只允许对进行中的手术追加使用。因此，术后发现遗漏另一种耗材时，现有更正流程无法补齐实际使用和对应费用。

目标是允许医生为原已完成手术补登记真实漏记的耗材，明确补登记性质与依据，保持手术完成状态、原记录及审计可追溯，费用只按新补记的实际使用增加一次。

## 范围

- 在住院医生的已完成手术耗材区域提供明确的「补登记耗材」入口，覆盖 standalone Web 与 DSH Surface。
- 补登记引用原住院、原手术执行和受信岗位身份，选择本院可用耗材、数量并填写补登记依据；支持此前未登记过的耗材，也支持同一耗材另补一笔实际使用。
- 仅允许患者仍在院、账户未结算且病案未归档时补登记；离院未结算也不能补登记。
- 复用共享 Command、计费、预留及审计 owner；既有撤销、改数量和替换记录继续使用更正流程。

## 用户故事

1. 作为住院医生，我希望在手术完成后，为漏记的球囊补登记一笔实际使用，以便临床耗材记录与费用一致，而无需修改一笔无关耗材或重新完成手术。

## 验收条件

- [x] 已完成手术允许按基础范围独立补登记一种此前未出现的耗材，不要求引用或替换某一笔已有使用。
- [x] 同一耗材允许另补一笔漏记使用；界面清楚区分「新增使用」与「更正原记录」，不诱导通过改数量替代所有补登记。
- [x] 提交前展示所选耗材、数量、计费依据和新增费用，缺少有效选择、正整数数量或补登记依据时不能提交。
- [x] 成功后最终耗材汇总和当前费用包含新增使用，手术仍为已完成；原使用记录和原完成事实保持可追溯，历史标识补登记、登记人、登记时间及依据。
- [x] 重复提交、请求回执丢失后的恢复和并发变更不产生重复使用或重复收费；冲突与失败可见，输入保留，刷新后可核对正式结果。
- [x] 若涉及原预留，系统明确展示其适用性及处理结果，不能重复计入预计与实际费用，也不能默默重新占用已释放或失效的预留。
- [x] 无权限、跨患者或跨手术、已结算、已归档状态被服务端拒绝，界面给出相应原因；不通过补登记改写已冻结账务或病案。
- [x] 补登记后相关费用与术后核查能够反映新的实际使用，旧分析需要重核时有明确状态；不依赖真实模型调用才能登记。
- [x] Web 与 DSH Surface 从真实入口完成漏记一种新耗材的补登记及刷新回查，既有耗材更正流程继续可用。

## 设计决定

在原耗材弹窗中并列提供补登记与已有记录更正；补登记使用独立的 `inpatient.surgery.supplement-material` Command，原术中登记合同保持不变。补登记按当前有效本院目录及所选版本冻结耗材，显式消耗仍有效的预留时沿用原预留冻结单价；已释放或耗尽预留不可重新消耗，只能另记额外使用。提交携带当前申请版本、可选预留版本及已审阅的收费定义身份、单价和单位，服务端只核对这些计费断言，不接受客户端指定收费金额。补登记不重新开启手术，不借另一笔耗材的更正制造新增使用。取舍见[术后补登记决策](../decisions/implemented/feature/2026-11-09-postoperative-material-addendum.md)。

## 测试策略

使用合成患者、临时 SQLite 和受控 Provider，从公开 Command 验证补登记新耗材、同耗材新增一笔、收费一致、幂等恢复、并发冲突、权限隔离和冻结边界。前端验证输入、预览、错误恢复与成功刷新，Playwright 覆盖 Web 和受影响的 React 18/19 DSH Surface 真实入口。若 Agent-facing CLI 或错误恢复合同变化，同一 diff 更新 owning Operation Catalog、运行时 Skill 与漂移测试。

## 范围外

- 真实库存出入库、供应链、采购及平台收费渠道接入。
- 已结算或已归档后的临床耗材追加，以及重新打开手术或篡改原完成记录。
- 扩大既有 AI 自动执行或新增真实模型运行。

## 依赖与风险

复用当前术中登记与耗材更正能力，相关实现跟踪见 [术中逐笔登记](https://github.com/CaiZongyuan/clinmesh/issues/333)。[住院医生站减负](https://github.com/CaiZongyuan/clinmesh/issues/400)拥有弹窗展示的独立范围，本规格不反向扩大该票验收；实施复用其已完成入口。主要风险是补登记与更正语义混淆、收费重复、过期目录或预留被误用，以及冻结后的历史被改写。
