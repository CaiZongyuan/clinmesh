## 可用条款

| 官方条款 | 正文要求 | 可支持的检查及边界 |
| --- | --- | --- |
| [第三条][2010-text] | 病历书写应当客观、真实、准确、及时、完整、规范 | 支持核对事实与完整性的方向；未规定 Agent 的算法、问题等级、操作按钮或软件签署门禁，不能用该条证明模型判定必然正确 |
| [第八条][2010-text] | 按规定内容书写，由相应医务人员签名；实习、试用期医务人员所写内容需注册医务人员审阅、修改并签名 | 签名属于正式完成文书的合同。未签署的编辑草稿不能仅因没有签名就持续报告一个尚未到期的缺项；沿用既有签署与身份校验，不让 Agent 代签 |
| [第十一条][2010-text] | 门（急）诊病历包括首页或手册封面、病历记录、化验单、医学影像检查资料等 | 文书完整性不是正文单字段完整性；已有报告可以保存在关联资料中，不能据此要求每份报告全文复制进正文，也不能解释成所有患者都必须做检验和影像检查 |
| [第十二条][2010-text] | 首页包括姓名、性别、出生年月日、民族、婚姻状况、职业、工作单位、住址、药物过敏史等；手册封面包括姓名、性别、年龄、工作单位或住址、药物过敏史等 | 首页与手册封面是两种列举，不能将两份清单叠成每份正文必填。药物过敏史有直接条款依据，但应检查所属记录位置；未记录、尚未询问与明确否认过敏必须区分 |
| [第十三条：初诊][2010-text] | 就诊时间、科别、主诉、现病史、既往史，阳性体征、必要的阴性体征和辅助检查结果，诊断及治疗意见和医师签名等 | 可形成初诊病历章节与关联元数据的完整性清单。“必要的阴性体征”需要临床适用性判断；本条没有要求每名门诊患者都填写住院入院记录的全套系统查体或完整生命体征 |
| [第十三条：复诊][2010-text] | 就诊时间、科别、主诉、病史、必要的体格检查和辅助检查结果、诊断、治疗处理意见和医师签名等 | 复诊使用其自己的清单。本条没有逐项要求重新撰写初诊的现病史、既往史，也没有允许把已知且与本次就诊相关的重要事实从复诊记录中遗漏 |
| [第十三条：急诊时间][2010-text] | 急诊就诊时间具体到分钟 | 仅适用于急诊；不能据此新增所有普通门诊正文的分钟级时间必填 |
| [第十四条][2010-text] | 接诊医师在患者就诊时及时完成门（急）诊病历记录 | 支持诊疗进行中提示待补内容、签署前集中核对；没有要求问诊第一句话后草稿立即齐全，也没有给出自动阻断签署的软件规则 |
| [第十五条][2010-text] | 急诊留观和门（急）诊抢救记录有额外要求，抢救记录按住院抢救记录要求书写 | 属于特定急诊场景，不能把抢救记录、患者去向、留观过程等字段变成普通门诊全员必填 |

第三章第十八条详细定义主诉、现病史、既往史和系统体格检查，但条款标题及适用对象是“入院记录”。其主诉持续时间、发病地点、完整系统查体等内容可用于理解医学概念，不能未经门诊适用依据与产品确认就全部提升为普通门诊确定性缺项。[同一官方全文][2010-text]

## 从条款到可执行提示

以下为研究建议，不是已经批准的实现要求。

1. 结构检查可以确定某个适用章节是否为空、关联就诊时间或科别是否存在。先合并正文与所属元数据的证据，避免要求医生在正文重复登记已存在的信息。字段非空只能证明有内容，不能证明所写内容足够或真实。
2. 正文语义检查可以提示“未找到既往史记录”“已出具的相关报告结果可能尚未记录”“请核实必要查体是否已记录”，并给出检查位置和条款。它不能仅因“查体正常”“已告知”非空就确认全部质量要求通过，也不能无适用性依据列出所有正常体征供医生填空。
3. 辅助检查尚未安排、尚未出具、已有结果但与当前记录无关，必须与已知相关结果遗漏区分。条款不授权补造“检查正常”，也不授权为补齐病历而额外推荐诊疗项目。
4. 初诊与复诊需可信的文书或就诊上下文。第十三条没有定义如何由 Encounter 数量自动推导；不能直接将“首次使用系统”“本院没有历史数据”或“当前就诊第一次保存草稿”当作初诊，也不能把首诊负责制度与初诊文书类型混为一谈。上下文不足时应说明无法确定适用清单。
5. 草稿阶段的未完成内容是待补提示，正式完成时的要求由现有提交校验承担。新增质控不阻断签署属于本项目已确认的产品边界；不要把它写成国家规范明确允许忽略文书要求。模型提示也不能覆盖原有签署门禁。

需要防范的误报包括：复诊误套初诊全清单；关联元数据或既往记录已经载明的信息被要求重复录入；无检查结果被判为“缺辅助检查”；对不适用的阴性体征提出全员必填；就诊进行中的合理未完成状态被标成违规；只因一句表述没有命中关键词就断言没有记录。缺少资料时可以提示核实，不能自动改写成“无异常”“无过敏”或“患者否认”。

## 对四项质控的意义与未决点

“缺项”可以引用上述适用条款；“已知信息遗漏”需要当前医生可见的问诊、补充信息和相关报告证据；“事实不一致”需要核对对象、原文、时间与语境；“Agent 新增事实缺少来源”需要校验真实来源与内容支持关系。第三条为客观、真实、完整提供一般方向，但没有规定这四项分类，也没有将模型输出本身授权为事实依据。不同时间的症状变化或检查结果变化，不能仅因词面不同就标成矛盾。

尚需产品明确：首期采用初诊、复诊中的哪些适用内容，是否包含首页药物过敏史，以及缺少文书类型上下文时如何呈现。条款依据、适用条件和推荐实现应分别保存，研究记录不自行把候选规则升级为正式规格。
