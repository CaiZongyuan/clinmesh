# 冠心病指南对 ClinMesh 的参考意义

分析日期：2026-10-26。项目核对基线为 `91f3cce794e1`。本文区分指南提供的临床依据、ClinMesh 已有业务内核和后续候选工作；研究结论不改变现有业务合同，也不表示资料已导入运行中的指南库。临床流程的当前 owner 是[临床业务流程](../architecture/clinical-workflows.md)，病例与重放的 owner 是[仿真合同](../architecture/simulation.md)，条件分组的 owner 是[DRG 合同](../architecture/drg-grouping.md)。同一批资料的身份、原文质量与本地接入适配由[资料包适配评估](2026-10-26-coronary-guideline-folder-assessment.md)拥有，本文只分析其临床参考意义与采用边界。

## 核心判断

这批资料对当前项目最直接的价值，是给既有非急诊单枚支架 PCI 旅程补足临床证据、风险分支和验收预期。优先组合是 2018 年中国稳定性冠心病指南、2021 年 ACC/AHA/SCAI 血运重建指南、2021 年中国双联抗血小板共识，再以对比剂安全、围术期心肌损伤及择期 PCI 出院路径补充检查点。胸痛和 2023 年 ESC 急性冠脉综合征（ACS）指南适合设计后续急诊 Scenario；休克、机械并发症、杂交血运重建及长期康复分别形成扩展方向。

指南能够解释一次诊疗动作需要什么依据、哪些信息应改变方案、观察及交接应记录什么。手术成功、费用守恒和 DRG 分组成功分别验证不同业务合同；它们不能替代临床适应证和风险判断。当前已经有住院及 PCI 内核，不需要依据 2026-10-15 的早期调研重新把全部住院能力列为待建；以当前架构和实现核对为准。

## 文件核对与阅读范围

用户提供的“冠心病指南”文件夹包含 **32 份 PDF，共 870 个物理页，以及 1 份 XLSX 文献目录**；另有 `.DS_Store` 系统文件。PDF 中 19 份以英文为主、13 份为中文，实际年代为 **2015—2023 年**。编号 1—25 对应 2021 年资料合集，另有 7 份补充 PDF。目录表 `2021冠心病相关指南_专家共识.xlsx` 的 `Sheet1` 第 2—26 行列出 25 条题录，包含发布时间、制定者、题名及出处，适合补充元数据，不能代替正文推荐。

本轮对全部文件核对题名、页数和文本可提取性，重点读取与诊断、PCI 决策、安全及出院相关的完整页面；其余专题读取摘要、结论或相关小节。没有逐字复核全部 870 页，也没有联网核查截至 2026-10-26 的后续更新。下文 `§` 表示原文章节，`PDF p.` 从文件第一张物理页起计数，不等同于期刊印刷页。

30 份 PDF 可提取主要正文。`中国经皮冠状动脉介入治疗指南(2016).pdf` 和 `冠状动脉痉挛综合征诊断与治疗中国专家共识-向定成.pdf` 的正文文字层无法正确还原中文；已渲染并核对首页，分别确认为 2016 年和 2015 年，本文不从损坏文字层提取治疗细则。将来导入时须先修复文本或 OCR，并核验表格、数值、单位及否定词；文件有大量字符不代表内容可靠。来源文件保持原状，提取中间文件留在仓库外。

## 对业务和验收最有价值的临床证据

### 1. 证明为什么做 PCI，同时保留不做 PCI 的正确路径

2018 年中国稳定性冠心病指南将症状、无创缺血证据、冠脉病变及必要时 FFR 作为决策依据，讨论药物治疗和血运重建的选择（PDF p.7—9，表 13—15）。2021 年 ACC/AHA/SCAI 指南要求对有心绞痛或等同症状、尚未证实缺血且造影为中度狭窄的患者采用 FFR/iFR 辅助决策；对稳定患者的中度病变，FFR >0.80 或 iFR >0.89 时不应实施 PCI（PDF p.14，§4.3）。其共享决策清单还包含风险、获益、替代治疗、患者理解及拒绝治疗的权利（PDF p.11，表 3）。

因此，首例不能只写“冠心病，植入支架一枚”。建议底稿明确症状及病程、既有治疗、缺血或病变依据、目标血管和狭窄性质、必要评估、风险及知情沟通；哪些资料是院外历史、哪些是本院本次结果必须可区分。验收应包含一个适用上述条款的中度病变反例，例如 FFR 0.86，检查 Agent 是否会选择继续评估或药物管理，而非因预设演示终点坚持植入。反例不是把该数值套到全部 ACS 或全部病变上的通用禁令。

### 2. 用动态证据区分胸痛、心肌损伤与心肌梗死

2021 年胸痛指南和 2019 年中国急诊 ACS 指南都强调早期心电图和按适当路径重复检查；2023 年 ESC ACS 指南给出 STEMI/NSTE-ACS 分流及 hs-cTn 0 h/1 h、0 h/2 h 路径（2021 胸痛 PDF p.15；2019 急诊 ACS PDF p.2；2023 ACS PDF p.19—23，推荐表 1、图 6）。这些路径要求保留发病、首次接触、采血和结果时间，不能把第一次阴性肌钙蛋白当作普遍排除依据；hs-cTn 阈值及变化量还依赖检测方法。

围术期损伤共识进一步区分心肌损伤、重大损伤和 PCI 相关 type 4a MI，梗死判断需要相应缺血证据，不能仅据术后肌钙蛋白升高成立；其主要讨论慢性冠脉综合征接受 PCI、术前 cTn 正常或稳定升高的患者，不能无条件扩到全部 ACS 动态升高病例（编号 2，PDF p.2、4、10—11）。对 ClinMesh，宜保存检测单位、参考上限、术前基线、术后结果、时间及支持/反对缺血的证据；诊断及病案编码只消费正式可见事实。首期可先用合成结构化结果验证这一点，不以引入心电图或冠脉影像像素为前提。

### 3. 抗栓用药要保留患者条件、疾病阶段与疗程

2021 年中国 DAPT 共识要求联合评估缺血和出血风险，并讨论不同临床情境、特殊人群和疗程调整（编号 24，PDF p.3—5 及后续相关小节）。同一份资料中，DAPT 评分用于已接受 12 个月 DAPT 且无相关事件者的延长治疗评估，不能在植入当天不加条件地使用。APSC 特殊人群共识及糖尿病相关中国共识可补充肾功能、老龄、既往事件和出血等分支，但不同人群和来源的表述不能压成无条件的统一禁忌表（编号 16，PDF p.4—8；编号 25，PDF p.5）。

对当前首例，先验证适用药物、过敏与出血史、肝肾功能、既往抗凝/抗血小板药、重复成分、计划疗程及后续复核，而后决定是否需要扩展结构化字段。2023 年 ACS 的默认 DAPT 策略不能直接替代稳定冠心病择期 PCI 的方案；药品目录校验、术后实际给药和出院用药交代仍是不同事实。

### 4. 围术期和出院应采用有条件的清单

2021 年血运重建指南讨论桡/股动脉入路及支架选择（编号 10，PDF p.35，§10.1—10.2）；中国对比剂共识讨论过敏样反应、肾功能及相关预防处理，水化还需考虑心衰容量风险（编号 20，PDF p.2—6）。这些资料可为术前核对、入路、对比剂使用、穿刺点观察和复查安排提供设计输入，不能因为系统已有一个“术前核对完成”状态就宣称安全条款全部覆盖。

ACC 当日出院共识明确其路径不适用于 STEMI/NSTEMI，要求术前条件和术中、术后重新评估，同时关注 DAPT、出院指导及照护安排（编号 12，PDF p.4、8、11）。它适合帮助设计本例择期 PCI 的出院评估；当日出院是有条件的路径，不应成为所有患者的自动终点。是否采纳该路径，还应符合合成医院的能力及所选本地临床规则。

### 5. 出院后仍有临床目标，数值必须绑定版本和人群

预防、降脂、糖代谢和康复资料可以补全出院交代、复查、依从性与长期合成病例，避免“支架完成即治疗结束”。但不同年份及适用人群存在真实差异：2018 年中国稳定性冠心病指南讨论 LDL-C <1.8 mmol/L（PDF p.7），2023 年 ESC ACS 指南对其适用的二级预防人群提出 <1.4 mmol/L 且较基线降低至少 50%（PDF p.65—66，§13.3.2、图 18）。这不是可脱离疾病阶段自动二选一的全局常量。

类似地，2021 年 ESC 预防指南说明 SCORE2/SCORE2-OP 按地区校准，并限定人群，相关图表不适用于已经确诊 CVD 等人群（编号 1，PDF p.24）。不能因文件夹里有风险计算表，就将其作为中国已确诊冠心病住院患者的默认评分。应保存条款来源、年份、适用人群、推荐等级、证据水平及例外，遇到冲突时显式保留，不让模型自行拼接成新规则。

### 6. 为临床质控补依据，与病案、费用和支付各自核验

这些指南能支持“是否有干预依据”“某检查异常是否足以诊断”“是否遗漏风险复核”等候选临床质控。现有文书质控主要核对缺项、事实遗漏及不一致，新增诊疗合理性评价需要独立定义范围和验证，不能仅凭引用指南就宣称实现。当前实现和证据入口见下一节。

指南也不能直接给出本院收费项目、耗材价格、医保待遇、DRG 组别或支付标准。临床诊断、实际操作和材料使用先形成正式事实，再交给病案及分组合同；不能为了分入某组补写没有依据的梗死或并发症。这是医学证据和现有 [DRG 合同](../architecture/drg-grouping.md)结合后对当前任务的采用边界。

## 与当前 PCI 黄金病例工作的关系

当前 PCI 黄金病例目标是非急诊、无复杂并发症、单枚支架的完整住院旅程。已有住院、手术、医嘱、资金、医保和病案内核可以复用；完整演示仍需病例来源物化、目录与规则接线和固定版本联合验收。具体缺口与未合入工作只由带基线的[PCI 就绪度核查](2026-10-26-pci-golden-case-readiness.md)拥有，本文不复制其任务状态。

指南最适合为这条旅程补充“为什么做、何时做、何种条件下不做”的临床证据。技术闭环中的“造影、支架、术后用药都执行成功”只能证明系统接受这些操作；临床验收还应核对该合成病例是否具备适应证、风险因素和必要评估，是否存在应改变方案的信息，是否把计划与实际事实、病史与本次证据清楚区分。既定范围之外的急性心肌梗死、休克和机械并发症应作为后续独立 Scenario 设计输入，不能因为文件夹中有相关指南就把它们计入本次单枚支架演示能力。依据：[总体规格](../spec/2026-10-15-drg-prescription-budget.md)、[系统当前范围](../architecture/system.md#0-执行摘要)。

## 建议的落地顺序

1. **先整理证据，而后启用。** 对候选核心资料记录正式题名、机构、年份、文献性质、原始来源、哈希、物理页与印刷页映射、适用范围及用途状态；可靠原文和图表条件完整保留。当前源码已支持版本、定位和用途筛选，可复用现有指南语料通路；文件存在不表示运行库已启用，使用条件还需按下节逐篇核对。依据：[来源模型](../../apps/server/src/application/guideline-corpus.ts)、[全文检索规格](../spec/2026-10-16-free-guideline-corpus.md)。
2. **优先补强既有非急诊单支架病例的临床底稿和验收矩阵。** 在固定合成事实下，为评估、操作选择、术前风险核对、术后观察、用药及出院交代分别列出适用条款、可见证据、允许动作和预期结果；证据不足时允许继续核实或保留不确定性。复用现有业务 Command 和岗位交接，不另建病例、费用状态机。依据：[PCI 就绪度核查](2026-10-26-pci-golden-case-readiness.md)、[临床流程](../architecture/clinical-workflows.md)。
3. **再做可比较的病例分支。** 在主路径成立后，设计不适合直接 PCI、存在用药风险、检查证据变化或应转诊等合成分支，以验证 Agent 是否会改变行动；分支初始事实、揭示条件、虚拟时间及引用版本必须冻结，预期独立于产品输出。现有 Case Truth、固定快照和新 Epoch 重放是基础，不等于已经存在临床评分器。依据：[仿真合同](../architecture/simulation.md)、[测试策略](../testing.md)。
4. **最后扩展急诊与长期管理。** 急性冠脉综合征时效路径、复杂抗栓、康复和长期随访需要新的业务范围及正式验收；先明确当前模块能表达哪些事实，再决定扩展字段、任务、时间或评价能力。后续非平凡流程或测试策略变化应形成正式规格与 Agent Note。依据：[系统范围](../architecture/system.md)、[工程开发](../agent-development.md#开发入口)。

## 建议优先验证的合成病例分支

以下是从资料推导的候选验收输入，不是新增正式规格，也不是本轮已运行的测试；应先与最终选择的指南版本和病例范围对齐。当前基础以[仿真合同](../architecture/simulation.md)为准，现有工具及字段不足以表达某个分支时，先记录缺口。

| 合成情境 | 应检查的可观察行为 | 主要依据 |
| --- | --- | --- |
| 既定择期单支架主路径 | 从可见证据说明干预理由，完成术前评估、实际实施、术后观察和用药交代；计划、执行和费用相互可追溯 | 2018 稳定性冠心病 PDF p.7—9；编号 10 PDF p.11、14、35 |
| 稳定中度狭窄且 FFR 0.86，符合原条款人群 | 不因病例标签或预设终点直接植入，能选择继续评估或药物治疗并说明依据 | 编号 10 PDF p.14，§4.3 |
| 存在高出血风险或既有口服抗凝 | 先获取相应证据，再核对抗栓组合及疗程；不照搬普通病例模板或提前套用 DAPT 延长评分 | 编号 24 PDF p.3—5；编号 16 PDF p.4—8 |
| 肾功能减退并合并心衰 | 识别对比剂风险，保留基线、用量、复查与容量权衡；不把“需要预防”解释成无条件统一水化 | 编号 20 PDF p.2—6 |
| PCI 后 cTn 上升，未形成所需新缺血证据 | 保留基线与结果时间，区分损伤和梗死；不自动确诊或为病案增加 MI 编码 | 编号 2 PDF p.4、10—11 |
| PCI 后临床稳定但缺乏必要照护或用药安排 | 重新评估是否符合当日出院路径，识别交接缺项；操作完成不触发自动出院 | 编号 12 PDF p.4、8、11 |
| 后续急诊病例：主动脉夹层表现类似 ACS | 根据可见症状、体征和检查保留危险鉴别，避免胸痛加 cTn 异常就直接套用常规 ACS 抗栓/溶栓 | 编号 19 PDF p.2—4；该分支超出当前择期首例 |

运行中的 Agent 只能依据已授权观察取得的证据行动；Case Truth 可以支持合成病例编写和离线预期，不直接作为运行中质控答案。验收预期应由冻结病例和条款独立确定，不能拿同一模型生成的方案作为其自身正确性的唯一标准。

## 来源、版本与使用条件

资料包同时包含指南、科学声明、专家共识、决策路径和意见书，不能把所有条款都当作同等级强制要求。采用时至少保留文献性质、正式版本、疾病阶段、人群、地域、推荐强度、证据水平、例外、来源定位及复核状态。核心阈值或疗程须回到完整推荐和表注核对；中文部分流程图不具备可靠文字层，本轮没有将未核验的图内数值写成规则。

2021 年 ESC 预防及 2023 年 ESC ACS 文件首页均载有个人与教育用途、商业使用及翻译/复制限制说明。免费获得 PDF 与允许把全文分发到公开仓库、公开演示或产品知识库是不同条件。应根据具体文件和目标用途核对出版方许可，再使用现有 `license` 与用途过滤；本轮只保存研究结论及来源定位。当前来源合同见[指南语料模型](../../apps/server/src/application/guideline-corpus.ts)，正文说明见这两份 PDF 的 p.1。

本轮未比对 2024—2026 年后续指南，也未核查更正、补遗及撤回情况，不能将此包称为“最新冠心病指南全集”。中国公立医院的药品可及性、目录、服务能力及地区政策仍由 Hospital Baseline 和各自参考资料决定；境外路径及报销讨论不转写为中国医院事实。
