Throwaway logic prototype · 合成高血压病例

一条 Synthea 数据，怎样变成可运行的中国医院病例？

下面不用抽象架构词堆叠，而是追踪同一名合成患者：从 FHIR R4 原始 Bundle 开始，经过代码识别、显式映射、本院目录选择和病例真值补全，最终安装成可离线重置的 ClinMesh Scenario Package。

这个原型回答的问题

Synthea 已经给了诊断、血压和历史用药，为什么不能直接装进 ClinMesh？中间每一步究竟增加了什么信息，哪一步失败会阻止病例运行？

先看一句话答案

Synthea 只提供“患者发生过什么”的美国临床素材。ClinMesh 还必须回答“这些代码在中国是什么意思”“本院能不能执行”“这次病例要揭示什么真值”，然后把全部答案冻结，运行时才不需要 Synthea、完整国家目录或外网。

七步转换总览

点击任一步查看真实数据形状。上方是“当前流水线进度”，下方代码区是“这一阶段的数据”。它不是同一个 JSON 不断加字段，而是不同责任的数据经过验证后组合。

五个引导场景

          
这些场景展示真正需要设计的边界：映射存在不代表医院可执行；新参考库发布不应改变旧 Package；上游离线也不应影响已安装病例。

        

        

        

          

            

            

            

          

          

        

      

    


    

      

        

          
同一个对象为什么有这么多层

          
以氨氯地平为例，RxNorm 药物概念、中国产品、本院可开药品和库存批次不是四种写法，而是四个不同问题的答案。

        

        

          
            
层次示例它回答什么为什么不能省略

          
          
            

              Synthea/RxNorm
              RxNorm 308136
amlodipine 2.5 mg tablet		
              来源病史里记录的是什么药物概念？
              保留来源语义和纵向病史，但不代表中国存在同一产品。
            

            

              中国参考产品
              drug-product:amlodipine-2p5-demo
页面使用合成演示 ID		
              中国目录中的剂型、规格、厂家和产品身份是什么？
              一个通用成分可能对应多个规格和厂家，不能直接成为处方项目。
            

            

              本院可开药品
              PH-HTN-AML-001
内科可开，单价 8.60 元		
              本院是否启用，怎样开，多少钱？
              国家存在的产品不等于本院采购或允许门诊开立。
            

            

              合成库存批次
              LOT-AML-SYN-001
数量 300，效期 2030-12-31		
              这次发药从哪个批次扣减？
              库存是医院运行事实，不能从国家目录或真实医院复制。
            

          
        

      

    


    

      

        

          
这条流水线明确不做什么

          
负面边界与正向流程同样重要。它们防止系统因为“看起来能匹配”而生成错误临床事实。

        

        

          

            不按显示名称静默映射
            
看到 “hypertension” 不能直接写成 I10。必须命中固定来源体系、版本和 code 的已审核映射。

          

          

            不把完整参考库装进运行医院
            
完整 LOINC、药品和国家服务目录留在 authoring 侧；运行库只安装这家虚构医院实际启用的解析结果。

          

          

            不让 LLM 编造检查结果
            
病例未定义的检查只能返回未建模、不可用或正常域受控采样，不能让对话模型自由生成医学真值。

          

          

            不把映射等同于可执行
            
即使 RxNorm 已找到中国药物概念，只要本院未启用对应药品，这次处方仍必须失败。

          

          

            不让新版本改写旧病例
            
参考库、映射或医院目录发布 v2 后，已安装 Package 继续绑定 v1 hash，reset 仍还原原始世界。

          

          

            不依赖运行时外网
            
NHSA、NMPA、NHC、LOINC 和 Synthea 全部离线时，已安装病例仍能问诊、检查、开药、收费、发药和重置。
