# CHS-DRG 3.0 官方规则、OpenDRG 资料包与完整条件核验

本文汇总国家医保局 CHS-DRG 3.0 与医保结算清单官方规范依据、`opendrg-public-data-2026-10-20.zip` 离线资料包核验，以及 ClinMesh 声明式分组引擎与上游程序的 13,784 例完整条件对照证据。现行运行时合同归 [`drg-grouping.md`](../architecture/drg-grouping.md) 与 [`drg-reference-storage.md`](../drg-reference-storage.md)。

## 一、国家官方政策与清单规范依据（2026-10-15 核验）

1. **CHS-DRG 3.0 发布与地方职责**：国家医保局《关于印发按病组和病种分值付费 3.0 版分组方案并做好落地实施相关工作的通知》（[医保发〔2026〕22 号](https://www.nhsa.gov.cn/art/2026/9/2/art_104_21975.html)，2026-09-02 发布，含 492 个 ADRG、825 个 DRG；[9 月 9 日配置信息公开](https://www.nhsa.gov.cn/art/2026/9/9/art_14_22070.html)及[9 月 12 日更正提示](https://www.nhsa.gov.cn/art/2026/9/12/art_14_22123.html)）要求省级保持与国家 ADRG 一致，各地结合本地历史费用测算权重、费率与机构系数。[新闻发布会实录](https://www.nhsa.gov.cn/art/2026/9/2/art_14_21978.html)明确病种支付标准是医保与医院结算标准（不同于患者报销待遇或医院真实成本），且严禁将其作为限额对医务人员考核或阻断必要临床救治。

<a id="医保清单诊断与手术操作"></a>

2. **医保结算清单、主要诊断与主要操作选择**：《医疗保障基金结算清单填写规范》（[医保办发〔2021〕34 号](https://www.nhsa.gov.cn/art/2021/8/30/art_140_8508.html)）含 193 项指标，诊疗信息源自病案首页但使用医保版诊断与手术操作编码（不能把病案首页直接等同于医保清单，参见[五问五答](https://www.nhsa.gov.cn/art/2024/11/29/art_14_14901.html)）。主要诊断须为导致本次住院的主要疾病（一般与主要手术一致；入院病情为 `4 无` 的院内新发并发症不作主要诊断）。主要手术操作优先填与主要诊断对应的最高风险/最高难度有创治疗操作（如已实施 PCI 支架置入 `36.0700` 时，不能因冠脉造影 `88.5500` 时间更早而将造影置于主操作；仅行造影时亦不得按既往史或计划补填支架）。

<a id="入院病情与-ccmcc"></a>

3. **入院病情四分类与 CC/MCC 排除**：清单“入院病情”固定为四值——`1 有`（入院已明确）、`2 临床未确定`、`3 情况不明`（含入院后新发现的高血压、高脂血症等慢性病，严禁填 `4`）、`4 无`（住院期间新发生），不能简化为美国 POA 布尔值。其他诊断是否触发细分组同时取决于 CC/MCC 表、同 CCE 排除组及目标 ADRG 是否设置并发症细分（例如国家版 3.0 冠脉支架路径 `FM39` 不按 CC/MCC 细分）。

## 二、OpenDRG 公开资料包核验（2026-10-21 / 2026-10-25 核验）

输入归档 `opendrg-public-data-2026-10-20.zip`（`47,369,362` 字节，SHA-256 `8aac49166dad394d3c6f2af2b298728363011d02859d6fca101f6c2b4851c33f`，采集自 [OpenDRG CE 演示站](https://www.opendrg.cn/demo/drg/ce/index.html)）独立复算全部 `2,300` 个文件哈希零差异，共 154 份数据集、`766,146` 条记录（61 个方案中 39 个含公开 JS 分组程序共 32 套实现，62 张支付病组表，65 张字典映射表）。

- **`chs_drg_30` 完整度与地区表缺口**：`chs_drg_30` 具备完整分组程序 `raw/3258.b47bba5f.js`、参数表 `groupers/chs_drg_30.json`（CC 6,337、MCC 1,581、CCE 21,036、有效操作 9,514 条）及 `payments/chs_drg_30.json`（825 组中 818 组有参考权重与费用，7 组缺失）；而 `zhejiang_2024` 仅有四张字典关联表且无完整分组程序或病组支付表，严禁跨方案拼凑成地方正式结算规则。
- **公开使用说明边界**：[OpenDRG 版权说明](https://www.opendrg.cn/blog/copyright.html)与[下载说明](https://www.opendrg.cn/blog/download.html)明示社区版保留版权声明可免费下载与私有部署；旧仓库 `DRG_JavaScript` 的 Apache-2.0 未包含 3.0 bundle，因此本机仿真审核依据其社区版公开说明与国家医保局配置公开说明，不冒称该 bundle 为 Apache-2.0（详见 [PCI 演示环境核验](2026-10-27-pci-drg-demo-enablement.md#来源用途)）。
