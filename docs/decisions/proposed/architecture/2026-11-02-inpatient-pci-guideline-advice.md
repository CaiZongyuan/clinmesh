# Agent Note: 住院指南参考意见与具体耗材确认分开

Status: proposed

## Problem

现有单次耗材预计以完整参数、具体有效候选和确定数量为前提；缺项会在模型派发前阻断整个准备。指南已经能支持的类别、测量说明与具体产品确认条件绑定，使医生难以在准备过程中获得帮助。当前具体材料输出也不能表达“类别有依据，但尺寸与数量未知”。造影报告带入测量后，正常路径的测量缺口减少，但医生仍看不到选型的指南依据，没有报告的手填路径也仍可能缺项。

需求与验收由[住院 PCI AI 减负规格](../../../spec/2026-11-02-inpatient-ai-usability.md#指南依据说明)拥有；测量来源与费用说明的取舍见[同规格的 Agent Note](2026-11-02-inpatient-ai-usability.md)。取证实验仅证明人工主题能帮助取得固定问题的原文，结果和限制见[研究记录](../../../research/2026-11-02-llm-wiki-for-inpatient-guidelines.md#两专题的实际取证对照)。

## Proposal

同一 PCI 计划在原单次准备生命周期内分别表达指南参考意见与可确认的具体材料。缺少患者测量、具体候选或数量依据，不阻止已有合法原文支持的类别和缺项说明；授权、来源可用性、模型控制、请求未知恢复及独立核验仍为相应分析前提。参考意见不能通过伪造产品 ID、默认一件或补造测量来适配现有具体材料合同。

首期用经过核对且版本固定的支架专题导航定位来源，再回读现有指南库原文。主题和原文共同参与输入预算与结果指纹，来源撤回、用途或正文质量失效时，派生意见也不得作为缓存继续提供。研究 Markdown 不是直接获得医学审校身份的产品数据，主题纳入产品前需要核对引用、人群、例外及明确的适用范围。

原始 AI 意见和来源只读，医生沿现有参数与真实材料工作稿编辑。新分析只提供参考或候选差异，不覆盖人工稿；同一状态不能把参考意见完成表达成具体预留已可确认。正式候选、数量、目录、预留集合、真实用量及计费仍由原 owner 执行。

同次准备的取消先停止尚未发布的指南步骤，避免取消清单准备后仍继续模型计费；在途结果不得发布或继续独立核验。已经发布的意见可以保留历史只读，医生显式重新评估创建新的指南准备版本，但不自动恢复耗材任务或改动人工清单。指南意图与结果按计划及版本持久保存，模型步骤、格式修复、未知恢复和实际请求计量继续复用既有执行边界，不新增第二套模型账本。

通用 Command 回执不经过指南来源的实时治理，因此准备回执只持久保存意图状态与执行标识，不嵌入指南原文或意见。页面和请求重放均从当前受治理投影读取有效内容，避免来源失效后仍能从独立回执入口恢复旧正文。

这项提案在[单次耗材预计决策](../../implemented/architecture/2026-10-28-single-material-estimate.md)之外增加参考意见语义，保留其持久意图、版本保护、整批事务和恢复理由；不反转[有限选型依据决策](../../implemented/architecture/2026-10-27-pci-selection-evidence.md)对真实产品和合成范围的保证。原文治理继续沿[指南全文决策](../../implemented/architecture/2026-10-16-free-guideline-corpus.md)。

## Alternatives considered

- 保留所有缺项齐全才生成：维持现状，但类别说明和测量问题仍无法在医生准备阶段提供帮助。
- 只把指南加到原提示词：派发前完整性门槛和输出必须定型定量的合同仍在，无法改变患者资料不足时的实际体验。
- 全面取消候选、数量和版本检查：可以减少阻断，却把不确定说明直接变成可确认产品，破坏正式业务责任与费用依据。
- 为类别建立假目录条目或默认数量：能沿用现有输出，但混淆医学类别、具体产品及真实计价，不采用。
- 新建通用知识平台、另一套模型执行与账本：超过单专题需要，重复原文治理、授权、未知恢复和计量。
- 自动整理全量指南并直接投入使用：当前实验未验证自动医学编译或冲突裁决；首期采用有明确范围、来源和核对记录的主题。

## Acceptance criteria

以正式规格 G1–G9 为唯一验收 owner。重点证明缺测量仍可读到有条件参考、具体材料不可伪造、原文进入生成与核验、人工稿不被覆盖、来源失效不能从派生内容恢复，以及原正式确认与计费不变量保持。实验命中数不能代替真实 HTTP 和页面接线证据。

## Risks

需要为现有具体材料合同增加明确的参考意见表达，不能仅把 `incomplete` 改成成功。患者资料不全、指南不可用与模型失败必须分别表达；人工专题也可能遗漏例外。版本及权限变化时需同时保护来源投影、模型结果和人工编辑。真实模型质量尚未验证，提出或批准规格不授权真实模型运行。
