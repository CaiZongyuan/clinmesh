# Agent Note: DRG 离线资料只维护当前精简格式

Status: implemented

## Problem

项目处于开发阶段，完整格式的自动升级、兼容读取和发行回退增加了安装路径与核验分支。完整来源文件的保留用于逐字节构建和来源核对，不要求安装器支持历史物理格式。当前需求见[精简储存规格](../../../spec/2026-10-25-drg-compact-storage.md)。

## Decision

离线锁和持久化清单必须包含 `clinmesh.drg-compact.v1` 储存索引。安装、清单核验、制包与导出统一使用精简读取器；删除完整格式分支、自动转换和旧发行锁。正常准备只复用当前资料或下载固定精简包。

维护者构建器读取当前锁中的来源清单，从完整逻辑文件生成物理索引、别名、派生配方和模板；完整核验输出后才发布目录。该构建输入不作为可安装格式，不引入旧锁 schema。相同来源、身份和时间可重建同一快照。

本决策取代[物理储存分离决策](../architecture/2026-10-25-drg-compact-storage.md)中的旧格式可用性约束；其无损字节、来源隔离、失败保旧和禁止永久物化合同继续有效。当前格式及命令由[储存合同](../../../drg-reference-storage.md)拥有。

## Alternatives considered

- 扫描旧安装目录并自动升级：需要发现与筛选历史版本、处理升级失败和回退，不符合开发阶段只维护当前格式的边界。
- 只删除旧发行锁，保留可选索引和完整格式读取：仍保留未使用的安装与核验分支，无法建立单一储存合同。
- 删除精简包构建器：失去从锁定逻辑来源可复现构建资料的能力，因此保留与当前锁配套的维护入口。

## Consequences

缺少精简索引的锁与清单被拒绝，不执行迁移。开发者使用当前资料和新建参考库；程序不遍历或删除个人完整来源副本，不清空临床业务库。自动安装失败仍保留本次目标目录及参考库，当前资料重复准备保持离线、完整核验和幂等登记。

公共准备入口验证旧锁拒绝、当前格式首次获取、离线重复、损坏修复、失败保旧和 check-only；制包、导出及清单查询继续验证完整覆盖、来源、危险路径和哈希边界。所有夹具使用合成资料与临时数据库。
