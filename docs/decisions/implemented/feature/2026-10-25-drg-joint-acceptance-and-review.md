# Agent Note: 住院 DRG 双轨编码、在院与归档双态评估、依赖指纹绑定与受控医保办核定

Status: implemented

## Problem

把 CHS-DRG 3.0 接入真实住院闭环面临四重约束：第一，病案首页诊断与手术操作锁定国家临床版 `nhc-icd10-clinical@2022.r4`，而分组规则字典使用国家医保版码域，若做名称模糊映射会制造失真入组；第二，在院预分组若强依赖已提交的离院病案首页会阻断术前术中实时评估，而归档后若继续按当前规则包与最新参数实时重算又会导致历史病组与原预估漂移；第三，若允许请求手填医保核定金额或缺失依赖指纹，在异步计费或切换患者后会提交过期审阅或伪造医保回盘；第四，下载完参考资料并不代表使用条件与编码适配已获部署确认。

## Decision

在[共享支付、住院与 DRG 边界](../architecture/2026-10-21-payment-inpatient-drg-boundaries.md)及[完整有序条件分组程序](../architecture/2026-10-25-drg-condition-program.md)之上，建立双轨同码直通、在院／归档互斥双态、全依赖指纹绑定与确定性医保办核定链路，详细合同见[住院与手术流程](../../../architecture/inpatient-workflows.md)、[DRG 条件分组](../../../architecture/drg-grouping.md)及[部署指南](../../../deployment.md)，核验记录见[DRG 条件核验研究](../../../research/2026-10-25-drg-condition-verification.md)：

1. **临床版与医保版双轨同码直通**：病案首页提交与审核强制核验完整临床版编码来源；`groupDrgCase` 对同码条目直接入组，未同码条目如实返回无法入组（四态结果 `grouped | ungroupable | ambiguous | invalid-input` 附逐步路径说明与 `codingNote` 口径声明），绝不做按名称模糊映射。
2. **在院实时事实评估 vs 归档不可变冻结及预估基线**：未归档病例实时读取当前正式诊断、已完成手术与执行计费事实（首页未提交时以修订 `0` 表达，多待实施计划支持显式指定假想主操作推演，实际主操作仍须医生显式确认）；病案归档事务内同步计算并将分组结果、医院侧支付预估及参数版本一并冻结写入 `inpatient_record_archive.drg_result_json`（规则包未启用时冻结结果为 `null`，绝不因 DRG 未启用阻塞法定病案归档）。前端按归档状态严格互斥展示在院推演或冻结结果，旧归档缺预估基线时明确标为不可对账而不按新参数回填。
3. **无状态全依赖指纹与受控医保办核定**：`simulate` 保持无状态只读评估（不落库可变评估实体），规范哈希 `fingerprint` 完整覆盖住院身份、临床修订、医嘱与实际执行事实（按实际执行单判定排程而非仅看已校对状态，避免漏算）、手术与预留、目录单价及规则版本；可见页面轮询发现依赖变化即置 `stale` 并锁定已打开的确认框要求重审。医保办专岗仅读取归档分组属性与编码来源摘要（无需完整病案文书权限），模拟核定金额由服务端按固定版本合成支付参数（`基础费率 × 病组权重`，FM39 等与病例包共用单一参数 owner）确定性计算，严禁客户端传入核定金额；核定记录 append-only 绑定归档 `sourcesHash`、冻结分组哈希与参数身份。
4. **公开读取强制审计与规则启用双门禁**：所有公开 DRG 读取接口均记录成功与拒绝审计（审计写失败则拒绝返回结果）；生产运行时启用 DRG 必须同时具备物化 v2 规则包与绑定 Manifest 及临床目录版本的受信部署审核文件。

## Alternatives considered

- **按疾病／手术中文名称模糊映射双轨编码，或规则未配置时阻断病案归档**：模糊映射掩盖真实码域差异，阻断归档则使可选仿真能力绑架核心病案收口。
- **每次 `simulate` 落库可编辑评估实体，或核定时用最新参数重算医院原预估**：落库引入第二份需同步的费用状态，重算原预估则抹平参数升级前后的真实对账基线。
- **允许客户端请求体直接提交医保核定金额，或资料哈希校验通过即默认启用运行时分组**：前者允许伪造医保结算回盘，后者混淆文件完整性与业务适用审核。

## Consequences

住院医生、病案人员与医保办在同一套真实住院与冻结归档事实上协同完成术前推演（无操作 FR59、造影 FM59、支架置入 FM39）、归档锁定与医院侧结算差额复核，且医院侧 DRG 差额与患者个人医保待遇、归档后财务更正保持严格解耦。
