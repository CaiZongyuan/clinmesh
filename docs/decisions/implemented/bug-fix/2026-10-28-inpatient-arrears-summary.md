# Agent Note: 住院欠费使用当前资金摘要

Status: implemented

## Problem

医生端按医疗费用与预交金比较预警，漏掉医保抵扣及独立补缴，导致已结算归档仍显示欠费。首次结算冻结账和归档后的财务更正分别保留，单纯隐藏已结算或已归档患者又会掩盖后续真实待收。

## Decision

住院概要增加最小 `outstandingFen`，在一致读取中复用首次资金与后续财务更正的正式计算。金额确定时返回非负整数分，未知收退款或医保来源待重审时返回 `null`。字段可选以兼容原 Command 回执；缺失表示摘要不可用，客户端刷新当前概要，不回退费用减预交金。

横幅、医生列表及临床提醒消费同一摘要，归档只关闭临床待办，不隐藏当前资金待核对或真实欠费。公开资金和财务明细继续保留原岗位校验，内部计算不触发收费明细读取审计。当前合同由[临床流程](../../../architecture/clinical-workflows.md#住院出院与结算)拥有。

## Alternatives considered

- 仅隐藏已结算或归档的欠费：会漏掉后续更正产生的待收。
- 前端读取完整收费账计算：扩大医生权限，复制资金及医保口径，并形成逐患者额外请求。
- 将补缴并入预交金或改写原结算：破坏原款身份、退款来源及归档冻结事实。
- 新增必填概要字段：历史幂等回执不能重写，必填会破坏原操作恢复。

## Consequences

概要保留当前读取权限与病区隔离，仅增加金额或待确认事实，不返回交易方式和医保年度余额。多表计算使用当前事务或一个读快照；列表复用财务 owner 的计算成本高于旧费用比较，不维护第二套可编辑余额。公共 HTTP、生产工作台挂载和真实 Web 入口分别验证余额、权限及刷新，回归保留首次结算与归档不变断言。
