# Agent Note: 乳腺病理切片摄取、五项事实匹配与既往切片会诊闭环

Status: implemented

## Problem

乳腺切片病理会诊需要基于公开 TCGA-BRCA（NCI Imaging Data Commons）的真实 H&E 全视野数字切片完成“选定既往手术标本、申请会诊、20× 瓦片阅片、核对受体报告并确认已阅”的临床闭环。与放射灰度序列不同，数字切片包含数万个瓦片、混用浏览器原生不支持的 JPEG 2000 编码、缺省 10× 中间倍率且 DICOM 头含受试者标识；Synthea 乳腺癌病例又已固定受体（ER/PR/HER2）、淋巴结与 T 分期事实，随机生成命中率极低（0.25%–7.5%），且必须以“患者携带外院既往手术切片来院会诊”建模而不能把外院 R4 手术伪造成本院 R5 Procedure。

## Decision

在通用素材存储与 `ClinicalRequestKernel` 之上构建独立的病理素材包、五项事实派生匹配与会诊闭环，当前合同见[检验、检查与报告](../../../architecture/examinations-and-reports.md)、[仿真、病例与素材](../../../architecture/simulation.md)、[病理使用指南](../../../pathology.md)与[病理切片素材清单](../../../../pathology-assets/README.md)：

1. **独立切片素材包、确定性补层转码与去标识存储**：病理拥有独立的清单目录、素材目录与 `pathology:*` 维护命令。摄取仅保留最高 20× 组织金字塔（40× 原生层按整数 2×2 区域均值降采样至 20×，缺 10× 层时同法生成，丢弃缩略图、标签图与宏观图并剔除 DICOM 患者头与非 JFIF/Adobe 应用段）；基线 JPEG 原样保留，JPEG 2000 经锁定版本 OpenJPEG WASM 与 `jpeg-js`（质量 85、YCbCr 4:4:4）离线转码，逐瓦片核验颜色空间后按行优先拼接为单层瓦片文件加累计偏移索引，供[OpenSeadragon 瓦片金字塔引擎](2026-10-02-slide-pyramid-engine.md)定位读取。
2. **五项临床事实单一派生、可见病史匹配与长窗口定向生成**：适配条目直接从清单素材临床字段派生（ER、PR、HER2、病理 N0/N+、肿瘤 T1–T4），不手写平行条目清单。匹配器仅读取 Index Encounter 之前医生可见的来源病史，严格区分相符就绪、未安装（`ASSET_NOT_INSTALLED`）、缺项未知（`FACT_UNKNOWN`）与事实冲突，按“病例 + 来源身份 + 会诊服务 + 来源手术引用”冻结绑定。定向生成向 Synthea Provider 下发五项最新 Observation 编码值保留条件，并强制至少导出 45 年病史窗口，防止早期乳腺手术与受体记录因导出起点过晚被截断。
3. **既往切片会诊类型与受控边界**：申请内核追加 `pathology` 适配器，医生从可见来源病史选定送检手术并以来源引用快照保存（不转写为本院 R5 Procedure）。签发时创建采集时间取自来源手术、接收时间取自本院收片的 `Specimen`、模态为 `SM` 的 `ImagingStudy` 及只复述已复核来源字段（固定组织学表述与免疫组化，不含未核实分级、切缘或淋巴结计数）的 `DiagnosticReport`；FHIR `Provenance` 不暴露内部素材 ID，患者问诊模型仅获知“会诊已受理”而不接收病理结论，医生确认已阅须具备当前会话内真实瓦片显示证明。

## Alternatives considered

- **建模为本院穿刺活检或将来源手术转为本院 FHIR R5 Procedure**：公开切片多为手术切除标本且缺乏取材制片流程依据；转写 R5 Procedure 会把外院既往史伪造成本院医疗行为。
- **保留原生缺 10× 层级或将 JPEG 2000 留给浏览器 WASM 实时解码**：缺 10× 会导致中间倍率下瓦片请求激增 16 倍或画面模糊；浏览器端携带 WASM 解码器会膨胀 DSH 单文件包并增加宿主兼容风险。
- **在 `matching.json` 手写受体组合或将未覆盖与冲突合并为单一状态**：手写列表会与签署复核的素材字段分叉；区分冲突与缺项才能定位是素材库缺口还是来源记录不全。

## Consequences

新增切片素材无需修改匹配规则文件即可自动派生适配条目，改动素材临床字段则同步触发重新复核与未开始病例重评估。转码与补齐 10× 层使安装体积约为原始 JPEG 2000 的 1.5–2 倍；切片像素缺失或损坏时文字报告仍可只读查看，但禁止新确认已阅。
