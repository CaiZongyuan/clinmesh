# Agent Note: 自动整理病历以句子编号传输来源

Status: implemented

## Problem

自动整理病历的后台事实需要完整来源，但让模型重复抄写来源原句增加响应体积和标点、换行、句界错误。来源界面已由[移除来源展示决策](2026-10-14-consultation-recording-without-source-ui.md)移除；该决定仍保留来源核对、更新合并和审计，并不意味着可以删除事实依据。

## Decision

来源语义检查已按[统一质控决策](2026-10-19-recording-quality-consolidation.md)归现有病历质控，不再执行自动记录后的逐片段核对；本决策继续拥有句子编号、完整引用恢复、快照隔离和预算。

`ConsultationRecordingService` 为新批次的不可变快照保存 `citationProtocol: sentence-references-v1`，实时、补录与显式恢复共用该入口。`consultation-recording-sentences.ts` 按共享完整句界谓词生成句子、原来源身份及 UTF-16 起止位置；完整快照 hash 的前 16 个十六进制字符与有序句子下标组成短编号。映射在调用前生成，重启或重复消费只从持久快照按固定版本重建，不查询最新来源。同文不同来源、同来源内重复原句拥有不同编号及位置；跨快照编号明确拒绝。快照仍受病例、Epoch、授权和任务代次约束，hash 不承担授权职责。

模型输入保留完整轮次和逐句编号文本，便于跨句理解；新增事实只返回 `text` 与 `sourceIds`，服务端恢复原 `sources: [{ sourceTurnId, quote }]`。每项最多 12 个不同编号，不截原句凑入上限；过长引文或超限候选明确失败，独立候选继续处理。`retainedFactIndexes` 原样复用旧事实，不要求模型重述。完整句与疑问共存、否定、条件、数值和不确定性由原文及独立语义核对保留。

本提案调整模型传输责任，不改变后台证据语义。句子编号仅在所属快照内有效，持久事实仍使用原来源身份和逐字引文。恢复或重试使用原快照，新旧任务按各自协议处理。来源编号存在不能证明总结忠实，独立核对的否定结论继续是合法结果。

有效候选先恢复完整来源并经业务 schema 规范化，再按内容去重；同一来源内不同编号指向相同原句时，等价更新只处理一次，不制造竞争替换。不同来源的同文引用仍保留各自身份。无效候选以原始编号区分，避免恢复失败后空来源相同而吞掉独立失败；它们仍参与共享目标的原子冲突判断。

未保存协议标记的旧快照继续使用完整引文模型协议；既有事实、Command 回执和已经完成的正文不迁移或重新生成。公开 API、持久事实格式及共享 Command 不变。本决策只替代[多轮来源决策](2026-10-12-consultation-agent-summary-sources.md)和[增量记录决策](2026-10-15-low-latency-document-recording.md)中的模型复述责任，保留其校验、人工编辑保护、冻结和恢复边界；正式验收由[句子引用规格](../../../spec/2026-10-19-recording-sentence-references.md)拥有。

固定快照仍限 256 KiB；模型请求的 128 KiB 限制包含编号映射、原文、schema 和提示词。Provider 对实际序列化请求再次计数，每次格式修复包含新增提示；超限保留来源供显式恢复，不调用模型或截断证据，不提高预算。

## Alternatives considered

- 保留模型逐字复述：无需改变传输合同，但继续承担重复输出及引文格式错误。
- 同时删除后台来源：无法维持逐事实语义核对、多轮更正与拒绝事实保护。
- 只引用整轮消息：返回更短，但丢失句子级证据定位，长消息中不同事实与疑问的依据更难区分。
- 让模型返回字符位置或靠模糊匹配找回原句：位置、换行或重复文字可能错配，不能作为确定性恢复依据。

## Consequences

事实文字仍由模型生成，编号存在只证明归属，不能证明语义忠实。合法的否定核验继续在格式校验之后处理，不诱导模型改成通过。新引用解码不增加模型调用；生成与格式修复沿用最多两次尝试，异步核对独立执行。

`recording-sentence-references.test.ts` 的固定合成多轮病例中，整理模型输入（来源、schema 和提示词）从 6,028 字节增到 6,550 字节，输出从 297 字节降到 195 字节（减少约 34.3%）。输入增加来自显式句子映射和协议提示；数据是 UTF-8 JSON 序列化字节，不含传输 envelope，不代表 Token、费用或实模耗时。没有压测或真实模型调用。

纯函数测试覆盖标点、问号组合、LF/CRLF、重复原句定位、跨轮引用、编号隔离及容量失败。真实 `DshModelProvider` 与宿主 handler 的合成回归覆盖新 schema、一次格式修复、否定核验、旧 SQLite 在途快照和重启后不重复生成；公开 HTTP 与共享 Web/DSH 浏览器回归继续拥有状态、人工保护和来源界面隐藏的证据。旧状态机 fixture 在测试边界转换引用，仅证明原有业务不变量，不能替代原生新协议接线测试。
