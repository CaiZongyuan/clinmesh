# Agent Note: 病历待补充问题仅在详情展示

Status: implemented

## Problem

后台已发现空字段或已知事实遗漏，但详情过滤全部待补充问题，医生看到“本次检查已更新”后无法找到检查发现的内容，容易将无可见提示误解为病历完整。正文持续显示缺项又会干扰正常问诊。

## Decision

“依据与说明”的病历质控按字段展示待补充和待核实问题，包含已有摘要、影响、处理建议与字段定位；签署汇总展开后的详情复用相同展示，旧处理记录保持只读。页面顶部的紧凑提示仍只展示开放的待核实问题。

本决策部分取代[安静质控提示决策](2026-10-18-quiet-document-quality-hints.md)中完全隐藏待补充问题的范围。后台检查、证据、缓存、授权及签署校验不变；不新增逐条来源展开或确认动作。当前验收合同由[质控规格](../../../spec/2026-10-15-doctor-document-quality-control.md)拥有。

## Alternatives considered

- 继续完全隐藏待补充：无法按需查看后台已经发现的缺项与遗漏，检查状态与可见结果脱节。
- 在页面顶部展示全部问题：问诊中的正常空字段会持续占据正文区域。
- 单独建立待补充面板：重复字段定位、状态与问题展示逻辑，增加入口负担。

## Consequences

待补充成为按需查看的辅助信息，医生直接编辑病历即可。没有顶部提示仍不代表病历完整或临床质量通过；检查失败、过期及原有签署门禁继续如实生效。

组件回归覆盖十字段与历史记录；真实 Web 与 React 18/19 ShadowRoot 验证详情显示、双语标签、窄宽度与字号、字段定位及原有签署流程。
