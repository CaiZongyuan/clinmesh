# Agent Note: 手术耗材术前不可变基线、逐笔与补录更正、完成净差额核实及常规免备注

Status: implemented

## Problem

住院手术耗材跨越术前预计预留、术中分次消耗、完术最终核实与术后错漏补录。若复用一次性手术执行接口逐笔登记耗材，会提前结束手术并重复收取术式费；若从可变预留余额反推术前计划或直接原地覆盖已记费数量，会丢失术前审阅原貌与原始账务依据；若手术完成后发现漏记新耗材只能重开手术或挂靠无关记录更正，会污染临床事实；而若完术核实与按计划常规操作仍一律强制手填机械同义 `note`（或在存在真实改量时用前端模板代填），又会制造无谓文书负担或掩盖需要医生解释的真实偏离。

## Decision

以单一手术与计费 owner 串联术前不可变快照、术中逐笔／术后补录更正、完术净差额核实及按偏离裁决的留痕规则，详细业务与界面合同见[住院与手术流程](../../../architecture/inpatient-workflows.md)及[临床 UI 设计](../../../ui/design.md)：

1. **术前不可变确认基线（`inpatient_material_plan_confirmation`）**：单次耗材清单确认在替换预留的同一 Command 事务内追加不可变术前快照，冻结确认人、依据指纹、材料目录版本、规格、单位、数量与单价；预留消耗或释放不改变该基线，无跨来源明确取代关系时如实并列保留供术后核查比对，绝不从剩余预留或当前草稿反推历史计划。
2. **单 `Procedure` 分阶段生命周期、追加更正与术后独立补录**：手术以同一实际 `Procedure` 区分 `in-progress` 与 `completed`（分组与病案首页只消费已完成集合）。术中耗材登记不可覆盖：纠错通过 `correct-material` 追加原使用说明、共用 `InpatientBilling.reverse` 精确冲正引用及可选替代使用；完术后在院、未封账且未归档窗口内发现漏记全新耗材时，通过独立窄命令 `inpatient.surgery.supplement-material` 追加 `recordingKind=postoperative-addendum` 记录与材料费（校验医生审阅的 `expectedCharge` 单价与单位断言，保留原完成时间与唯一术式费）。
3. **完成手术净差额核实与显式预留收拢**：`preview-completion`（采用 POST 承载核实清单，Catalog 标记只读风险避免 CLI 误走写回执恢复）对输入、实际手术、目录、预留及既有费用／冲正生成绑定会话与岗位的指纹；`complete` 在同一事务重验指纹，按预留汇总先退回减少量（复用材料更正与精确冲正）、再追加增加量（零最终量不写零记录），收一次术式费，且仅关闭明确勾选的本手术预留（写入 `releaseReason`），保留未勾选的住院后续安排。
4. **常规无差异路径免填 `note` 与偏离强制留痕**：文书与纠偏节点（`request`、`confirm-consent`、`check-preop`、`cancel`、`supplement-material`、`correct-material`）保持 Schema 层 `note` 非空必填；常规执行与核实节点（`start` v2、`record-material` v2、`preview-completion` v2、`complete` v3、`execute` v3）由服务端统一裁决——仅在术式与计划一致、耗材显式绑定本台有效预留且不超余量、完术零数量差额（`deltaQuantity === 0`）且无本台未用预留或未解释清单冲突时允许省略 `note`，由服务端生成非空结构化默认留痕写入数据库、审计与 `Procedure.note`（省略与空白归一化至同一预览指纹）；一旦命中任何偏离而未填说明，服务端确定性返回 `400 INPATIENT_SURGERY_NOTE_REQUIRED`，前端自动展开空白输入框要求手填，绝不在存在差额或未用预留时用规则模板代填。

## Alternatives considered

- **重记最终耗材总量，或在前端循环调用逐笔更正后再调完成接口**：重记总量会重复产生材料收费，分步调用在中途冲突时留下半成品账目。
- **完术时自动释放全住院或本计划全部剩余预留**：误删分阶段手术保留的后续预留，改为显式勾选关闭并持久化 `releaseReason`。
- **仅在前端隐藏并代填默认备注，或将所有手术命令 `note` 一律改为无条件可空**：前者让 CLI/Agent 继续拼接废话且掩盖服务端偏离校验职责，后者丢失术式变更、借用通用预留与现场改量的可审计原因。

## Consequences

从术前确认、术中逐笔、完术净差额收口到术后在院补录均共享同一本住院费用账与幂等回执链：常规按计划手术零冗余填字，任何规格、数量、术式或预留偏离均强制保留医生真实说明，供术后核查与病案归档追溯。
