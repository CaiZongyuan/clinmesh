# Agent Note: 指南固定资料包与内部测试启用

Status: implemented

## Problem

指南原件和数据库只保存在本地时，克隆代码无法重现同一资料环境；新增冠心病 PDF 也无法直接使用现有官方域名同步入口。既有用途过滤还会使已下载的资料无法进入内部测试建议，资料取得与实际可用需要共同验收。需求由[指南安装规格](../../../spec/2026-10-26-guideline-release-installation.md)拥有。

## Decision

沿用 [DRG 固定分发机制](2026-10-22-drg-reference-distribution.md)的版本锁、临时下载、安全解包、离线复用和失败保旧思路，为指南建立独立资料包和安装入口。原件、派生正文、提取工具版本及核验记录一起锁定，部署侧导入现有全文 SQLite；不将大型原件加入源码历史，也不在每次安装时重新生成可能不同的 OCR 结果。指南只复用窄机制，不依赖 DRG 清单，也不先建设通用资料平台。

显式 `internal-testing` 部署策略允许包中已登记、正文检查通过且 active 的资料供内部测试检索和建议使用，原始许可与待核实状态保持原样。该增量只在此策略内调整[既有用途过滤决定](2026-10-16-free-guideline-corpus.md)，未选择该策略的部署继续沿用旧规则。自动检查、Agent 对照原页校对与自然人审校分别登记，Agent 修订保留原始提取、物理页及逐项差异，不要求安装者另行完成校对。控制字符、替代字符等未确认的提取异常段落保留完整原文，但在检索候选限额之前隔离，避免错误运算符或缺字进入模型。不可读、待核验、已撤回和被替代的来源仍停用。启用、停用、包身份、正文质量规则与部署策略进入统一可用判断和 revision；包已下载不能被解释为检索命中或建议已引用。

运行库使用整包 SQLite 事务导入，预先验证所有文档并保留其他来源；不替换 SQLite 文件，使已打开的只读连接继续看到新内容并使旧建议失效。重复准备和只读检查比较实际元数据、段落及身份，并用 FTS 完整性检查核对索引与全部实际正文，不能只相信存储摘要、来源数量或外部正文表返回的行数。独立索引损坏由普通准备在事务内离线重建，仍保留其他来源。正式目录更新失败时恢复 previous，恢复失败保留唯一备份路径。正常开发入口与生产构建准备同版资料，业务请求不承担下载。

准备器在系统临时目录复制并核对稳定的主数据库与 WAL，读取其中已提交内容，SQLite 的共享内存文件只在该临时目录创建，结束时清理。复制前后校验文件身份、纳秒时间、大小和内容；并发发布或 checkpoint 导致变化时显式失败，等待 writer 完成后重试，不退回只查主文件或忽略活动 WAL。运行时仍使用普通只读连接，持续观察后续事务更新。

## Alternatives considered

- 人工复制个人数据库：无法保证新环境自足，来源和派生正文也可能缺失。
- 每次从出版方重新获取并抽取：无法重现本地补充材料及 OCR 核验结果，远端变化还会混入安装。
- 把原件与 SQLite 提交 Git：使大文件和生成数据进入源码历史，不符合既有同步边界。
- 将全部来源标成开放许可：丢失真实来源状态，其他部署无法恢复原有使用策略。
- 只分发可搜索数据库：安装快，但无法独立核对原始页面与提取内容；采用原件和提取结果制包，接收端建立运行库。

## Consequences

固定包可以复现同一原件、正文、校对修订和核验结果；大文件不进入 Git，首次获取仍依赖已发布 Release 可达，完整安装可离线复用。MinerU 恢复的正文通过独立物理页锚点与原件对照，跨页边界未确定时保留页范围。Agent 校对范围、未确认段落和自然人审校状态保持可回读；资料不代表最新指南全集或临床质量认证。

合成归档、临时库、公共准备入口和受控模型 HTTP 旅程分别验证取得、加载、检索和引用，不借用维护者现有 SQLite 作为新安装证据。安装、失败恢复与正文核验状态由[部署指南](../../../deployment.md#免费指南全文同步)拥有；完整验收由[规格](../../../spec/2026-10-26-guideline-release-installation.md#验收条件)拥有。代码中的固定 URL 和内容锁不代表 Release 已发布。
