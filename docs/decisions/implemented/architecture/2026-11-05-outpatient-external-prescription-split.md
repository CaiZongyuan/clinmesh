# Agent Note: 门诊本院药房与国家参考目录分轨及外延处方零院内账项

Status: implemented

## Problem

当运行环境同步国家医保药品分类与代码参考库（269,110 条品规）后，门诊药品选择弹窗若默认直接展示参考目录分页结果，会掩盖本院有定价、库存批次与适应证规则的院内药房目录。医生从参考目录选药并正式开具时，若仍无条件生成单价 0 分的 `ChargeItem` 与 `charge_record`，门诊收费预览会因收款明细要求正数金额而报错，药房队列又因仅关联本院目录而无待发记录；单张处方若混用两类来源更会导致部分计费与永久部分调剂死锁。同时，右侧「待开具处方」确认入口此前将所有 `CATALOG_CONFLICT` 与 `WORKFLOW_CONFLICT` 折叠为同一条笼统提示，掩盖了服务端已有的细分拦截原因。需求范围见[门诊处方目录分轨与报错反馈需求（Issue #399）](https://github.com/CaiZongyuan/clinmesh/issues/399)。

## Decision

门诊「选择药品」两栏弹窗在左栏顶部显式提供「本院药房」与「国家参考目录」分段切换，「添加药品」默认选中「本院药房」，编辑草稿既有条目时自动定位其所属来源页签。「本院药房」展示当前启用的门诊可用院内药品、规格包装与单价并支持含单字在内的院内关键词过滤，未锁定本院来源且空结果时提供一键切换至「国家参考目录」入口；「国家参考目录」支持含单字在内的关键词分页检索参考品规，并在列表上方提示其仅生成电子外延处方、不在本院收费与药房发药。候选行保持紧凑，不常驻展示适应证编码。本决定部分取代[医生临床目录选择与草稿确认](../feature/2026-08-31-doctor-clinical-catalog-dialogs.md)中“药品选择器默认读取 Reference Release 第一页”及“药品搜索最少两个字符”的约定；诊断默认浏览及参考目录防抖、分词、有界分页合同继续有效。

单张门诊处方强制单一履约来源。前端在草稿或待开具人工清单已含某一来源药品时禁用另一来源候选并在行内说明原因（编辑唯一现存条目自身除外）；服务端在保存处方草稿、直接正式开具及诊疗建议待办原子确认三条路径统一校验来源一致性，混源请求返回 `409 CATALOG_CONFLICT` 与 `reason: PRESCRIPTION_MIXED_CATALOG_SOURCES`。

纯「国家参考目录」处方正式开具时保留完整临床请求事实（创建带处方号的 `Prescription`、每药一条 `MedicationRequest`、审计与 Action Trace，清空草稿，满足门诊完诊门禁中的 `medication-conclusion`，并在未撤回时支持 `prescription.withdraw`），但不创建 `0 元` 的 FHIR `ChargeItem` 或 `charge_record`，命令 `effects` 不含虚构 `ChargeItem` 引用，且不进入门诊收费或药房队列。「本院药房」处方继续按院内单价创建 `ChargeItem` 与 `charge_record` 并走完收费、审方与批次发药闭环。当前流程状态机见[临床业务流程](../../../architecture/clinical-workflows.md#81-门诊闭环)。

服务端公开操作错误结构保留可选细分 `reason`，直接开具与诊疗建议待办确认统一透传 `PRESCRIPTION_*` 原因码，CLI 与 Web 共享该字段，使右侧「待开具处方」与处方页共用同一套可操作中英文报错映射，仅在缺少已知 `reason` 时回退通用冲突提示。

## Alternatives considered

- 在药品候选行常驻铺设适应证编码标签：国家参考目录 26.9 万条品规无结构化适应证约束，本院门诊目录体量小，行内堆砌编码既造成视觉噪音又对参考目录产生误导；改为开具拦截时精确反馈具体 `reason`。
- 允许单张处方混开院内与院外药品并在后端拆分为院内计费子集与院外免计费子集：需要改写单处方支付状态、部分调剂完成判定及撤回原子边界，复杂度高于真实临床“院内处方与外延处方分方开具”的常规做法。
- 为国家参考目录处方保留 `0 元` `ChargeItem` 并在收费预览自动豁免：违反临床请求与可计费活动分离原则，也会在账单、医保映射与退款校验中留下无意义的零金额账项。

## Consequences

日常院内开药默认命中本院有库存定价的门诊药品，院外参考目录仍可在缺药时显式检索并完成电子外延处方与完诊闭环，不再污染门诊收费待缴队列和药房待发队列。医生在待办确认或处方页开具被拒时可直接定位未确认主诊断、适应证不符、活动过敏冲突、剂量数量超限或跨源混开等具体原因。院外社会药房处方流转平台、院外医保结算及住院医嘱目录规则不在本决策范围内。
