# Agent Note: 自动记录来源语义检查统一归病历质控

Status: implemented

## Problem

自动记录保存每个片段后分别调用模型进行语义核对，现有病历质控也检查 Agent 片段的来源支持性并独立复核。两条调用链重复处理相近证据，病历和签署入口还并列展示独立核对状态与质控问题。引用合法性无法证明语义正确，但逐片段增加一次请求也没有额外准确性收益的对比证据。

## Decision

取消自动记录保存后的逐片段语义核对及其模型绑定、调度通道和专用重试，现有病历质控统一检查来源语义。实时、补录、显式重试和恢复继续在确定性校验后经共享 Command 保存草稿、完整来源和进度。引用合法性、字段来源角色、候选隔离、人工编辑、幂等、预期版本、授权、Epoch、任务代次及签署冻结仍由记录链保护。

自动片段通过批次关联表引用不可变快照，复合外键约束片段与批次属于同一 Workspace、Epoch 和病例。质控读取本次病例的变更前后事实、关系、已拒绝事实和新来源上下文，沿连续替换的目标链检查旧事实保留、更正或冲突关系及无新依据的拒绝事实重现；历史变更后片段不作为当前事实或独立证据。上下文参与现有指纹、输入预算和完整覆盖检查，沿用质控生成、独立复核及同输入复用，不按片段另建模型任务。上下文缺失、断链、环、超限或检查失败只能说明不完整，不能作为通过。否定结论形成待核实提示，保留影响及处理建议，不自动改写正文。

生成与独立复核接收完整来源；提示证据使用已经逐字校验的原句，保留来源身份、类型和时间，同来源同引文去重，不同引文分别保留。证据过多时分组形成稳定标识的待核实提示，每组保留变更前后片段并遵守既有单条问题的证据数量和文本长度上限，不丢弃后续引用、不扩大 wire 或模型预算。问题总数超过既有展示上限仍明确不完整，合法否定结论不能因展示证据超限而变为模型失败。策略版本使旧失败缓存失效，完整输入相同时仍复用现有任务。

正常人工接管的当前片段退出自动变更及其来源归属检查，当前正文仍参与整份病历质控；未保存候选按保存稿中的锚点投影，人工改写同样不阻断其他自动片段与字段的检查。替换关系依照不可变批次当时的归属：人工目标优先使用人工快照并终止自动祖先链，历史自动目标使用当时的文字和事实，不混入后续人工正文或追溯否定已经发生的关系。仍归自动且保存稿锚点或证据缺失时保持不完整，不能借人工接管分支掩盖损坏的来源归属。

前向迁移以 `retired_status` 保留旧核对记录原状态、原因和证据，将 pending 标为 stale，并回填历史批次关联。旧 `consultation.verify-history` outbox 事件仅兼容消费与退役，不能绑定或调用模型；重复消费安全完成。Query 与历史控制回执中的兼容 `verification` 计数固定为零、issues 为空，不表示事实通过核验。历史判定不能触发活动提示或核对重试。病历编辑器、签署对话框和 Agent 签署审阅只保留现有质控及真实记录失败恢复，无逐条确认门禁。

本决策部分替代[增量记录决策](2026-10-15-low-latency-document-recording.md)中的写入后独立核对及其展示，并调整[句子编号决策](2026-10-19-recording-sentence-references.md)的核对归属；其增量保存、不可变来源、程序解码与输入预算继续有效。[病历质控决策](2026-10-15-doctor-document-quality-control.md)继续拥有生成、独立复核、输入复用与签署汇总。当前运行合同见[临床业务流程](../../../architecture/clinical-workflows.md)，完整验收由[正式规格](../../../spec/2026-10-19-recording-quality-consolidation.md)拥有。

本决策也接替[病史总结决策](2026-10-12-consultation-agent-summary-sources.md)中的独立忠实性模型调用；其原始来源、事实限定及编辑保护理由继续适用。

## Alternatives considered

- 保留两条核对链：能提供逐片段状态，但继续承担重复调用和重复提示，额外收益缺少对比证据。
- 仅隐藏独立提示：后台任务、恢复和模型消耗仍然存在。
- 删除全部语义检查：无法发现真实引用与病历含义不匹配，也会丢失旧事实及拒绝事实保护。
- 将逐片段核对提前到写入前：重新增加草稿保存前的等待和请求次数。
- 仅向质控追加提示词：无法证明每项变更的保留、关系和拒绝事实规则已得到检查，因此沿用结构化完整覆盖及独立复核。
- 每条提示附带全部来源全文：模型输入合法时仍可能超过单条问题的证据合同，使有效否定结论无法发布。

## Consequences

自动记录正常批次只有一次整理模型请求，格式错误仍沿用有界修复。质控检查仍可能误报或漏报，空提示不代表临床正确或监管合规通过。完整上下文可能触及原输入预算，系统必须明确报告不完整，不能截断证据或提高预算掩盖缺口。

HTTP/file-backed SQLite、合成 Provider 和真实 DSH 传输边界回归分别证明模型请求类型与次数、引用与状态保护、非空旧库升级和重复消费。Web 真实入口及 React 18/19 ShadowRoot 合同验证独立提示消失、质控保留及手工编辑和签署行为。此证据不代表 Token、费用、实模延迟或临床准确率改善；压测和真实模型调用须另行授权。
