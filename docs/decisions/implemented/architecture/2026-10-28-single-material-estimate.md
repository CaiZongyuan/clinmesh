# Agent Note: 冠脉造影参数带入、有限选型依据与手术计划单次耗材预计

Status: implemented

## Problem

住院冠脉造影／PCI 术前准备若要求医生先手填全部血管测量参数、分类计划数量并开启长期后台跟进任务，才能触发耗材预计，或在术中每登记一笔耗材都自动调用两次模型复述确定性余量，既没有减轻临床录入负担，又会在默认未启用 DRG 规则的环境下让 AI 预计因缺分组而完全停摆；同时，目录价格与企业信息本身不能证明器械尺寸适用或导管导丝兼容，而循环调用单笔预留接口也会在中途失败时留下半份未审阅清单。

## Decision

建立结构化造影测量带入、版本化有限合成选型依据、保存计划触发的单次持久预计与整批原子预留确认链路，当前业务与仿真合同见[住院与手术流程](../../../architecture/inpatient-workflows.md)及[仿真、病例与素材](../../../architecture/simulation.md)，取证背景见[PCI 与 DRG 演示启用研究](../../../research/2026-10-27-pci-drg-demo-enablement.md)：

1. **正式造影报告参数带入与有限合成选型依据**：诊断性冠脉造影完成后，仿真侧从隔离 `Case Truth` 零模型生成正式造影报告与结构化测量（多支病变与阴性 FFR 扩展见[多支冠脉造影生理学报告](../feature/2026-11-12-cardiology-default-labs-and-multivessel-angiography.md)）。保存 PCI 计划时自动复制测量至选型草稿并绑定报告身份与版本，服务端逐项核实字段是否被手改以区分 `report` 与 `manual-revision` 来源（无报告病例保留纯手填路径）。`InpatientPciSelection` 独立于后台跟进保存选型确认历史，联接院内已安装耗材与固定合成依据包校验靶病变尺寸、器械组合兼容与数量范围，明确区分真实集采报价出处与合成仿真规格，绝不冒充真实器械 IFU。
2. **绑定手术计划的单次预计意图与双轨工作稿**：保存受支持手术计划的共享 Command 在同一事务写入单次耗材预计意图（历史计划支持显式补建，与持续 DRG 跟进生命周期解耦），复用持久分析队列、生成／独立核验、[模型请求准入与用量账本](2026-10-21-model-usage-accounting-control.md)及未知恢复。DRG 规则结果仅作为费用说明数值来源而不再作为模型派发前置门槛（DRG 未启用时自然语言说明原因）；术中改为纯规则实时费用板，不再逐笔自动调用模型（偏离计划登记的受限说明见[手术流程指引与受限助手](2026-11-13-surgery-flow-assistance.md)）。模型输出与医生持久工作稿分离：首次有效结果仅初始化空白工作稿，后续重算生成候选差异而不静默覆盖医生已保存或本地未保存手改稿。
3. **一次确认原子写入选型、不可变基线与整批预留**：医生对参数、耗材清单与费用确认一次（发送前经本地视图守卫拦截异步预检期间的切页或切患者），在单一 Command 事务内重验同计划活动预留集合指纹（见[住院写入与集合指纹恢复](../bug-fix/2026-10-20-inpatient-command-intent-recovery.md)），原子写入选型确认、不可变术前清单基线并整批替换冻结活动预留；预留仅参与费用推演与术中核对，不提前锁扣实物库存或产生正式收费。

## Alternatives considered

- **保存计划时隐式开启长期持续跟进，或将 DRG 未启用设为预计阻断项**：一次术前准备不应暗中授予跨阶段后台消费权限，默认未配 DRG 的部署也不应丧失耗材目录匹配能力。
- **让模型从造影报告自由提取测量，或直接把最新模型结果覆盖医生工作稿**：报告本身已是结构化数据，规则复制零误差零消耗；覆盖工作稿则会抹掉医生审阅修改。
- **前端循环调用单笔预留接口**：中途冲突会留下新旧混杂的半份预留，无法证明整份术前清单经一次完整审阅生效。

## Consequences

医生保存 PCI 计划后无需开启后台跟进即可获得带造影测量出处与目录依据的预计草稿，并在一次原子确认中完成选型与整批预留锁定；造影病变超出有限合成依据范围或模型不可用时如实回退手工准备，不影响正常手术执行闭环。
