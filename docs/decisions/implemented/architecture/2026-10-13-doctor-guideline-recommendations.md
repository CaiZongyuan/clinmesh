# Agent Note: 门诊可追溯诊疗建议、分批证据读取与信封预算收敛

Status: implemented

## Problem

门诊医生核对诊疗建议时必须同时查验指南原文依据、当前病例证据与本院真实可执行目录：模型记忆、无限定语摘要、目录默认用法或隐藏仿真真值都不能冒充临床依据，病例变化后的迟到生成也不能覆盖当前人工草稿。同时，纵向合成病史与全院检验目录极易突破单次模型请求预算（240 KiB 载荷／256 KiB 宿主桥接信封），尤其当必读安全资料较大且中文 UTF-8 字节达字符数三倍时，若在每个筛选批次重复携带必读全文或漏做字节计量，会导致筛选批次塌缩或生成阶段无剩余空间。

## Decision

在共享建议服务、按字节预算的分批筛选收敛与非侵入草稿边界上构建门诊诊疗建议链，当前运行合同见[临床决策支持与质控](../../../architecture/clinical-decision-support.md)，文献来源见[临床推荐指南研究](../../../research/2026-10-13-clinical-recommendation-guidelines.md)：

1. **受核验指南依据、真实目录归一化与双阶段语义复核**：`DoctorRecommendationsService` 仅从当前责任医生的公开读模型采集本次问诊、病历、报告与授权历史（含[院后复诊的已出院住院临床摘要](2026-11-12-outpatient-workflow-domain-split.md)），结合[免费指南全文库](2026-10-16-free-guideline-corpus.md)与[共享指南专题注册表](2026-11-17-shared-guideline-topic-registry.md)提供按患者人群隔离的原文条款。候选按本院真实目录归一化（病理限定可见既往手术，处方读取冻结产品规格但缺依据字段保持 `null`、绝不填入目录默认用法用量），再经独立模型请求逐项核验临床证据支持与限定语保留：合法 `false` 保持否定结论不触发格式修复重试；仅当非处方候选病例复核成立但缺指南或院内目录时，才降级为不带执行身份的只读病例思路（`considerations`）。
2. **UTF-8 字节打包、紧凑索引筛选与超限收敛轮**：本次就诊与安全必读资料（诊断、过敏、用药、设备、手术、本院完诊／出院记录及异常或无解释标记的 Observation）始终保留，历史记录统一按 `12 KiB` UTF-8 字节（兼守 12,000 字符上限）无损按完整字段拆包。全部资料可装入单次请求时直接生成；超出时先执行最多 8 批、2 并发的历史筛选（筛选请求中必读与已选证据降为紧凑索引，模型只返回原证据包编号而不改写摘要），若合入生成请求仍超 `240 KiB` 载荷／`256 KiB` 信封，则执行一轮受[模型执行账本](2026-10-21-model-request-control-recovery.md)管理的 `history-consolidation` 收敛请求（容量为 0 时直接保留必读资料并附处理说明，仍超限则显式报缺证而不截断必读安全资料）。存在检验目录项时始终执行紧凑目录视图（不含 `reportDefinition` 与参考范围）筛选审计，确保生成仅引用已审目录项，独立核验与落盘继续使用完整真实服务定义。
3. **代次指纹防过期与人工草稿保护**：`doctor_recommendation_state` 持久化输入指纹、状态与代次；排队与完成写库二次核对指纹、目录可用性与责任岗位。前端按临床资料版本拉取而不重建编辑器，人工输入始终优先，待开具清单的显式勾选、防过期与正式开立由[待开具项目原子确认](2026-10-18-prepared-clinical-confirmation.md)承接。

## Alternatives considered

- **直接将建议写入正式诊断／处方／申请，或把核验否定当作格式错误重试**：混淆辅助候选与医生处方权，诱导模型改口放行无依据建议。
- **仅截取近期首页历史、用模型摘要代替原文包，或摘要／截断必读安全资料**：遗漏远期过敏／手术等关键安全信息或丢失原文限定语；筛选阶段改传必读紧凑索引即可在不裁剪生成阶段必读全文的前提下解除批次塌缩。
- **按字符数估算中文请求体积或拆批执行最终生成**：中文 UTF-8 三倍体积会击穿 256 KiB 桥接上限，而拆批生成会丧失全病例综合判断视野。

## Consequences

多年复杂病史病例可在受控批次数与 256 KiB 信封内完成全候选筛选并保留完整必读安全原文进入生成与核验；必要资料自身超限时明确提示不完整而不静默丢证据。确定性目录与独立模型复核能拦截虚构编码和明显失实引用，但不能替代临床医生的最终适用性判断。
