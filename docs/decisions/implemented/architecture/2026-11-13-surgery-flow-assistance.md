# Agent Note: 住院手术流程指引、DRG 费用预计过渡、受限后台跟进与术后核查交接

Status: implemented

## Problem

住院冠脉介入从术前准备、术中耗材消耗、完术核实到术后主操作确认与病案归档横跨多个阶段与角色。若页面首行、步骤条与底部操作栏各自判断下一步，会导致耗材确认与知情同意互相抢占；若每次耗材或待办动作都无差别触发模型请求，既浪费配额又因页面短期 `PageContext` 关闭而丢失后台授权边界；若 PCI 刚完成而医生尚未在病案页确认主操作时，头部费用条立即从术前计划的 FM39 参考切回先前造影的 FM59，会制造“刚做完手术就超支”的假警报；而在多台手术或病案归档／撤权后，若无独立核查修订与岗位交接，历史差异待办要么被第二台手术覆盖，要么因延长旧后台权限而越界。

## Decision

整合确定性步骤指引、术后主操作待确认预计过渡、受控后台跟进计量与按已完成手术隔离的核查责任交接，详细业务与界面合同见[住院与手术流程](../../../architecture/inpatient-workflows.md)、[收费、结算与医保](../../../architecture/billing-and-insurance.md)及[临床 UI 设计](../../../ui/design.md)：

1. **单一术前下一步判定、等效低价提示与多计划净差额预计**：工作台与手术页共用同一客户端状态与正式查询顺序衔接“选型参数 → 耗材确认 → 知情同意 → 护士术前核对 → 开始手术”（选型重审仅随真实选型修订与确认来源触发，不因普通收费或申请版本递增误判）。版本化合成依据包显式声明同类别、同规格、适用兼容的等效耗材组，接近参考阈值时仅在等效组内提示更低单价候选（绝不建议减量、改规格或改术式）；多手术计划的工作稿各自贡献相对原预留的净增量，统一汇入全住院费用推演而不重复叠加总额。
2. **术后待确认主操作的 `postoperativeEstimate` 平滑过渡**：费用推演只读返回 `postoperativeEstimate`，当存在实际已完成手术但最新首页修订尚未覆盖该操作时，若唯一新候选或全部候选得出一致病组与同身份支付参考，患者头部紧凑费用小条（见[住院岗位单行头部](2026-11-03-inpatient-prototype-composition.md)）即展示该预计参考并明确标注“待确认主操作”（多候选不一致或缺价时如实显示未知，避免回退旧 FM59 误报超支）；医生在[在院病案页保存主操作](../bug-fix/2026-11-13-inpatient-primary-procedure.md)后自然切回正式预分组，全程零自动代选主操作。
3. **受控后台跟进（`InpatientDrgFollowup`）与仅偏离触发助手**：`InpatientDrgFollowup` 持久化本次住院的稳定任务身份与启动岗位授权版本，每次后台读取、派发与发布均经 `IdentityService.modelTaskContextStatus` 重验住院责任，并复用 `ModelUsageService` 与 `ModelTaskRecovery` 逐次记账（住院 DRG 用量人工修订须同时具备管理员资格与当前病例读取权限）。计划内耗材登记直接走确定性单笔 Command，仅偏离冻结计划的登记按实际使用身份去重触发独立说明任务（手术申请理由另用只读已确认诊断与造影报告的独立草稿任务）；完术核实打开即按已登记有效量请求预览并汇总超计划笔理由，默认折叠无差异数量编辑（常规免备注规则见[手术耗材最终核实决策](2026-10-30-surgery-final-material-reconciliation.md)）。
4. **按已完成手术隔离的术后核查与归档责任交接（`InpatientDrgReview`）**：核查以每台已完成手术及其关联冻结术前计划为独立键保存不可编辑依据快照、紧凑差异清单与岗位待办（待办点击不重跑模型；问题仅在最新正式临床／账务事实复查消除后标为已解决，人工“无需处理”须记录岗位与理由；收费员仅见财务疑点）。停止跟进、撤权或病案归档后立即停止新模型分析，由当前有效人类岗位经交接承接未解决待办且不增加出院硬门禁（无需开启持续跟进的按需分组记录核对与单次解释见[分组记录核对决策](2026-10-30-drg-record-checks-on-demand.md)）。

## Alternatives considered

- **PCI 完成后自动设为主操作、沿用术前缓存金额，或回退比较旧正式参考**：分别越过医生主操作确认权、忽略术中实际诊断／费用变化，或把待确认空窗误报为超支异常。
- **每笔术中登记与每次点击待办都触发模型调用，或按规格字符串模糊推断低价替代品**：浪费模型配额且模糊匹配无法证明器械兼容与临床等效。
- **用最新手术计划覆盖整次住院核查依据，或为完成交接延长已撤销的后台任务权限**：抹除前序手术未结差异，破坏权限即时撤销边界。

## Consequences

术前准备、术中偏离、术后主操作待确认窗口与归档交接在确定性规则与受控模型辅助之间保持清晰边界：金额、分组与等效候选完全由程序决定，模型仅提供可追溯说明且失败不阻塞手术完成与出院结算。
