# Agent Note: 临床建议与病历质控的具体说明

Status: implemented

## Problem

诊疗建议把病例缺项、指南未覆盖、院内不能执行和独立核验失败汇总为“缺少依据”，模型顶层清单又可能把所有未记录事项变成前置门槛。病历质控的自由文本缺少影响和动作，任意 missing-field 及宽泛官方书写原则无法约束具体临床推断。用户需要能理解并核实的说明，且已允许显示无指南支持的待核实诊断或检查思路。

需求分别由[诊疗建议规格](../../../../docs/spec/2026-10-13-doctor-guideline-recommendations.md#待核实思路与说明)和[病历质控规格](../../../../docs/spec/2026-10-15-doctor-document-quality-control.md#说明与判断边界)拥有，既有[来源与草稿决策](2026-10-13-doctor-guideline-recommendations.md)及[质控输入归属](2026-10-15-doctor-document-quality-control.md)继续约束原有边界。

## Decision

把可采纳建议与只读思路作为不同的结果类型。可采纳建议继续要求真实指南和院内身份；无指南或无目录时仍可提出病例推断，独立核对事实及限定语，输出不携带执行身份。只有指南支持不足而病例复核成立的非处方候选可以降为思路，不能通过降级重新发布事实不成立的内容，也不补造处方字段。

系统限制按真实执行结果归类，显示相关条目、未通过环节和已有具体原因。病例待核实事项只附在相关条目下，生成及复核共同判断其是否影响该项决策；模型顶层长清单不直接发布。保留来源与时间，患者在家未测、分诊已有记录、未安排的检查以及系统不能核验分别解释，不互相替代。

质控新问题给出具体摘要、影响和最小处理动作，语义复核覆盖整个说明。确定性规则限制缺项适用范围，避免仅靠提示词让任意字段成为必查要求。一般书写原则保留为背景，具体模型判断作为项目辅助；说明含义参与问题关联，策略变更使旧结果失效。新增字段兼容读取旧持久数据，不为旧条目捏造解释。

## Alternatives considered

- 只改标题或润色提示词，无法解除无指南的提前返回、阻止伪缺项进入质控或说明具体核验原因。
- 放宽所有候选的指南与事实要求，会把未经支持的推断变成可采纳诊断、检查或处方。
- 从自由文本猜分类、删除关键词或补写缺失事实，不能稳定区分来源、时点和真实缺口。
- 为两类说明建立通用评估框架，会引入不必要的协议与状态；继续使用原有 owner、预算、模型桥与医生操作即可。

## Consequences

两类结果共用完整输入、独立复核及原有预算，思路不会写入草稿或正式事实。质控保持独立持久化与非签署门槛，人工修改、核实保留和最终确认继续归原有 owner。运行行为由[系统架构](../../../../docs/architecture/clinical-workflows.md#81-门诊闭环)拥有，验证入口见[测试策略](../../../../docs/testing.md#end-to-end)。

结构与来源校验能拒绝错误身份或不允许的缺项类别，语义说明仍依赖模型，存在误报、漏报和过度保守的可能。合成回归与有限实模样本不能替代全面临床质量验证；医生仍需核对来源和具体适用性。
