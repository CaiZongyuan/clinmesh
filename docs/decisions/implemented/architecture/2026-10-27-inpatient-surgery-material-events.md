# Agent Note: 同次手术逐笔耗材与原费用更正

Status: implemented

完成时自动关闭本计划余量的策略已由[最终耗材核实决策](2026-10-30-surgery-final-material-reconciliation.md)部分替代；逐笔事实、追加更正及共享收费 owner 的取舍继续适用。

## Problem

一次性手术执行把实际操作、全部耗材、收费和完成状态放在同一个意图中。逐笔复用它会提前完成手术、重复记术式费，并使部分预留与已发生使用失去区分。直接覆盖原数量又会删除原记录及收费依据，无法解释术中增补或记录错误。

## Decision

手术 owner 以同一实际 Procedure 保存 `in-progress` 与 `completed`，开始、单笔材料确认、记录更正和完成分别经过窄 Command。原一次性完成入口保留整笔预留合同，并复用同一实际事实与计费写点；已经开始的手术只能继续原实例。分组与首页只消费已完成集合，术中事实独立返回；新集合和历史字段允许读取旧持久输入。

原材料使用和收费保存为不可覆盖事实。更正追加对原使用的说明、原费用精确冲正引用及可选替代使用；当前有效使用排除已更正条目，历史仍可回查。已有收费员冲正只引用一次，不自动把单独财务冲正解释成临床事实变化。收费员与手术更正共用 `InpatientBilling.reverse`，岗位授权留在各自业务 Command；不提供任意反向金额或另一套费用账。

预留保留原数量，分次使用增加消耗并核对版本，费用推演只计余量。完成只收一次术式费，并收拢明确绑定本手术的未用余量；未绑定的住院后续计划保留。术后记录纠错允许在病案未归档且账户开放时处理，退回本手术的余量继续收拢，不使已结束手术重新产生计划费用。

当前合同见[住院手术](../../../architecture/clinical-workflows.md#住院手术最小闭环)，正式验收由[PCI 住院 Agent 规格](../../../spec/2026-10-27-inpatient-drg-agent.md)拥有。

## Alternatives considered

- 每笔材料调用一次性执行：会重复完成操作，无法表达剩余计划，保留独立开始与完成意图。
- 修改原材料数量或原收费金额：会失去原始记录与账务依据，采用追加更正和关联冲正。
- 另建可编辑术中费用账：会分裂正式收费 owner，继续复用共享收费与原费用关联。
- 完成时释放全部住院预留：会误删未归属本手术的后续治疗计划，只收拢显式绑定的余量。

## Consequences

材料记录更正不代表实际取出器械、退库存或改变医生治疗方向。缺单位、跨病例、旧版本、超预留、已经更正、账户结算与归档均拒绝写入，未知结果按原幂等身份查回执。新增使用及更正进入建议与费用依赖，不能继续把旧建议作为当前依据；模型更新仍由病例跟进 owner 发起。
