# Agent Note: 住院 PCI 测量来源、费用说明与术中模型调用

Status: implemented

## Problem

住院 PCI 的耗材建议要求医生先手填测量、数量依据并逐项认可候选，AI 只在医生已决定的范围内复核，医生工作量没有减少。系统中没有任何环节自然产生结构化测量：检验报告不含造影所见，造影 Procedure 只有自由文本说明，病例作者底稿只能由仿真侧读取。

持续跟进的耗材分析把 DRG 规则未启用、分组未完成和缺少支付参考写入模型分析缺项，三者任一出现就停止派发；部署默认不启用规则，因此开启跟进后 AI 实际不工作。术中每次登记耗材都触发生成和核验两次模型请求，而模型必须原样返回规则算出的剩余数量，只增加一句理由。

## Decision

由仿真侧在诊断性造影完成后读取 Case Truth，按规则或模板生成本院正式造影报告及结构化测量，与检验报告共用隔离边界：报告成为正式事实后才可被医生和建议模型读取，Case Truth 不进入建议模型。保存 PCI 计划时，系统按规则把报告中的测量逐字段复制到选型草稿并绑定报告身份和版本；没有报告时保留手填路径。

测量来源由服务端对照绑定的正式报告核实，不能随客户端传回的 `source` 一起无条件保存。对象、部位、数值、单位或方法任一变化后，该测量改为人工修订来源；其余未改测量保留报告来源。原报告身份和版本继续独立绑定，避免人工值被误认为报告原句或测量，也不回写报告原件。

医生对带出处的参数、AI 起草的清单和费用确认一次，同一共享 Command 原子写入选型确认、术前清单快照和预留。

页面的初次检查不能覆盖异步身份预检期间的计划或页签切换，因此共享写入口在发送前再次核对调用者提供的当前视图守卫。守卫是本地闭包，不进入持久意图；尚未发送的旧操作停止，已发送而丢失回执的原意图仍按原输入和幂等键恢复。视图可见性与会话身份分别保护，避免同一医生切换病例或离开审阅后继续提交旧确认。针对住院的完成与交接反馈也绑定原命令的住院身份，避免晚到回执使用当前另一病例的姓名生成提示。

DRG 推演结果只作为费用说明的数值来源，不再是模型分析的前置条件；DRG 不可用时以自然语言说明原因。术中改为规则计算的实时费用板，不自动调用模型，解释按需请求。术后用量与收费差异随正式事实直接计算，不依赖持续跟进。

当前工作稿与已确认选型由同一个选型模块提供不同读取视图，复用候选和认可集合的判定。用量回顾按手术申请读取已确认视图，避免较晚手术的确认或同手术未确认修订改变旧用量依据；费用模块不复制候选算法。有效清单仍优先，参数回退不建立正式清单，也不能把证据缺失或冲突转换成已确认计划。

正式需求与验收见 [住院 PCI AI 减负需求（Issue #374）](https://github.com/CaiZongyuan/clinmesh/issues/374)；同一审阅区中指南参考意见与具体清单分开表达的取舍见[指南参考意见 Agent Note](2026-11-02-inpatient-pci-guideline-advice.md)。

术后材料与财务核对是正式事实的确定性派生，不依赖原模型任务继续持有授权。内部事实接口只接收受信的 Workspace/Epoch/Admission 范围并复用原手术、费用及确认快照，公开读取和处置继续校验当前 Actor 并按岗位裁剪；模型仍按原任务授权停止。这样，原 Agent Grant 撤销后，后来合法提交的费用及临床更正仍能解决原待办，无需借用失效的医生上下文或创建另一套规则。

## Alternatives considered

- 由模型读取报告提取测量：报告本身由本系统以结构化形式生成，复制字段更准确、可追溯且不消耗请求；只有报告变为自由文本时才需要提取并另加独立核验。
- 术者在造影 Procedure 上增加结构化测量字段：减少重复录入，但仍需人工输入，不能让 AI 先起草。
- 术前不要求尺寸，只给类别与费用说明：医生填写最少，但术前无法形成具体清单和预留。
- DRG 不可用时禁止开启持续跟进：行为保守，但在默认部署下等同于该能力不可用，而耗材清单与目录价格并不依赖分组。
- 保留术中逐笔自动模型请求并加入医保信息：模型输出仍被剩余数量完全约束，增加请求与等待而不增加决策信息。
- 扩充同类耗材候选以比较价格：需要新增多款合成适用与兼容依据及正反对照，单独规划。

## Consequences

- 正常演示与验收从造影报告进入 PCI 准备，无报告的既有病例继续使用手填流程；报告生成不调用模型，私有 Case Truth 不进入医生或建议模型。
- 合成选型依据仍只覆盖单病变、固定管径与每类一件；造影所见超出范围时不能形成可确认清单。
- 一次确认同时承担选型认可与整批预留的业务责任，沿统一 Command 保留原子事务、幂等恢复及版本检查；CLI、Operation Catalog 与运行时 Skill 共享相同合同。
- 当前测量来源、费用说明及术后差异边界由[临床业务流程](../../../architecture/clinical-workflows.md#手术计划的单次耗材预计)维护，仿真侧来源隔离由[仿真合同](../../../architecture/simulation.md#105-case-truthpersona-与-action-trace)维护。
