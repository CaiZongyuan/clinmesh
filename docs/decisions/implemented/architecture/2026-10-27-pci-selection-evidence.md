# Agent Note: PCI 参数确认与有限合成选型依据

Status: implemented

## Problem

住院手术目录已有具体合成耗材、收费和来源价格，但这些事实不能证明患者测量、产品适用或器械兼容。固定单枚支架的病例作者底稿也不是医生确认的临床计划。后续住院 Agent 需要可引用的参数版本与可核验候选，同时不能将合成规格冒充真实产品 IFU。

## Decision

参数确认归住院临床 owner，以本次住院保存追加的确认版本，可引用本次有效手术计划；不依赖后台跟进任务。每条测量保留对象、部位、方法、单位和来源标识／版本，数量由医生独立计划，未知项保留未知。确认通过共享 Command 的病例授权、预期版本、幂等键与归档锁执行，旧确认历史保持可读。

候选读取联接本院实际安装的产品与版本。固定依据包明确声明有限合成仿真条件、组合兼容及数量适用范围；只有医生认可、测量与数量满足该仿真条件且组合版本可用时，候选才可供后续模型建议消费。缺项、矛盾、真实来源超出仿真验证范围或目录漂移均保留原因。原价格来源和合成产品规格分别展示；不声称获得真实临床选型金标准。

当前读取与确认合同见[临床流程](../../../architecture/clinical-workflows.md#pci-参数与候选依据)，正式验收由[PCI 住院 Agent 规格](../../../spec/2026-10-27-inpatient-drg-agent.md)拥有。

## Alternatives considered

- 将参数附在后台任务：会使临床参数依赖跟进任务生命周期，并产生影子病历；采用独立临床 owner。
- 从固定耗材尺寸与单枚支架底稿反推测量和数量：没有患者事实依据；保留人工录入与独立数量计划。
- 将全部候选标为未知直至取得真实器械 IFU：无法提供规格要求的可核验仿真样例；采用明确标识且有独立正反对照的有限合成范围。
- 将价格目录中的产品直接标为可推荐：价格、单位和企业不能证明临床适用或器械兼容；候选必须通过独立证据核对。

## Consequences

依据包只证明明示的合成条件，不自动推广到其他规格、数量、病例或真实产品。未来扩大支持范围须补齐相应独立依据与对照样例，并更新依据版本；参数历史和既有正式手术／费用事实继续保留。
