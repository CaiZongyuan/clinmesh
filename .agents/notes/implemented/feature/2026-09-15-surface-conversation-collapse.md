# Agent Note: Surface 会话整体收起

Status: implemented

## Problem

ClinMesh 的 workspace 布局把 DSH 会话放在右侧，但应用全屏同时遮住左侧导航，不能替代会话收起。会话的原生文件栏还拥有独立开合、文件选择及展示状态。任务合同见 [issue #101](https://github.com/CaiZongyuan/clinmesh/issues/101)。

## Decision

Surface registry 按应用保存内存中的会话收起状态，默认展开，切换布局或关闭再打开应用均保留，注销应用后释放。状态不写入分栏宽度偏好；全屏仍由既有布局接口控制。ClinMesh 页头右侧提供会话开关，登录、加载和错误页面保留恢复入口；全屏下通过返回分屏恢复此前状态。

通用 Host Adapter 同时隐藏会话与原生文件区域，保持 DOM 挂载、原生文件开合和选中状态。应用覆盖释放的空间，左侧导航不受影响。隐藏区域设置 inert、aria-hidden、visibility 和 opacity；原生文件面板显式设置 visibility:visible，单独隐藏祖先不足以阻止其显示。恢复和卸载通过现有 effect ownership 机制撤销适配层效果，不调用关闭文件、取消任务或重建会话操作。

DSH 官方源码保持原样，通用显示协调归属 dsh-react-surface，医院界面仅调用公开接口。文件栏保留原生呈现方式。纯布局及 registry 测试覆盖尺寸和状态，浏览器集成测试覆盖挂载连续性、原生草稿、文件选择、滚动位置、全屏往返和清理。

活动 Surface 的宿主 overlay 位于原生全屏文件与浮动文件层之上，保证文件全屏或窄窗口时应用页头的收起入口仍可点击；文件不会覆盖应用所占区域。挂到 body 的原生浮动文件也随会话隐藏，body 的直接子节点监听负责捕获后续创建和移除的浮窗。关闭应用时恢复原 overlay 层级和浮窗呈现。层级值绑定当前 DSH 0.1.5-rc.2 兼容基线。

## Alternatives considered

**使用 full-frame 代替收起。** 会同时遮住左侧导航，无法满足只释放右侧辅助区域的需求。

**关闭原生文件栏后自行恢复。** 会引入第二个文件状态 owner，增加开合及异步更新竞争；保留原生状态并隐藏整个区域即可满足需求。

**改造 DSH 或强制覆盖式文件预览。** 不符合官方宿主维护边界，也不是本次交付所需能力。

## Consequences

收起不会取消任务，仍挂载的会话继续接收更新。刷新页面后默认展开；用户分栏宽度仍由既有持久化偏好拥有。依赖宿主语义节点及原生文件样式的兼容性需要在 DSH 升级时验证，不能仅凭单元测试推断真实宿主表现。
