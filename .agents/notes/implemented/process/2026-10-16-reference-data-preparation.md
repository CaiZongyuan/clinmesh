# Agent Note: 参考资料先形成可追溯清洗候选包

Status: implemented

## Problem

五类医保与价格资料的 MinerU 合并包可以保真保存原始识别结果，但页数、哈希和分片连续不证明编码、跨页表格或规则语义正确。直接转成当前 ReferenceArtifact 会把尚未核实的条件和价格混入已启用目录，也不能表达 DRG 列表、排除关系与未知价。

## Decision

采用离线候选包作为资料归档与正式 Reference Release 之间的审核边界。工具、字段与运行方式由[清洗工具说明](../../../../scripts/reference-preparation/README.md)拥有。候选包同时保存原件、标准化行、机器修正证据、待复核项和跨库报告；任何修正保留原始值与 PDF 单元格或页定位。包内脚本只归档，不作为指令执行。

ICD 对照 PDF 矢量网格，按字形定位，避免编码与拉丁名称在文字层粘连后跨列。只验证文本保真，不把机器核对改称人工审定。DRG 保存完整条件正文与列表关系，保留排除表引用，不从文字列表推断可执行的与或优先级。省级价格、医保支付标准、院内收费与成本是不同事实；资料未提供的值明确留空。

候选包不会直接进入现有签名同步链。正式发布仍须由 owning Dataset 提供 schema、许可、来源版本和适用范围，再经现有 Reference 同步及验证机制形成新 Release。运行时和历史业务事实的边界沿用[系统架构](../../../../docs/architecture.md#54-中国术语与参考数据策略)，评估需求沿用[DRG 设计方案](../../../../docs/spec/2026-10-15-drg-prescription-budget.md)。

来源复核与院内参数齐备分别建模。原表明确的条件价格保存适用条件和规则，分类标题保留身份及子项关系；自主定价和地方价表缺口进入等待外部资料状态，不通过静默填零或借用邻行价格消除异常。每轮复核生成新候选包，保留前版问题与逐字段变更证据；主目录与附表问题共同进入汇总。官网字典身份确认不能自动证明与另一规则版本兼容，完整编码仍须逐条检查。

## Alternatives considered

| 方案 | 未采用的原因 |
| --- | --- |
| 用合并包的完整性报告直接代替数据验收 | 完整保留也可能完整保留错误编码或空正文页 |
| 全局把数字零改成字母 O，或截断后缀后跨库匹配 | 会改变合法字母、前导零及扩展码，掩盖真正版本差异 |
| 只保留修正后的 CSV | 会丢失原始值、层级和定位；表格软件还可能改变编码类型 |
| 为本批资料绕开签名链直接写 Reference SQLite | 当前 schema 未覆盖全部新类型；导入成功不能提供来源与适用性验收 |

## Consequences

来源参考的用途化发布与应用内合成评估由[模拟实现决策](../architecture/2026-10-18-drg-simulation.md)补充：本地清洗清单与文件逐级固定哈希，不冒充上游签名 Dataset，也不将发布等同临床和院内计价启用。

大文件和生成结果保留在 `.data/` 或仓库外，不进入 Git。清洗工具及边界回归在仓库中复现，候选包独立保存完整校验清单。待复核和未知字段是显式数据状态，不能因发布方便而静默删除；正式分组语义、地方支付参数和院内产品价格映射仍需各自验收。
