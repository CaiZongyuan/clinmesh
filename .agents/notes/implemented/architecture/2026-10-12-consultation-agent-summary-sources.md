# Agent Note: 问诊病史总结与多轮自述溯源

Status: implemented

## Problem

逐句摘录可以确定性证明原文归属，但跨轮问诊产生重复、口语化的病史。允许改写后，原文匹配只能证明患者说过引用，不能证明总结忠实；整字段重写又会覆盖人工编辑与其他自动片段。需求由[病史总结规格](../../../../docs/spec/2026-10-12-consultation-agent-summary-sources.md)拥有。

## Decision

每个总结片段保存有序事实，每项事实包含总结文字和一个或多个患者轮次的完整原文引用。正文由事实文字连接；引用只指向同 Workspace、Epoch、病例中截至当前回答已保存的 patient text。来源查看显示事实与轮次关联、完整回答、引用高亮、相邻医生问题和原时间。患者自述仍是自述，居家测量与外院诊断不升级为本院事实。

来源校验与界面高亮共用完整句定位：同一引用先出现在其他句子内部时，跳过该匹配，定位首个满足句界的出现位置。没有合法完整句匹配时保留完整回答而不高亮，避免把否定句中的局部文字展示成事实依据。定位和片段锚点共用 `core` 中的纯文本句界规则，保留 LF、CRLF 分隔。

生成与独立忠实性核对共享同一持久任务的固定模型和终止信号，DSH 窄桥接合同明确允许 `consultation_history_summary` 与 `consultation_history_verification`。确定性边界检查来源、完整句界、字段与目标归属；引用校验与片段锚点共用句界规则，保留 LF、CRLF 分隔，只去除句间水平空白。独立核对检查引用是否支持每项事实、否定和限定是否保留、更新是否丢失旧事实，以及新增、归并、更正和矛盾关系是否成立。关系判定依据全部事实及引用，不依赖兼容字段中的单条代表引用或其关键词。核对的否定结论是正常模型输出，不能作为格式错误要求模型改成肯定。未通过核对的结果不写入草稿，使用既有有界失败与显式恢复。

两阶段共享[既有任务总预算](../bug-fix/2026-10-08-consultation-model-output-budget.md)，各请求至多修复一次结构；前一阶段耗时会减少后一阶段的剩余时间，总预算耗尽按已有超时失败收敛。内容中的不确定性保留规则由本决策拥有，取代旧提取器整句跳过不确定陈述的策略。

`update` 归并相关新信息并替换一个未被人工修改的自动片段；`correction` 保留旧自述和明确更正证据；`conflict` 保留矛盾双方供医生核对。替换保存前一片段全文、来源和状态，撤销恢复前一版本及其来源。片段被人工编辑后归属医生，后续总结成为待核对建议；无关片段仍可独立更新。片段粒度是总结语义组，组内局部编辑保护整个组，不进行不可靠的字符级事实重写。

撤销或忽略保存该总结的全部事实引用为已拒绝证据，按字段、患者轮次和归一化句尾识别，不受引用顺序影响；旧摘录沿用原单条引用。仍被当前有效且未拒绝片段使用的引用保留，用于恢复前一版本后继续归并其事实；其他已拒绝引用从候选中逐项移除，没有剩余来源的事实不进入总结，没有剩余事实的候选直接跳过。剩余事实以移除后的来源进行忠实性核对，不能用无关新引用支撑混入的旧事实；不对一个事实内部的文字作不可靠拆分，失去必要来源时使用既有有界失败与显式恢复。多项事实共用原话时，独立核对同时比较已拒绝事实和当前有效病史，只有本次回答重新支持相应已拒绝事实才能恢复，不能因另一事实仍有效而重新开放整个旧引用。

过滤后的候选先校验引用与目标，再要求至少一条来自本次回答且未被拒绝的引用；仅重写旧回答不改变草稿或重新形成建议。同样内容由新的患者轮次再次提供时可形成新建议。共享 Command 写入时重新读取全部拒绝事实；若与生成和核对时的快照不同，不在事务中缩减已经核对的来源，而是使用既有有界重试重新生成、过滤和核对，再检查本次回答条件，保留医生在模型处理期间作出的拒绝决定。

旧摘录和旧 Command receipt 保留原字段及标识。新迁移为总结增加事实 JSON 与 `update` 关系；没有事实 JSON 的旧摘录继续使用原文、旧锚点恢复和旧来源入口，读取不重写正文。新 Query 返回 `summary` 和 `facts`；旧回执允许缺省这些字段并使用原 `sourceTurnId` 回退。生成、保存、核对、暂停、撤销和签署仍由现有共享 Command owner 执行。

本决策替代[增量摘录](2026-10-08-consultation-history-increments.md)中的正文逐字约束；[片段归属](2026-10-08-consultation-history-ownership.md)、[审阅与撤销](2026-10-10-consultation-history-review-undo.md)和[签署准备](2026-10-10-consultation-signing-preparation.md)的控制边界继续适用。

## Alternatives considered

- 只修改提示词：原来的正文构造仍复制 quote，且单来源无法支撑跨轮总结。
- 每次重写三个完整字段：可以得到统一文风，但人工编辑、独立片段的撤销与迟到结果难以可靠隔离。
- 用关键词、数字匹配替代语义核对：无法判断否定、因果、时间、外院来源或错误关联，也容易把忠实改写当成失败。
- 只信任生成器的自我声明：合法引用并不能证明事实得到引用支持；保留独立核对边界，同时承认模型核对仍有概率性局限，临床签署继续要求医生审阅。
- 持久化引用字符范围：可以固定高亮位置，但当前来源回答不可变，共享完整句定位即可保持校验与展示一致，无需增加 wire 字段与迁移。
- 整段总结只检查一条新引用：无关新事实会夹带恢复已拒绝事实；逐项移除拒绝引用并重新核对语义，保留当前有效前一版本和患者再次提供同一事实的能力。

## Consequences

多轮归并与逐项来源可以持久核对，更新和撤销保持已有人工及签署边界。生成需要额外的一次有界辅助模型请求；真假语义不能由 JSON schema 穷尽证明。HTTP 回归覆盖拒绝后重启及引用重排、无关新事实夹带旧事实、一个事实依赖拒绝与新来源、多事实共用引用、处理中撤销、无新证据的旧总结改写、新轮次重新提供证据、其他事实之后的更正引用，以及 LF、CRLF 分行来源。浏览器合同断言完整原文及高亮前后位置。CI 使用改写总结和独立核对替身，真实 DSH 验收用多轮合成问诊核对病史质量、引用和刷新行为。旧状态机回归通过测试适配器沿用摘录形状的夹具，不能充当新总结质量的验收证据。
