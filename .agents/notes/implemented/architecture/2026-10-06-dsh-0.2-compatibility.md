# Agent Note: DSH 0.2 消息与桥接兼容基线

Status: implemented

## Problem

DSH `0.2.0-rc.2` 的 Cordis、工具结果消息、上下文来源和预设注册合同已不同于 `0.1.5-rc.2`。仅提高 ClinMesh 的宿主版本会让旧 React Surface 与 AG-UI 依赖失配；只修改 peer 声明也不能证明实时工具结果、持久会话恢复和页面入口可用。

## Decision

ClinMesh、React Surface 与 AG-UI 使用同一组精确宿主依赖和 Cordis `4.0.4`。React Surface 采用上游重命名后的 PTC runtime；AG-UI 从独立 `ToolResultMessage` 读取 call ID、结果内容和错误状态，并为自身注入的 snapshot 声明独立消息来源。AG-UI 的可选预设组合通过宿主声明式 registry 提供，持久化验证使用宿主公开的会话格式版本。消息和预设适配由各自桥接仓库拥有，ClinMesh 通过精确支持提交复用，不复制实现。

当前主会话由 DSH 0.2 的公开 `uiSession.adapter.current` 绑定拥有，`sessions.list` 不再包含 current。React Surface 的 lease、ClinMesh 的 Page Context 与病例右栏都订阅同一绑定的 key；选择、切换或清除会话时同步更新或释放能力，不能依据旧列表字段推断会话。

ClinMesh 的病例右栏 guide 使用稳定的业务标签 kind 作为引导项身份，满足新宿主的必填 ID 合同。医院 Query、Command、Page Context、execution proof 与人工审阅边界沿用现有接口；宿主升级不改变正式业务写入路径。

Profile 只声明三个外部桥接插件的链接依赖；内置的 `dsh-base` 与 `dsh-web-app` 仍列在 bundle 清单，但由宿主槽位的 npm 锁提供。Profile 不再重复安装宿主依赖闭包，否则配置编辑器可能解析到另一份 `dsh-app-boot`，无法访问启动时登记的根 Include。候选 smoke 除 HTTP 首页外，还向隔离 Profile 写入专用设置标记并核对返回值；标记不同于宿主预览提示的确认版本，不代表用户接受提示。设置热重载失败时保留具体原因并拒绝推进锁。

宿主安装 manifest 显式允许运行所需的 subprocess helper、koffi、node-pty 和 protobufjs 安装脚本，并拒绝 Google GenAI 的占位脚本。npm 的默认脚本拦截不能使宿主只完成包解压而遗漏原生运行支持；这份 policy 与已锁定的宿主依赖共同供 launcher 和候选验收复用。

统一 launcher 在复用工具目录前核对已安装 dshvm 的 manifest 版本。旧版、缺失或非法 manifest 触发按锁重新安装工具，不能仅凭 CLI 路径存在跳过升级；仍有效的宿主槽位、Profile 和 bridge 构建继续复用。

源码支持提交写入人工维护的候选目标，上一份机器人发现清单保持其原有归属。只有隔离安装、宿主加载与仓库检查通过才推进升级分支的已验证锁。自动证据与原生 Session 的人工验收仍按[候选验收决策](../process/2026-09-15-dsh-upstream-candidate-verification.md)分开表达。

## Alternatives considered

**只改 peer 版本或放宽兼容范围。** 旧 AG-UI 将工具结果当作嵌套 content block，无法读取新消息的 call ID 和错误状态；声明兼容不能修复行为。

**在 ClinMesh 内复制桥接适配，或修改 DSH 宿主。** 这会让共享协议拥有多个实现，并破坏对公开宿主发行的复现。支持提交留在 bridge owner，宿主发行内容保持原样。

**让自动发现清单接管人工支持提交。** 自动发现与人工目标是不同事实；同步两份文件会丢失防止机器人覆盖支持目标的依据。

## Consequences

AG-UI 的合同覆盖空工具结果、实时与冷恢复的 call identity、snapshot 来源、预设组合、旧日志迁移和 browser broker。React Surface 保留共享 React API、样式隔离和产物约束；ClinMesh 的 React 18/19 浏览器合同与真实入口验证继续承担应用侧兼容证据。升级锁中的源码提交必须可从对应公开仓库重新检出，日常 Profile 与医院数据库不参与隔离验收。
