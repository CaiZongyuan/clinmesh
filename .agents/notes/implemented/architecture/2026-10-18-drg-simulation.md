# Agent Note: 清洗目录按用途发布并隔离住院 DRG 模拟事实

Status: implemented

## Problem

五类清洗资料包含国家编码、历史省级价格、未知金额、规则正文与未解决的跨库差异，无法直接当作当前医院目录或可执行分组器。当前 HIS 的门诊收费与处方有自己的事实 owner；住院模拟不能借用门诊病例身份，或另外复制门诊账务后双向同步。

## Decision

在同一个 Reference SQLite 中增加 `prepared_reference_release` 和 `prepared_reference_record`，发布完整的来源参考快照，保留每条 JSON 原始值、规范值、定位、备注关系与用途状态。`reference-data.lock.json` 的 `preparedRelease` 固定本地发布清单 SHA256，清单再固定每份 JSONL 的哈希和行数；同步复用 `pnpm reference:sync` 的迁移与离线发布入口。此来源是本地清洗档案的哈希固定发布，不冒充 `cn-health` Registry 的签名认证；已有三个 Dataset 的签名链继续执行。生成文件与 SQLite 不进入 Git，重建方法归属[部署说明](../../../../docs/deployment.md#3-同步参考目录推荐)。

来源参考的发布允许保留存疑、缺失、保密或明确不适用的记录，禁止据此自动启用临床分组或计价。查询能读取完整来源，计算只使用有明确版本的合成映射。此用途分离承接[离线清洗决策](../process/2026-10-16-reference-data-preparation.md)，应用内合成部分落实[DRG 评估提案](../../proposed/architecture/2026-10-16-drg-cost-assessment.md)，正式地区能力仍以后者描述的依赖为准。

`DrgSimulationService` 是合成住院上下文的事实 owner，通过现有 `CommandExecutor` 实施身份、事务、幂等、审计与 Action Trace。`drg_simulation_case` 按 Workspace/Epoch 隔离，病例 revision 在事务中核对，保存临床 revision、冻结行价格、独立收费与成本状态及不可由客户端覆盖的评估历史。它不修改门诊处方、收费、FHIR 或现有患者；首次病例只包含明确合成的基线费用与独立后续预留。

病例还冻结完整映射和模拟规则、支付参数快照，收费行分别冻结计价单位、单价和总行金额。单价用十进制定点字符串，数量为显式计价总数，整数运算在行金额边界舍入为分；疗程不再次乘算。收费发生、成本发生、临床撤回与确认冲销分别改变对应事实，已执行成本不能通过临床撤回释放。未知价保留 null，不能确认零元收费；无法匹配模拟规则时没有确定剩余额度。

接口位于 `/api/sim/v1/drg`，由登录医生或管理员访问；写入要求受信 Origin，Command 要求幂等键和病例预期版本。医生端通过 TanStack Query 读取、预览与刷新，临床草稿和处方草稿留在视图状态；请求键包含病例、revision 和完整输入，开具前再次请求服务端预览并在事务内重核依赖。模拟功能在医生工作台的独立页签提供，不发布未经实现的 Agent CLI、FHIR 能力或医保清算入口。

## Alternatives considered

| 方案 | 未采用的原因 |
| --- | --- |
| 将全部清洗行转成已启用药品或现行收费项目 | 目录资格、来源事实和当前院内计价的证据不同，未知价和保密价也不能填零 |
| 为本地清洗来源伪造 Registry 签名 | 无法建立真实上游身份；本地清洗的发布身份必须与签名 Dataset 区分 |
| 在门诊处方旁直接减一个固定金额 | 会把门诊费用误当住院全账，无法表达独立执行、冲销和住院版本 |
| 只保存模拟版本名称，不冻结参数值 | 修改模拟配置后旧病例无法重现原报价和支付参考 |
| 要求先取得真实医院数据再实现流程 | 合成映射与模拟规则已获用户授权，可独立验证流程；真实数据依赖仍显式保留 |

## Consequences

已导入目录可按数据表检索完整来源，但这不代表本院启用了全部项目。当前应用内演练覆盖肺炎、呼吸衰竭与气管内插管的显式 `SIM-*` 条件，以及少量模拟药品和输液项目；高血压可用于展示无适用规则。模拟金额、库存、剂量记录和固定预留不构成真实临床或医保规则，后续须独立实施完整住院与当地正式分组、支付和成本验收。行为与验收归属[DRG 设计方案](../../../../docs/spec/2026-10-15-drg-prescription-budget.md)。
