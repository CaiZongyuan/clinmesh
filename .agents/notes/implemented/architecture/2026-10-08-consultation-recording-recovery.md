# Agent Note: 问诊自动记录的暂停与顺序恢复

Status: implemented

## Problem

[病史增量边界](2026-10-08-consultation-history-increments.md)提供持久任务和自动更新，但医生需要暂停整理而继续问诊、显式补录既有病例及恢复失败回答。模型结果可能在暂停、恢复或重试之后返回；仅停止浏览器动作无法阻止旧结果写入。需求见[自动记录规格](../../../../docs/spec/2026-10-08-consultation-auto-record.md)。

## Decision

病例级记录资格保存控制版本、暂停状态和起始轮次。新建 DSH Consultation 默认启用，患者回复排队；既有 Consultation 没有资格时，Query 只返回待补录与未整理数量，首次补录必须由医生通过受审计 Command 明确发起。历史补录包括患者开场白，新问诊的自动排队从后续回答开始，开场白仍可作为提取上下文。后台进度与控制版本分别拥有：控制版本只随医生控制意图推进，处理成功不使控制按钮的版本过期。

公开控制合同统一表达 pause、resume、backfill 和 retry，绑定当前 Encounter 与控制版本、岗位责任、幂等键及审计。补录必须已有当前 Workspace/Epoch 的 Consultation；仅有挂号与接诊事实的旧病例返回 `WORKFLOW_CONFLICT`，不创建记录控制或任务。暂停保留已保存对话和未完成任务；控制动作推进未完成任务的代次，旧模型输出和旧 outbox 事件不再拥有写入资格。恢复与人工重试使用本次控制动作的受信上下文，不借用原任务已失效的 Grant；后台仍重新校验该确切 Grant。已完成回答、来源和[人工片段归属](2026-10-08-consultation-history-ownership.md)不因恢复而重置。

按 Consultation 序号只调度首个未完成回答；它成功应用后在同一 Command 事务排队下一回答。失败经过有界自动重试后成为可见失败，并阻止后续回答越过它。医生重试重新排队未完成回答，模型路由在新任务代次首次执行时绑定当前配置；同一代次的自动重试和重启沿用绑定。提交增量前再次检查代次、暂停状态、顺序及原有签署与 Epoch 门禁。

病例 Query 从持久任务和公开回答投影已整理、剩余与失败数量，界面区分暂停、待补录、处理中、失败待更新和待核对。TanStack Query 拥有状态；刷新、切换病例和服务重启重新读取事实。暂停与恢复控件同时出现在问诊记录和病历记录中，临床草稿合并及人工保护沿用原 owner。

控制成功先取消该病例尚未完成的读取，只有回执控制版本严格高于缓存版本时，才将记录状态合并到该 Workspace/Epoch 的病例缓存。控制版本不随处理进度、人工归属或显式草稿保存推进；同版本 Query 已反映控制提交后的事实，迟到回执保留这些事实与保存后的空值。随后重新读取病例。已有病例遇到网络或服务端暂时读取失败时继续显示已确认状态与未保存编辑，处理中状态继续轮询，服务恢复后更新进度。首次加载失败、权限拒绝、上下文冲突及无效响应仍显示错误并停止病例操作；页面与 Agent 上下文使用同一可用性判断。

## Alternatives considered

- 浏览器保存暂停标记：后台、刷新和重启无法共同遵守，因此控制与任务进度持久化在 SQLite。
- 所有回答同时提取：较晚更正可能看不到较早增量，也会在失败后形成顺序空洞，因此按首个未完成回答调度。
- 仅在启动提取前判断暂停：无法阻止已在途结果；任务代次同时隔离暂停后恢复及人工重试。
- 恢复时重跑全部回答：增加模型调用并可能恢复医生已结束的建议，因此完成任务不重置。
- 控制成功仅使病例缓存失效：后续读取失败时仍保存旧状态，无法启动恢复后的轮询，因此先应用受校验的 Command 回执，再重新读取。
- 用同版本控制回执整块替换已读取状态：后台进度、来源和显式保存可在控制版本不变时推进，因此只向更低版本缓存应用回执，保留同版本 Query 的较新事实。

## Consequences

问诊不等待补录；失败仍可保存不完整草稿。失败的首轮会暂停后续整理，医生可观察剩余数量并重试。已有病例读取不产生写入，首次补录及所有控制动作可通过公开 receipt 恢复。HTTP 与 file-backed SQLite 回归覆盖持久暂停、显式补录、按序恢复、失败重试、迟到结果、版本竞争、幂等和原有人工编辑保护；Web 组件回归覆盖迟到控制回执、同版本新 Query、后续读取失败、病例切换及空字段再次保存；Playwright 验证生产 Web 的控制旅程，React 18/19 ShadowRoot 合同验证控件交互。
