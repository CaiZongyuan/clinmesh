# Agent Note: 病历自动记录不展示来源界面

Status: implemented

同步语义核对、整轮自动重试和质量提示的当前边界由[增量记录决策](2026-10-15-low-latency-document-recording.md)补充或取代；本记录的其他来源与编辑保护理由继续适用。

## Problem

问诊整理已直接写入病历，自动记录来源区域和弹窗仍增加页面内容与操作。医生需要阅读和编辑正文，当前展示要求由[病历字段规格](../../../../docs/spec/2026-10-14-clinical-document-fields.md)拥有。

## Decision

共享 Web/DSH 病历编辑器和已签正文移除自动记录来源区域、查看来源弹窗及专用翻译。正文和整理进度、暂停、恢复、补录、重试继续使用现有组件。自动记录写入、后台来源校验、持久关联与审计沿用[直接记录决策](2026-10-14-consultation-direct-recording.md)。

本决定取代[多轮溯源决策](2026-10-12-consultation-agent-summary-sources.md)的来源查看和高亮展示；不改变其患者引用、完整句界和独立语义核对合同。

## Alternatives considered

- 默认折叠来源：仍保留额外区域和交互，不能满足当前页面展示要求。
- 同时删除后台来源：会破坏总结忠实性核对、更新合并和审计依据；展示移除不需要改变这些业务合同。

## Consequences

病历页面只展示正文和整理控制，不出现空来源容器。真实 Web 和原生 DSH 共享旅程直接检查病历字段值与刷新恢复；React 18/19 ShadowRoot 合同继续覆盖主题、语言、字号、窄分屏、长文本、只读状态和无来源入口。多轮来源归属由公开病例 Query 与服务端测试验证。
