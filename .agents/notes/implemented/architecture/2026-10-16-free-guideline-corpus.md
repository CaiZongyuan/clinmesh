# Agent Note: 免费指南的本地全文检索与用途边界

Status: implemented

## Problem

固定短引文不能覆盖新增病种，免费可下载也不能证明全文可用于任意模型服务。需要把完整来源、提取和可用性接入现有建议链，同时保持原文定位、输入预算、草稿与正式临床操作边界。需求由[免费指南规格](../../../../docs/spec/2026-10-16-free-guideline-corpus.md)拥有。

## Decision

使用独立 SQLite 保存来源和可定位原文，以 FTS5 trigram 和登记的中英主题检索；HIS 与 Reference 数据库继续拥有原有状态。下载只在显式同步时执行，建议请求只读本地库，避免网络可用性与未知内容改变本次模型输入。新增 PDF.js 仅负责 PDF 物理页文字提取，WHO 官方正文文本层直接保留字符与偏移，分段不使用模型摘要。

来源的下载身份、内容哈希、版本、更新状态和用途分别登记。未核实用途可取得和提取，但不能进入全文检索；已有短引文继续沿用其独立使用依据。固定引文通过文件哈希关联稳定来源 ID；已知撤回或替代按来源 ID、URL 或文件哈希排除同源固定引文，避免地址与文件同时更换后旧证据绕过来源状态。撤回与用途收紧先于下载生效；一般失败更新保留原有已验证内容。

同一事务产生检索依据和全库 revision，revision 进入既有建议指纹；新增、替代、撤回和用途变化都使旧结果失效。检索原文与原有短引文进入既有生成及独立核验，不新增正式诊断、院内药品、检查项目或临床规则。运行机制由[系统架构](../../../../docs/architecture.md#81-门诊闭环)拥有，运维入口见[部署指南](../../../../docs/deployment.md#免费指南全文同步)。

## Alternatives considered

- 只增加来源链接或摘要，无法让模型实际读取完整来源中的相关条款，也不能验证限定语和缺证原因。
- 增加向量服务或通用知识平台，引入新的部署、成本和维护边界，首批语料能够复用现有 SQLite 能力。
- 在生成请求内实时抓取全网，会让下载失败、重定向、来源用途和资料变动混入临床建议执行，难以复现。
- 公开下载即启用全部全文，混淆取得事实与用途许可；把未核实全文和原有必要短引文统一停用，又会丢失已有独立依据。

## Consequences

完整原文、缓存和索引保留在本地数据目录，不分发到 Git。新部署需显式同步并核对可检索数量，缺库只保留原有短引文，错库则启动失败。中文主题与英文正文的别名由来源注册表维护；当前检索没有医学语义召回保证，命中也不等于建议成立。

PDF 和文本层提取只保证可核对的字符与定位，不能替代复杂表格、脚注、临床版本和患者适用性的医学审校。WHO 非商业许可约束实际部署用途，国内全文未核实状态保持可见；具体取得事实由[来源研究](../../../../docs/research/2026-10-13-clinical-recommendation-guidelines.md#免费路线的首批原文与正文核验)拥有。
