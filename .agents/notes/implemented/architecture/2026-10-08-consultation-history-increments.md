# Agent Note: 问诊自动记录的持久增量边界

Status: implemented

## Problem

患者回答与病历填写原来是两次独立操作。后台提取可能晚于医生编辑、签署或 Epoch reset，整篇重生成不能保留人工内容，也不能证明模型使用了患者已公开的信息。整体需求及职责归属见[规格](../../../../docs/spec/2026-10-08-consultation-auto-record.md)与[整体决策](2026-10-08-consultation-auto-record.md)。

## Decision

新建 Consultation 在 DSH 模型桥接已配置时登记自动记录资格；迁移不为既有对话回填资格。患者文本回答与记录任务、可信行动上下文及 outbox 在同一 Command 事务保存。提取在事务外进行，输入只含该回答之前的 Consultation 文本，不读取 Persona、Case Truth、来源档案、宿主 Session 或 reasoning。DSH 辅助调用使用独立持久模型绑定，同一任务代次的自动重试与服务重启沿用路由；暂停、显式补录与人工重试的代次及顺序由[记录恢复决策](2026-10-08-consultation-recording-recovery.md)拥有。

模型返回窄字段、来源轮次、逐字引用与新增／更正／冲突分类。服务端要求患者文本和完整句子边界，允许句界旁的水平空白并保留换行句界，不把逗号或小数点当作句界。疑问语气同时检查引用和原文紧随引用的问号，拒绝通过截掉问号把提问当作事实；否定与限定语、伪造引用和不确定内容仍受原有校验约束。写入明确标为患者自述，居家测量及外院诊断保留原措辞；正式查体、诊断、过敏和处方不由此更新。引用边界只能约束可证明的原文，不能替代模型语义质量验收。

增量与来源持久化，应用经过共享 Command、病例责任校验及同一事务审计。[片段归属与定向核对](2026-10-08-consultation-history-ownership.md)取代基础切片的整字段及全草稿版本门禁，并拥有部分编辑保护、更正、人工核对和未保存文本合并；本记录继续拥有来源验证、授权与签署不变量，暂停补录与任务恢复由[记录恢复决策](2026-10-08-consultation-recording-recovery.md)拥有，持续核对、来源展开和撤销由[审阅和撤销决策](2026-10-10-consultation-history-review-undo.md)拥有。

病例 Query 的 `consultationRecording.hasSavedDraft` 从同一 Workspace/Epoch、病例对应的显式草稿保存 Command Effect 读取；自动写入不构成显式保存。首次加载、刷新或接收自动草稿时，只要尚未显式保存，未被已应用增量涉及的空字段就使用分诊和既往事实预填，等待医生核对保存；显式保存后的空值不被预填恢复。保存事实复用既有事务审计，不新增可与 Command 分叉的标记或迁移。

草稿与正式文书分别使用 schema：草稿允许空字符串，签署及修订仍要求完整内容。后台通过 Identity/Workspace 公共接口重新核对持久上下文；Agent 任务只保存原 Grant ID，撤销后不借同一 Client 的其他 Grant 继续写入。提问与显式重试回复都会保存完整患者回答并排队；Grant 的操作清单在签发后不可修改，因此原 Grant 含任一来源操作即可继续记录，仍须满足原有身份、岗位、时限、目录和策略约束。当前 Epoch 上下文失活时任务进入失败终态，旧 Epoch 结果被丢弃。提交前再次核对病例责任、文书状态和有效签署预览；已签文书不能被迟到结果修改。

## Alternatives considered

- 每次要求主会话 Agent 填写：依赖工具可见性及额外指令，无法保证保存后的自动触发。
- 浏览器直接启动提取：页面关闭或重连会丢失任务，无法恢复持久进度。
- 模型自由改写摘要：难以验证否定和测量来源，因此基础切片采用完整患者陈述的逐字引用。
- 并发变化后直接覆盖：会丢失人工内容，因此基础切片保留待核对建议，后续再扩展部分编辑归属。
- 只靠页面基线或草稿版本区分缺省空值：页面基线不能跨刷新保留，多个自动增量也会推进版本，因此显式保存事实由持久 Command Effect 提供。

## Consequences

患者回复不等待提取，失败只影响记录状态。自动记录复用 outbox 的有界重试、租约恢复和 Epoch abandon；来源与应用状态可重新查询。已有就诊不会因打开页面自动补录，standalone 默认不新增模型配置。主要行为通过问诊 HTTP、病例 Query 和真实 SQLite 验证，桥接测试拥有 DSH 辅助调用与重启 wiring，Playwright 拥有可见状态、自动新增提示和未保存输入保护。

模型输出修复、跨层调用预算与安全失败反馈由[自动病史调用决策](../bug-fix/2026-10-08-consultation-model-output-budget.md)拥有；本记录的来源、持久上下文与业务写入边界继续适用。
