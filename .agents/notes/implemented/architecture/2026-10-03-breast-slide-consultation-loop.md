# Agent Note: 乳腺切片病理会诊闭环

Status: implemented

## Problem

门诊医生需要为既往做过乳腺手术的 Synthea 随访病例取得一份病理结论并查看真实切片（[issue #135](https://github.com/CaiZongyuan/clinmesh/issues/135)）。病理与放射共用申请生命周期、读取边界和阅片外壳，但有三处放射没有的问题：标本从哪里来、送检的是哪一次手术、报告里哪些内容可以由系统写出。

本决策由 [issue #143](https://github.com/CaiZongyuan/clinmesh/issues/143) 交付。当前行为的详细归属是 [系统架构 8.7 节](../../../../docs/architecture.md)；切片摄取见 [病理切片摄取与独立素材包](2026-10-02-pathology-slide-ingest.md)，病例匹配见 [乳腺病例的病理切片匹配与定向生成](2026-10-02-breast-pathology-case-matching.md)，阅片引擎见 [病理切片阅片引擎选用 OpenSeadragon](2026-10-02-slide-pyramid-engine.md)。

## Decision

**入口选择既往手术切片会诊。** 公开授权的 H&E 切片几乎都来自手术切除标本，与“患者携带既往手术切片来院复核”的标本形态一致。会诊不需要本院采集、取材和制片，申请、执行、报告、已阅和更正都可以落在已有的申请内核上。

**病理是申请内核上的第三种申请类型。** 申请表的类型列追加 `pathology`，病理适配器拥有草稿表、申请明细、本院检查记录和报告内容表，状态机、幂等、版本、审计和完诊门禁汇总不复制。检验与放射的操作作用于病理申请时按既有规则返回稳定冲突。内核“同一病例同一服务只有一条进行中申请”的约束保持不变：有两次既往手术的患者依次会诊。

**送检手术由医生从可见病史中选择，以来源引用快照保存。** 服务目录随病例给出可送检的既往手术，清单只由可见来源病史和服务的手术编码决定。草稿保存和开立时各校验一次；开立后申请明细保存手术的来源引用、名称与时间。来源病史是 R4 资源，不转换为本院 R5 Procedure。

**标本如实表达“带来的既往切片”。** 报告发布时创建 Specimen：采集时间取所选来源手术的时间，接收时间是本院收片时间，处理步骤记录 HE 染色。来源手术没有本院 Procedure，因此不写 `collection.procedure`；R5 的 `container` 必须引用 Device，本院没有这类资源，玻片数量写在说明文字中。ImagingStudy 模态为 SM，每张切片一个序列并引用 Specimen；DiagnosticReport 通过 `specimen` 和 `study` 引用二者。

**报告内容来自素材清单中已复核的修订。** 模型不读取像素，报告只复述来源结构化字段，镜下所见按组织学类型使用固定表述，不写分级、部位和淋巴结判断。标本信息不在素材修订中，取申请所选的来源手术；同一张切片因此可以用于不同术式的病例。Provenance 记录受控系统执行者；所依据的素材与报告内容修订保存在本院检查记录和报告内容表中，不进入 FHIR 资源，与放射的私有边界一致。

**患者模型只知道会诊已受理。** 病理报告不作为对话卡片注入，患者模型的输入只有“哪项会诊已受理”，没有镜下所见、诊断或受体结果。

**切片阅片状态与放射共用。** 医生页面用同一份阅片状态记录“哪些申请已展开、哪些报告的图像已成功显示”，确认已阅要求切片在本次会话中成功显示过且当前可读。

## Alternatives considered

**本院活检或穿刺。** 更接近初诊流程，但需要新增采集操作、取材与制片状态，以及许可明确的活检型切片；公开素材不支持。

**为病理另建申请表与状态机。** 病理字段可以更自由，但受理、取消竞争、失败重试、已阅、修订链和完诊门禁都要重写并重新验证，检验与放射已经证明这些规则与申请类型无关。

**放开“同一服务一条进行中申请”，允许两次手术同时会诊。** 需要修改三类申请共用的唯一索引并为病理另立唯一性规则。Synthea 的乳腺癌病例只有一次乳腺手术，依次会诊足够。

**把所选手术转换为本院 Procedure 并由 Specimen 引用。** FHIR 关联更完整，但会把来源 R4 病史伪造成本院实施过的手术，违反来源病史与本院事实分属不同 owner 的规则。

**在 Provenance 中写出素材标识与报告内容修订。** 追溯更直接，但 FHIR 读取对医生和 Agent 开放，会泄露素材标识和匹配依据。

## Consequences

新增器官或标本类型时增加服务定义和素材，不改申请内核；允许同一病例多条并行会诊时需要调整共用索引。

切片像素缺失或损坏时报告仍可读，但不开放新的确认已阅；病例没有相符切片时申请以未取得结果结束，医生看到的失败信息不含匹配原因。

医生“接诊”页的检验检查栏目同时承载检验、放射和病理三类申请，该栏目发布 25 个 DSH Tool（上限 32）；病理的已阅并入通用的报告已阅提案，导航阅片并入栏目切换，见 [医生接诊页的 DSH Tool 按当前诊疗栏目发布](2026-10-02-doctor-tools-by-section.md)。病理会诊页面与 Tool 接入验收时 DSH 单文件产物为 4,015,282 字节。当前上限与体积余量见 [DSH 客户端产物体积预算](../testing/2026-10-07-dsh-client-size-budget.md)；新增依赖或页面代码仍须通过产物检查。
