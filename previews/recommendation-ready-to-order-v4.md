# 问诊页隐藏待办汇总的原型

状态：本版按已确认反馈移除问诊页的整块三类待办汇总，包括核对状态、项目数量、模块跳转、说明文字及该块中的暂停按钮。后台自动准备继续执行，结果在诊断、检查检验和处方栏目查看；暂停和恢复入口仍在对应业务模块。其余原型范围与交互见 [v3 原型记录](recommendation-ready-to-order-v3.md)。

打开 [v4 单文件 HTML](recommendation-ready-to-order-v4.html)，在问诊页点击顶部“保存下一轮问诊”和“模拟检查结果返回”，再进入三个业务栏目检查更新结果。顶部按钮为原型控制，临床内容均为合成预设，不产生真实诊疗动作。v3 文件保留不改写。

验证证据保存在本地 `.data/previews/recommendation-ready-to-order-v4/verification.json`，只核对本版变更及受影响的自动更新、暂停恢复和结果联动，不重复完整 v3 验证。
