# 放射及病理工作台

在综合门诊切换到「门诊管理员」，打开医院设置，选择「影像病理教学门诊」并确认重置世代。切换到「会诊医生」，为 Ellis Rowan 开诊。数据包的 `enabledModules` 可分别启用 `mod-imaging` 与 `mod-pathology`。

- 在「放射影像」开立胸部 CT 或胸片。在「病理会诊」选择可见的既往手术并开立会诊。费用按已核对的目录版本、币种、单价关联到原申请。预付机构须先在收费台完成放行。
- 受理并开始检查，推进虚拟时间或点击「立即出报告」。签发的所见、印象或病理诊断保存在 `diagnostic_reports`。管理员签发病例预置的更正后，负责医生须重新审阅新版。
- 打开报告先看文字。点击「打开阅片器」才会下载 Canvas 实现和该版本的关键帧。通过滚轮、方向键或按钮翻帧，拖动画面平移。放大、亮度、对比度、反相和复位均在本机执行。「预览本地图片」只创建临时对象 URL，切换或关闭时释放。
- 数据包的 `policies.requireRenderedReportFrame` 控制带图报告的首帧门禁。成功绘制报告首帧后可显式确认已阅。网络或绘制失败时，负责医生可选择「图像不可用，确认已阅文字报告」。审阅方式随报告版本记入审计。无图版本可直接审阅，本地预览不解锁正式确认。

## 教学素材

在 `cases[].caseTruth.results[]` 上声明对应服务的 `sections` 与可选 `images`。放射分为 `findings` 和 `impression`，病理分为 `microscopy` 和 `diagnosis`，各段均提供中英文。病理结果的 `priorSurgeryId` 须匹配本病例 `priorHistory.surgeries` 中的条目。相同服务、手术、阶段内按连续 `revision` 编写修订链。

`images` 可引用 `/clinical-frames/` 下的文件及子目录，或外部 HTTPS 静态对象（包括 R2）。新安装的数据包和浏览器清单每份报告最多 128 帧，每个引用最多 2048 字符。恢复旧快照会保留全部原始引用。旧图组超出展示范围时，负责医生可审阅完整文字报告。只有双语 `summary` 的既有放射结果按作者原文签发为报告摘要。

帧清单仅向具有报告审阅权限的负责岗位访客提供，查询绑定就诊、专科和已签发报告版本。随仓 `/clinical-frames/` 是可公开访问的合成教学示意图。私有图片应由外部 HTTPS 素材服务执行对象级访问控制，例如使用限时签名 URL。浏览器直接向素材服务取图。
