# 住院工作台

切换至 `cn-cardiology`，在工作台选择器进入住院工作台。挂号岗可从固定病例直接登记或核销医生开具的门诊住院证。护士选择床位接诊。住院医生确认有序诊断及 POA 后可签发药品、护理或手术医嘱。工作台按实际岗位显示命令。患者、病区与床位、行政状态、财务封账及病案状态可分别核对。

## 医嘱与执行

长期医嘱按数据包 `knowledge.inpatient.schedules` 和医院时区展开。护士校对时系统生成当天尚未经过的班次。虚拟时间跨日时生成新的待执行项并记一次床日。临时医嘱生成一次任务。PRN 需护士填写理由，每条医嘱每个本地业务日最多四次。批次药品在药房操作时出库，护士随后确认实际给药。申请停嘱即允许医生开立替代医嘱，护士核停后取消未完成任务。

在「检查检验」中可签署入院评估和开立检查。护士按照容器、标本和帽色核实合管项目，送检与检验受理在同一事务内发生。检验模块保存版本化结果，医生逐份确认已阅。

## 同台介入与病案

手术通知单冻结时间、地点、术式、医师、麻醉和术前医嘱停续策略。护士完成术前核查，医生核认结构化知情同意书。选择备选同台 PCI 时，第一阶段造影取得本次住院的病例结果，医生可以结束观察或在同一申请下转 PCI。两阶段分别核实耗材与费用。已完成阶段可供术后医嘱引用。手术终结时按通知单申请停用术前长期医嘱。

医生签发出院医嘱后由护士办理实际出区。出区停止床日费，床位保留至清床。收费员可在出院页办理预交金与首次结算。首次结算封账后护士凭最新资金状态清床。医生提交住院经过、去向与随访计划，病案员审核最新修订并归档。归档保存临床、费用和编码来源的不可变快照。

在 Windows 运行 `pnpm exec vitest run src/packages/mod-inpatient/tests` 验证操作目录、真实双宿主工作流及 UI Agent 确认。
