# 院内项目与价格映射怎么做

映射是建立“标准目录中的一项，与医院实际使用的哪一项对应”的关系。目录提供统一名称和规则，医院提供实际项目、产品、单位及价格。只取得标准目录或外省价格，不能证明本院开展、采购或按该价格收费。

## 需要的院内资料

只需项目和产品主数据，不需要患者、医嘱或就诊明细。

| 资料 | 至少需要的字段 | 通常由谁确认 |
| --- | --- | --- |
| 医疗服务收费项目表 | 院内项目码、名称、对应省级服务码、项目内涵、除外内容、单位、收费价、适用院区/医院等级、生效和失效日期、启停状态 | 物价或医保管理部门 |
| 药房产品目录 | 院内药品码、国家医保产品码、名称、厂家、剂型、规格、包装、最小制剂单位、转换比、收费单位、收费价及有效期、启停状态 | 药学部门 |
| 耗材物料目录 | 院内物料码、27位医保耗材码、注册证、厂家或注册人、规格型号、包装、采购/领用/收费单位、收费价及有效期、启停状态 | 设备耗材、物资管理部门 |
| 采购与成本表 | 院内产品码、合同/采购/库存成本的金额及口径、对应单位、有效日期；服务项目另取医院认可的成本归集规则 | 采购、库房及财务部门 |

收费价和成本分列。一项服务可能包含多个材料或药品，除外内容和是否允许另收费也要核对，不能把已包含的材料再次加到患者费用。

## 实际整理顺序

1. 固定医院、院区、适用地区、医院等级和数据截点。不同医院或日期可以对应不同价格，不能合并为一个“通用院价”。
2. 按完整编码找候选，再核对名称及关键属性。服务核对项目内涵和单位；药品核对厂家、剂型、规格、包装；耗材核对医保码、注册证、厂家、型号规格和包装。名字相同只算候选，不能直接确认。
3. 保存单位关系。采购单位、库存单位和收费单位可以不同；只有来源明确且院方确认后，才保存转换。例如“1盒=24片”仅在真实包装支持、允许拆零且收费口径确认时使用，不能仅凭同名药推断。
4. 分别挂接收费价与采购/库存成本，带原始单位、地区、有效起止日和来源版本。包装价换成每片价还须确认拆零及舍入规则；设备购置价不作为使用一次的服务收费。
5. 检查一对多、重复码、单位冲突和有效期重叠，再由相应部门确认。记录确认人、日期和依据；新价格新增版本，保留旧价。

## 映射记录的字段

| 字段组 | 保存内容 |
| --- | --- |
| 标准侧 | 标准记录ID、编码体系、完整标准编码、名称、来源版本 |
| 院内侧 | 医院/院区、院内项目或产品码、实际名称、厂家、规格型号、包装 |
| 单位侧 | 采购单位、库存单位、收费单位、转换分子/分母及证据、拆零与舍入规则 |
| 价格侧 | 收费价、采购/库存成本分别保存，金额、币种、分母单位、适用条件和有效期 |
| 审核侧 | 状态、待补字段、冲突原因、证据文件与行号、确认人和日期 |

## 状态怎么理解

- 待补全：缺院内编码、单位、价格或有效日期，空值保留，不填0。
- 待核实：有候选但属性不一致、单位不清楚、来源版本或当前有效性不明。
- 暂不可用：明确冲突、已停用、已被替代或不允许对应收费用途；标明具体用途和理由。历史事实仍保留。
- 已确认：身份、单位、价格及适用期均有依据，并由相应部门确认；本轮没有取得院内数据，所以没有这类映射。

医保药品目录的序号是目录条目编号，不是具体厂家规格的产品码。ICD-9手术操作码描述医学操作，不等于收费项目码；同一操作可能对应多项服务，不能直接一对一套价。20位耗材代码不能补零变成27位规格产品码。

当前江西、广东及心血管表提供的是各自来源的参考产品和报价。它们能帮助整理身份和字段；要形成真实院内映射，仍需上述院内主数据。缺少这些资料时，先保留“待补全”，不虚构医院或假定已采购。
