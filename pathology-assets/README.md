# 病理切片素材清单

本目录是 ClinMesh 乳腺切片病理会诊使用的病理素材包清单，与放射的 [影像素材清单](../imaging-assets/README.md) 相互独立。清单公开提交到仓库；切片像素与来源原始文件不进入 Git，由 `pnpm pathology:sync` 按清单从公开数据源拉取到本地的病理素材目录。安装、校验、修复与备份步骤见 [部署教程](../docs/deployment.md#病理切片素材)，设计边界见 [系统架构](../docs/architecture.md) 10.7 节。

## 目录内容

| 路径 | 内容 |
| --- | --- |
| `manifest.json` | 清单身份、切片数据合集（DOI、许可、署名、来源类型）和结构化临床字段的来源（地址、文件哈希、条款、署名） |
| `assets/<assetId>.json` | 一张切片：来源受试者与切片编号、Study/Series/Instance UID、IDC 序列目录、每个来源文件的字节数与 SHA-256、来源临床字段、已安装层级与摄取参数、报告内容修订及其核对记录 |
| `prompts/breast-pathology-report-v1.md` | 报告草稿整理规则；素材条目的 `draft.promptVersion` 指向它 |
| `matching.json` | 病例适配规则：适用会诊的来源病例（性别、诊断编码、可送检的手术编码、定向生成的年龄范围与至少导出的病史年数），以及受体、淋巴结与 T 类别对应的来源 Observation 编码和编码值 |

素材标识（`tcga-brca-he-01` 等）不含来源受试者编号；编号只出现在条目的 `source` 与 `clinical.sampleId` 中，不进入安装目录、回执和命令输出。

## 来源、许可与署名

切片全部来自 NCI Imaging Data Commons（IDC）公开发布的 TCGA-BRCA 切片 DICOM 转换合集，许可为 Creative Commons Attribution 3.0 Unported（CC BY 3.0），来源数据已由发布方去标识。使用、演示或再发布这些切片（包括截图和录屏）时保留以下署名：

> Clunie, D., et al. (2024). DICOM converted Slide Microscopy images for the TCGA-BRCA collection [Data set]. Zenodo. https://doi.org/10.5281/zenodo.12689962

来源文件从 IDC 公开存储桶 `idc-open-data` 匿名读取，对象路径为 `<idcSeriesUuid>/<实例>.dcm`；条目登记的 `idcSeriesUuid` 即 IDC 索引中的 `crdc_series_uuid`。

组织学类型、受体状态和病理分期不属于切片合集，来自 TCGA 开放获取的临床数据，经 UCSC Xena 的 `TCGA.BRCA.sampleMap/BRCA_clinicalMatrix` 取得，适用条款与署名单独登记在 `manifest.json` 的 `clinicalSources` 中，与切片像素的许可互不替代：

> The results are in whole or part based upon data generated by the TCGA Research Network: https://www.cancer.gov/tcga.
>
> Goldman, M. J., et al. Visualizing and interpreting cancer genomics data via the Xena platform. Nature Biotechnology 38, 675–678 (2020). https://doi.org/10.1038/s41587-020-0546-8

条目的 `clinical` 字段按样本编号（原发灶，`-01`）从该文件原样转录，取值保持英文原文，空值不写：

| 条目字段 | 来源列 |
| --- | --- |
| `histologicType` | `histological_type` |
| `estrogenReceptor` / `progesteroneReceptor` | `breast_carcinoma_estrogen_receptor_status` / `breast_carcinoma_progesterone_receptor_status` |
| `her2.ihcStatus` / `her2.ihcScore` | `lab_proc_her2_neu_immunohistochemistry_receptor_status` / `her2_immunohistochemistry_level_result` |
| `her2.fish` / `her2.finalStatus` | `lab_procedure_her2_neu_in_situ_hybrid_outcome_type` / `HER2_Final_Status_nature2012` |
| `pathologicT` / `pathologicN` | `pathologic_T` / `pathologic_N` |
| `sampleType` / `sex` | `sample_type` / `gender` |

## 摄取规则

ClinMesh 对来源切片只做下列处理，规则版本与参数记录在每个条目的 `output` 中，相同来源与参数重建出相同字节：

- **层级选择**：只保留组织金字塔（`VOLUME`）层级，丢弃缩略图、标签图和宏观图，被丢弃的实例不保留也不登记。最高安装 20 倍（0.5 µm/像素，名义倍率按像素间距取 2 的幂次，容差 5%）；原生 40 倍的切片从 40 倍生成 20 倍，40 倍实例只作为来源保留。没有原生 10 倍时从更高倍率的原生层级生成 10 倍。
- **降采样**：2×2（或 4×4）区域均值，直接对 sRGB 码值做整数运算并四舍五入（半数进位）；图像边缘只对落在层级范围内的像素取均值，超出层级尺寸的瓦片填充为白色。
- **编码**：来源 JPEG 瓦片原样复制，不重新压缩；JPEG 2000 瓦片用 OpenJPEG（`@cornerstonejs/codec-openjpeg` 1.3.6）解码后，与生成层级一样用 `jpeg-js` 0.4.4 编码为基线 JPEG（质量 85，JFIF，YCbCr 4:4:4）。
- **打包**：每个层级安装为 `levels/<n>.tiles`（按行优先顺序拼接的 JPEG 瓦片）和 `levels/<n>.index`（瓦片数 + 1 个小端 uint64 累计偏移）；第 0 层是 20 倍。单个瓦片不超过 2 MiB。
- **校验**：下载的实例必须带有请求的 Study/Series/SOP Instance UID。层级必须是 TILED_FULL、每个瓦片一个片段、8 位三通道、单一光路与焦平面，压缩为 JPEG 基线或 JPEG 2000，各层级尺寸与像素间距换算一致；其余一律拒绝。JPEG 瓦片按浏览器的规则从码流标记判断颜色模型，没有任何颜色标记且与 DICOM 声明的颜色空间不符的瓦片拒绝；带注释段或 JFIF/Adobe 以外应用段的瓦片拒绝。
- **颜色**：来源携带的 ICC profile 安装为 `icc-profile.icc` 并登记哈希，阅片不应用。

## 病例适配

适配条目不在清单中列举，由每张切片的来源临床字段派生：受体状态按自动核对的规则得出（HER2 以 IHC 3+ 或 FISH 阳性为阳性，IHC 0/1+ 或 IHC 2+ 且 FISH 阴性为阴性），淋巴结取病理 N 分期的阴性（N0）或阳性（N1–N3），肿瘤取病理 T 分期的 T1–T4 类别。五项事实相同的切片属于同一个条目；任一项无法得出的切片不形成条目，不参与病例匹配。病例的对应事实来自 Synthea 来源 Observation，编码与取值登记在 `matching.json`，五项全部一致的病例才会配到该切片，规则见 [系统架构](../docs/architecture.md) 10.7 节。

## 新增或修订素材

1. 在 IDC 索引中选定切片：女性、原发灶 FFPE 诊断切片、原生 20 倍或 40 倍。在 `assets/` 写入条目的来源部分（受试者与切片编号、Study/Series UID、`idcSeriesUuid`），并按上表从临床数据文件转录 `clinical` 字段；更换临床数据文件时同步更新 `manifest.json` 中的文件哈希。
2. 运行 `pnpm pathology:record --asset <id>` 拉取来源文件、摄取并写回来源实例与层级哈希。被拒绝的切片不会写入清单。
3. 按 `prompts/` 中的规则整理报告草稿，写入 `reports`，并记录 `draft.model` 与 `draft.promptVersion`。
4. 运行 `pnpm pathology:check`，查看由来源字段派生的受体状态和自动核对结果。HER2 字段相互矛盾或无法判定、组织学类型没有固定表述的切片不能发布。
5. 对照切片逐张复核：最低层级的组织区域内没有可识别文字，报告所写内容与切片不矛盾，来源字段转录无误。随后运行 `pnpm pathology:review --asset <id> --reviewer <姓名> --pathologist yes|no --conclusion approved|rejected` 签署。

只有通过自动核对并经人工复核通过的报告内容修订才算已发布。复核签署的内容哈希覆盖：素材标识；来源受试者与切片编号、Study/Series/Instance UID、IDC 序列目录及每个来源文件的字节数与 SHA-256；合集标识及其 DOI 与许可；临床字段及其来源的地址、文件哈希与条款；已安装层级的几何、哈希与摄取参数；`draft.promptVersion` 所指 prompt 文件的 SHA-256；报告修订本身。其中任一项变化，原签署自动失效，需要重新核对并签署。
